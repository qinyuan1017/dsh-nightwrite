# 弧光与剧情的咬合

> 适用：卡填完后要判「这个弧光会不会在正文里被用上」时读这份；排细纲时读这份。

**最常见的失败不是弧光写错，是弧光写完就被忘了。** 卡上有一段漂亮的起点→终点，正文里从头到尾没出现过一次「他缺什么」的戏，读完了角色也没变。

这份给弧光「真的进剧情」的四个咬合点、量化判据、以及细纲层面的排法。

---

## 一、四个咬合点

弧光必须在四个地方和剧情相接。**缺任何一个，弧光就只是卡上的一段字。**

| 咬合点 | 在哪 | 判据 |
|---|---|---|
| **1. 起点演给读者看** | 前 3 回 | 读者能说出「他缺什么」 |
| **2. 隐性欲望被演出来** | 前 1/3 | 至少 2 次「他自己没承认，但读者看出来了」 |
| **3. 转折落地** | 中点附近，具体回号 | 三条件全过（见 SKILL.md 第 3 步） |
| **4. 终点有对照回响** | 结尾附近 | 有一条与起点呼应但相反的戏 |

### 咬合点 1：起点演给读者看

**不能靠叙述交代。** 「他是个不被认可的仵作」是交代；「他把验尸的笔记藏在《论语》下面」是演。

**判据（前 3 回内）**：抽一个没读过设定的读者，问他「这个主角最想要什么、他最缺什么」。答得出 = 咬合；答不出 = 没咬合。

**三档强度**：

| 档 | 表现 |
|---|---|
| 弱 | 只通过他人评价交代（「听说你是仵作？」） |
| 中 | 通过一个具体动作展示（藏笔记） |
| 强 | 通过一个必须选择的情境展示（有人让他选：验尸还是读书） |

**前 3 回至少「中」档。**

### 咬合点 2：隐性欲望被演出来

**判据：隐性欲望在正文里有没有「他自己否认」的时刻？**

```
【合格】他验完尸，把刀洗了三遍。阿禾问他为什么洗这么久，他说「规矩」。
        —— 读者知道不是规矩，是他不想承认自己已经是仵作。
```

**量化：前 1/3 篇幅内至少 2 次。**

- 1 次太薄，读者会当成偶然。
- 3 次以上会变成明示（读者觉得作者在敲黑板）。

**「明示」的判据**：出现任何一句直接说出隐性欲望的内心独白。有 → 从「演」变成「说」，效果减半。

### 咬合点 3：转折落地

**判据（除 SKILL.md 三条件外补两条）**：

- **必须在具体回号**（SKILL.md 已要求）
- **回号必须在中点 ±15% 范围内**（以全书 100 回为例：第 35–65 回）

**为什么要在中点**：太早 → 后半段没有弧光驱动；太晚 → 转折的后果没时间展开。

**例外**：多卷书每卷一个小转折，大转折在中点。此时每卷的转折落在该卷 40–60% 处。

### 咬合点 4：终点有对照回响

**判据**：结尾前 5 回内，必须有一场戏，把起点的那个场景**反过来演一遍**。

```
起点（第 2 回）：他藏起验尸笔记，因为怕人看见
终点（第 98 回）：他把验尸笔记摊在堂上，当着所有人的面念
```

**判据：两场戏的「元素」是否可对应？** 地点/物件/对手/动作，至少三项对应，且方向相反。

**没有对照回响的弧光 = 读者感觉不到他变了。** 因为读者记不住抽象的人格变化，只记得住具体的场景重复。

## 二、咬合失败的四个症状

### 症状 1：「他成长了，但我不知道为什么」

**原因**：咬合点 2 缺失。隐性欲望从没被演出来，所以转折时读者不知道他失去了什么。

**诊断**：搜前 1/3 有没有「他否认自己有某欲望」的戏。没有 → 缺咬合 2。

### 症状 2：「转折很突然」

**原因**：咬合点 1 缺失或太弱。读者不知道他的起点落差，所以不理解为什么这个事件对他这么重。

**诊断**：前 3 回有没有一场「必须选择」的戏？没有 → 缺咬合 1。

### 症状 3：「后面就不像他了」

**原因**：转折后卡上 `state` 没更新，写手仍在按旧阈值写。

**诊断**：`characters.state` 的 `updatedAt` 是否在转折回之后？不是 → 缺更新。

### 症状 4：「结尾没什么感觉」

**原因**：咬合点 4 缺失。没有对照回响。

**诊断**：结尾前 5 回有没有与起点对应的戏？没有 → 缺咬合 4。

## 三、细纲层面的排法

弧光不是写完卡就完事，要在细纲里**占位置**。

### 排法：四个咬合点各占一章的「一件事」

以 100 回为例：

| 回 | 弧光任务 | 该回的「三件事」里必须有一件是 |
|---|---|---|
| 2 | 起点演出来 | 一次「必须选择」的戏 |
| 8 | 隐性欲望第 1 次 | 一次他否认的动作 |
| 18 | 隐性欲望第 2 次 | 一次他差点承认但被打断 |
| 50 | 转折 | 三条件全过的事件 |
| 95 | 对照回响 | 起点场景的反演 |

**这五回不许被主线事件挤掉。** 判据：这五回的细纲 `summary` 里，必须有一条与弧光任务直接相关。

### 弧光戏的独立性

**弧光戏可以和主线戏合并**，但**不能没有**。

```
【合并的好例】第 8 回：他奉命验一具尸，尸是他从前的同窗。他拒绝了。
               —— 既推进主线（有人死了），又演隐性欲望（他不想承认自己是仵作）
【分离的坏例】第 8 回整整一回都在写他内心的挣扎，主线零进展
```

**判据：弧光戏占该回篇幅的多少？** ≤40% → 好；40–70% → 可接受；>70% → 读者会觉得「这章没内容」。

## 四、配角弧光的压缩版

配角不需要四个咬合点全走，但需要**两个**：

| 配角类型 | 需要的咬合点 |
|---|---|
| 重要配角（出场 ≥10 回） | 1 + 3（起点演一次 + 一个小转折） |
| 功能性配角（出场 3–9 回） | 1（起点演一次） |
| 背景人物 | 0 |

**重要配角的转折可以不在中点**，但要落在他的出场区间内。

**配角的弧光不许抢主角的转折回。** 判据：同一回里不许有两个角色的转折。

## 五、弧光的三种反常配置（合法但需声明）

### 反常 1：不完成弧光

角色到结尾也没补上起点缺的东西。

**合法条件**：卡上必须写 `arc: 不完成（理由：……）`，且正文里必须有一处让读者意识到「他没能改变」。

**例**：悲剧配角、注定失败的反派。

**不声明就是失败**——读者会认为作者忘了。

### 反常 2：反向弧光

起点是好的，终点是坏的。

**合法条件**：反向弧光的转折必须是「他做了正确的选择，但世界惩罚了他」。

**例**：他守住了阈值，因此失去一切。

**判据：读者会不会觉得「这是世界的错」而不是「这是作者的错」？** 会 → 合法。

### 反常 3：平弧光

角色不变，但世界因他而变。

**合法条件**：必须有一个「世界变了」的可验证证据（某个制度改了、某个人被说服了）。

**平弧光的主角很少**，一般用于群像或史诗题材。

---

## 六、咬合检查表

排完细纲后逐项过：

- [ ] 前 3 回内有一场「必须选择」的戏（起点）
- [ ] 前 1/3 内有 ≥2 次「他否认自己欲望」的戏（隐性欲望）
- [ ] 转折落在具体回号，且在中点 ±15% 内
- [ ] 转折那一回，细纲 `summary` 有一条直接对应
- [ ] 结尾前 5 回内有一场与起点对应的反演戏
- [ ] 四个咬合点各自的回，都没有被主线完全挤掉（弧光戏占 15–40% 篇幅）
- [ ] 转折后 `characters.state` 已更新
- [ ] 同一回没有两个角色的转折
- [ ] 若为反常配置，卡上已声明

**九项全过 = 弧光真的进了剧情。**
