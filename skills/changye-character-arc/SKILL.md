# 人物弧光

设计角色的**变化轨迹**与**行为边界**。产物必须能用来判定「这个行为像不像他」。

## 五段式

| 段 | 内容 | 判据 |
|---|---|---|
| **起点** | 他现在的处境与自我认知 | 一句话说清他缺什么 |
| **欲望** | 显性目标（他自己承认的） | 能被拒绝、能被阻挠 |
| **隐性欲望** | 他不承认但驱动他的（核心） | 他自己说出来会反驳 |
| **转折** | 一个让他不得不重新选择的事件 | 发生后他无法回到原样 |
| **终点** | 他变成了什么样 | 与起点形成可对照的反差 |

加两个边界：
- **心理阈值**：绝不做的事 + 破例条件
- **能力上限**：能做什么、绝做不到什么

## 执行步骤

**第 1 步：先写隐性欲望**

这是最容易跳过也最重要的。三个测试：

1. 他能坦然说出来吗？→ 能说出来的是显性欲望，不是隐性。
2. 它和他的显性目标冲突吗？→ 不冲突就没有张力。
3. 它来自过去的什么？→ 说不出根源的隐性欲望是空的。

**第 2 步：写心理阈值（必须可判定）**

- 坏：「他很重感情。」（无法判定）
- 好：「他不会丢下同伴，哪怕会输；唯一破例条件：同伴已经变成敌人。」

破例条件必须写在卡上——没有破例条件的阈值会在关键情节挡住作者。

**第 3 步：定转折（必须不可逆）**

转折的三个条件：
1. 由**角色自己的选择**造成（不是别人逼的）；
2. 让他**失去**某样东西；
3. 之后**不能撤回**（不许用「其实没死」抹掉）。

**第 4 步：写终点与反差**

终点必须和起点形成**可对照的反差**：

```
起点：为了活着可以低头
终点：为了不低头宁愿死
```

没有反差的「成长」= 只是变强了，不是弧光。

**第 5 步：落盘**

`changye_op` → `ledger.upsert`（kind=`characters`），`id` 稳定。配角也要建卡，哪怕只有三行。

## 输入

- `ledger.get` 的 `characters`（防重复）、`rules`（能力上限受世界规则约束）
- `outline.get`（这个角色在哪几回出场，转折要落在具体回目）
- `brief`（题材决定弧光的幅度）

## 输出格式

```
【角色】<名> · id=<…>｜<身份>
【起点】<处境 + 自我认知>｜缺 <…>
【显性目标】<…>（可被阻挠的点：<…>）
【隐性欲望】<…>｜根源：<过去发生了什么>
【心理阈值】绝不：<…>｜破例条件：<…>
【能力上限】能 <…>｜绝做不到 <…>（受 rules/<规则名> 约束）
【转折】第 <n> 回 — <事件> — 失去 <…> — 为何不可逆：<…>
【终点】<变成什么样>｜与起点的反差：<一句对照>
【禁区】<这个设定挡住哪类写法>
```

## 检查清单

- [ ] 隐性欲望过了三测试（说不出、与显性冲突、有根源）
- [ ] 心理阈值写成可判定的句子，且有破例条件
- [ ] 转折由角色自己的选择造成
- [ ] 转折让他失去了具体的东西
- [ ] 终点与起点形成可对照的反差
- [ ] 能力上限与 `rules` 不冲突
- [ ] 转折落在具体回目，不是「中后期」
- [ ] 用了稳定 `id`，没有重复角色
- [ ] 配角也建了卡

## 禁止事项

- 不许写完整对白（只可给一句口吻示范）。
- 不许决定商业节奏（谁多出场、谁发便当）。
- 不许建「完美角色」：没有缺点、没有隐性欲望、没有破例条件的一律作废。
- 不许在正文写完之后补卡来「圆」已写出的行为；补卡必须声明是修正基准还是新增设定。
- 不许让转折由巧合或他人强制造成。
- 不许改 `rules` 来给角色加能力。
