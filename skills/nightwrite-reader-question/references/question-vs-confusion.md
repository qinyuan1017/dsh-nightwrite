# 悬念与困惑的判定

一份疑问清单的价值，全在分类对不对。把悬念判成困惑，改稿会把好钩子拆掉；把困惑判成悬念，读者会在某一章彻底放弃而且说不出为什么。

## 一条总判据

只问一句话：

> **读者能不能用一句人话把这个疑问说出来？**

- 能，而且说完之后他**想知道答案**（愿意等）→ 悬念
- 能，但说完之后他**觉得是自己漏看了**（回头翻）→ 困惑（信息投放问题）
- 说不出来（只觉得糊）→ 困惑（信息缺失）
- 能说出来，但**文本永远答不了**（前后矛盾）→ 硬伤

**「说不出来」是困惑的硬标志。** 读者读完一段，如果情绪是「有点闷」而不是「我想知道 X」，那就是没建立问题。

## 悬念的四个成立条件

### 条件一：指向具体

**判据**：这条疑问里有没有一个明确的「谁 / 什么 / 怎么」？

| 合格 | 不合格 |
|---|---|
| 「他袖子里那个东西是什么？」 | 「感觉有事要发生」 |
| 「院主为什么说他一个人住？」 | 「这里有点奇怪」 |
| 「他为什么不认沈这个姓？」 | 「他的身份好像有问题」 |

**「有点奇怪」「好像有问题」不是悬念**，是读者的钝感。它们说明文本给了不具体的异样感，但没给可追问的对象。

### 条件二：读者知道「有这么个东西」

SKILL 第 3 步的核心。**这是最常被违反的一条。**

| 成立 | 突兀 |
|---|---|
| 读者看到他把东西塞进袖子（不知道是什么）→ 后文掏出 → 成立 | 读者从未见过袖子有东西 → 后文突然掏出 → 突兀 |
| 读者听到院主说「别问」→ 后文揭出他藏着人 → 成立 | 从未有人提过 → 后文揭出 → 突兀 |

**判据**：这条悬念的「物件/信息」，在埋设段里有没有**被读者感知到存在**（哪怕不知道是什么）？

- 感知到存在 → 悬念
- 完全没出现 → 突兀（不是悬念，是漏埋）

**「感知到存在」的最低标准**：一个具体的名词或动作。不许是「一种感觉」。

### 条件三：文本暗示过答案存在

**判据**：文本里有没有让读者相信「这个问题是有答案的」？

三种暗示方式：

| 方式 | 例 |
|---|---|
| 有人物明确表示知道 | 「这事你别问。」 |
| 有一个可查的物证 | 官凭上的墨色深了一块 |
| 有一处反常（既然正常，就不该反常） | 碗是两只，但他说一个人住 |

**缺了这一条会怎样**：读者会认为这是作者随便写的，不会追。

**反例**：主角路过一座荒庙，作者写「庙里有尊没有脸的神像」，然后三章不提。读者不知道这是不是伏笔 → 不构成悬念，只是布景。

### 条件四：答案有代价

**判据**：读者想知道答案，是不是因为**知道答案会改变什么**？

| 有代价 | 无代价 |
|---|---|
| 「他袖子里是什么？」→ 若被人发现就完了 → 急 | 「他袖子里是什么？」→ 什么都不会变 → 不追 |

**无代价的疑问不算悬念**，最多算「有意思的细节」。判断方式：把答案直接告诉读者，会怎样？什么都不变 → 无代价。

## 困惑的三个子型

### 子型一：信息缺失（真漏）

**判据**：读者问出了一个具体问题，但整章（以及前文）没有任何地方提供答案，也没暗示答案存在。

**检测方法**：拿这个问题去正文里搜关键词。搜不到任何相关内容 → 信息缺失。

**修法**：补一句。位置规则见 SKILL 第 4 步：**在读者产生疑问的那一段之后 2 段内**。

### 子型二：信息投放问题（写了，但在读者放弃之后）

**判据**：正文里**有**这个信息，但出现在读者产生疑问之后的第 3 段以外，或者出现在下一章。

**这是最常见的一种**，且作者最不服气（「我明明写了」）。

**检测方法**：

```
1. 记下读者的疑问出现在第 X 段
2. 找到正文里回答它的位置，记第 Y 段
3. 计算 Y - X
```

| Y − X | 判定 |
|---|---|
| ≤2 | 正常 |
| 3–4 | 边缘（读者可能已经跳过了） |
| ≥5 | 困惑（读者大概率已经放弃理解） |
| 跨章 | 严重困惑 |

**为什么是 2 段**：读者的短期理解窗口大约是 2 段。超过这个距离，他要么回头翻（打断沉浸），要么放弃（后面越读越糊）。

### 子型三：指代不清

**判据**：读者知道这里有信息，但不知道这个信息指向谁/什么。

**典型**：

```
· 「他看了他一眼。」          ← 两个他是谁
· 「那个人没有回答。」        ← 哪个人
· 「事情没有那么简单。」      ← 哪件事
```

**检测方法**：把这句话单独摘出来，给一个没读过前文的人看，他能不能说出「谁/什么」？不能 → 指代不清。

## 硬伤的判定

**判据**：读者问出了一个具体问题，文本里**有两处互相矛盾的答案**。

| 硬伤 | 非硬伤 |
|---|---|
| 第 12 段说「他不知道官凭被改过」，第 30 段说「他早知道」 | 第 12 段说「他不知道」，第 30 段说「他猜到了」——猜测不是知道 |
| 第 3 段说「三日后」，第 20 段说「次日」指同一件事 | 两件事、两个时间 |
| 第 8 段他在城东，第 10 段他在城西且无移动 | 中间有交代 |

**硬伤必须转审校**（`nightwrite-continuity-pass`）。这份手册不处理硬伤。

**判据的关键**：硬伤必须是**事实层**的矛盾。动机不充分、节奏不好、人物不够立体——这些不是硬伤。

## 四种典型误判

### 误判一：把「读者没注意到」当成「悬念成立」

作者埋了伏笔，但埋在一段环境描写里，读者的注意力在别处。

**判据**：埋设那一段，读者读完之后会记得「有这么个东西」吗？

**检测方法**：读埋设段的前后各一段，问「这一段里最显眼的三样东西是什么」。要埋的物件在不在前三？

- 在 → 成立
- 不在 → 埋得太浅，需要提权（给它一个动作，别放在环境列表里）

### 误判二：把「读者懒得想」当成「困惑」

一段信息密度很低的内容，读者不会问问题。

**但这不是困惑，是无感。** 困惑的定义是「想问但问不出」或「问了但答不上」，前提是**有想追问的驱动力**。

**判据**：这一段的读者情绪，是「糊」（想搞清楚）还是「困」（不想搞）？

- 糊 → 困惑
- 困 → 不是困惑，是平坦段（转 `nightwrite-engagement-curve`）

**区别方法**：平坦段的读者会说「有点无聊」，困惑的读者会说「没看懂」。

### 误判三：把「留白」当成困惑

**留白**的定义：作者故意不给，且**不给本身有意义**。

**判据**：这个信息的缺失，会不会在后文被证明是刻意的？

- 会（后文有角色意识到「他从来不说这个」）→ 留白
- 不会 → 漏

**关键区别**：留白有**标记**。作者会通过某个人物的反应告诉读者「这里确实有东西没讲」。没有标记的缺失，读者只会觉得作者忘了。

### 误判四：把「悬念太密」当成「困惑多」

一章埋 8 个悬念，读者的实际体验是糊的，但每条单独看都是合格的悬念。

**判据**：数这一章的悬念条数。

| 单章悬念条数 | 判定 |
|---|---|
| 1–3 | 正常 |
| 4–5 | 偏密（读者记不住，需要分级） |
| ≥6 | 过密（读者的体验等同困惑） |

**修法**：不是删，是**分级**——明确哪 1–2 条是本章主悬念（有反复提及），其余降为背景疑问（只在埋设处出现一次）。

**用户视角的判据**：「这一章我最想知道的是什么？」读者答得出来 → 分级清楚；答不出来 → 过密。

## 统计与阈值

```
【统计】悬念 n · 困惑 n · 硬伤 n
```

三档的比例参照：

| 章型 | 悬念 | 困惑 | 硬伤 |
|---|---|---|---|
| 健康章 | 1–3 | 0–1 | 0 |
| 可修章 | 任意 | 2–4 | 0 |
| 必改章 | 任意 | ≥5 | 0 |
| 转审校 | 任意 | 任意 | ≥1 |

**注意**：困惑为 0 也不一定是好事。全书零困惑，说明信息给得太满，读者没有参与推理的空间——那是另一种问题（平淡）。

## 报告填写要点

```
【疑问清单】
  #1 第 6 段「他袖子里藏的是什么？」→ 悬念
      依据：第 5 段写他把东西塞进袖子（读者知道有这么个东西）；第 8 段有人问「你带的什么」，他没答（暗示有答案）
  #2 第 14 段「他为什么要去城西？」→ 困惑（信息投放问题）
      依据：答案在第 21 段（Y-X=7），超过 2 段窗口
  #3 第 22 段「他说『我从不欠人』指的是什么？」→ 硬伤
      矛盾处：第 22 段 vs 第 31 回（欠李婶一条命）
【悬念】（保留）
  · 袖中之物 — 指向：物件 — 暗示位置：第 5、8 段 — 条件四（有代价）：有，被人发现则前功尽弃
【困惑】（必须补）
  · 去城西的动机 — 缺什么：目的 — 应补在：第 14 段之后 2 段内（建议挪第 21 段的关键句）
【硬伤】（转审校）
  · 「我从不欠人」— 矛盾处：第 22 段 vs 第 31 回
【藏得对不对】
  · 袖中之物 — 读者是否知道「有这么个东西」：知 → 成立
【统计】悬念 1 · 困惑 1 · 硬伤 1
```

## 一个反直觉的结论

**困惑比硬伤更危险。**

硬伤会被读者当成「作者写错了」，然后继续读——因为它通常只影响一个点。

困惑会让读者**停止推理**。一旦停止推理，他就从「参与者」变成「旁观者」，后面所有需要他动脑的地方全部失效。而且他不会说「我看不懂」，他会说「这书不好看」——作者永远收不到准确反馈。

所以修稿顺序应该是：先消困惑（恢复读者的推理能力），再修硬伤（补事实），最后调悬念密度。
