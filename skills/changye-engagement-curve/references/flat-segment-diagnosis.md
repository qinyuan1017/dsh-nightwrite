> 适用：曲线打完发现某几段是平的，要知道「为什么平、该怎么修」时读这份，取四类成因的识别特征与对应修法。

# 平坦段的四类成因

平坦段（三曲线全 ≤4）不是一种病，是**四种病共用一个症状**。诊断错了，修法就全错——最常犯的是把「缺信息」的段落当成「缺动作」来修，结果加了一堆动作，还是平的。

## 分类判据：先问「这一段原本想干什么」

拿平坦段，问一句：**作者写这一段，本来想让读者得到什么？**

| 作者原本想给的 | 成因类型 |
|---|---|
| 让读者知道某件事 | 类型一：信息无效 |
| 让读者看见某个画面 | 类型二：描写无锚 |
| 让读者感受到某种情绪 | 类型三：情绪空转 |
| 让读者跟上时间/空间 | 类型四：过渡冗余 |

四类的修法完全不同。判类型时不要看段落写了什么，看**它想干什么**。

## 类型一：信息无效

### 识别特征

- 段内确实有新信息，但读者**不觉得自己需要它**
- 信息与被关心的人/事无关（历史、地理、势力介绍、别人的背景）
- 信息出现的位置离「需要它的时刻」太远（提前三章交代，三章后才用）

### 三种子型

| 子型 | 特征 | 例 |
|---|---|---|
| 提前交代 | 信息在这里出现，但到后面才用 | 开头介绍三家势力的关系，第 10 章才用到其中一家 |
| 无主信息 | 信息不属于任何在场的人 | 叙述者直接交代「此地三百年前是战场」 |
| 重述 | 信息是已知的，只是换了说法 | 第 3 段说了他左臂有伤，第 18 段又描述了一遍疼痛 |

### 修法

**修法一（首选）：把信息挪到它被需要的那一刻。**

不是删，是移。信息在被需要的瞬间给出，读者会主动吸收；在不需要时给出，就是平坦段。

判定「被需要的瞬间」：有人**因为不知道这条信息而面临损失**的那一刻。

**修法二：让信息长在一个人的处境上。**

原文：`此地三百年前是战场，据说夜里能听见甲胄声。`

改成：`「你夜里听见了吗。」院主把灯芯剪短，「这地方三百年前是战场。」`——信息没变，但它现在长在一个人身上，且这个人说这句话有目的（试探/警告）。

**修法三：重述直接删。**

重述没有修法，只有删除。如果删了读者会不懂，说明第一次说得不够清，改第一次。

### 不该用的修法

- **加动作点缀**（「他一边听着一边擦刀」）——信息还是无效，只是多了动作
- **加情绪反应**（「他听了心中一凛」）——读者没有跟着凛，因为他还不知道为什么要凛

## 类型二：描写无锚

### 识别特征

- 段内是场景/外貌/环境描写，且**没有人物在其中做任何事**
- 描写的对象后文不再出现（或只作为背景）
- 读者读完说不出「这段告诉了我什么」

### 两种子型

| 子型 | 特征 | 例 |
|---|---|---|
| 纯布景 | 描写一个后文要用的空间，但当前场景不在其中发生任何事 | 开头 200 字描写院子，人物第 3 段才出现 |
| 抒情布景 | 描写承担了情绪（「风从北面来，带着雪意」），但没有人在感受它 | 最常见的 AI 味段落 |

### 修法

**修法一：让人在里面做一个动作，且这个动作要用到描写里的东西。**

原文：`墙塌了一角，碎砖堆在井台边。井绳断了半截，垂在井沿上。`

改成：`他蹲到井台边，把断绳的两头往一处缠。碎砖硌着膝盖。`——描写里的三样（井台、断绳、碎砖）全部被动作使用了。

**修法二：让描写只留下「会被用到的那几样」。**

判据：这个物件在后续 3 章内会不会被用到？不会 → 删。会 → 保留，其余删。

一个场景通常只需要 **2–3 个物件**。写五个，有三个是负担。

**修法三：把抒情布景改成人物的感知。**

原文：`风从北面来，带着雪意。`

改成：`他把领口拢了拢。风从北面来。`——同样一句环境，现在长在一个人的身体反应上。

### 不该用的修法

- **把描写缩短**（从 300 字压到 150 字）——还是无锚，只是短了
- **换更漂亮的词**——不解决锚定问题

## 类型三：情绪空转

### 识别特征

- 段内在写情绪（心理活动、感受、回忆），但**读者没有跟着产生情绪**
- 情绪是被**命名**的（他很痛苦、他很愤怒），不是被演出来的
- 回忆段落，且回忆的内容读者已经知道

### 三种子型

| 子型 | 特征 | 例 |
|---|---|---|
| 情绪命名 | 直接说「他很难过」 | 「他心里一片冰凉」 |
| 回忆重述 | 回忆的是读者刚读过的事 | 「他想起三天前那件事」（三天前刚写过） |
| 提前抒情 | 事件还没发生，先写感受 | 「他知道，这一去凶多吉少」（还没去） |

### 修法

**修法一：把情绪命名换成一个具体动作。**

原文：`他心里一片冰凉。`

改成：`他把手在裤子上擦了两下，才去推门。`——不写冰凉，写手心的汗。

**判据**：改完之后，读者能不能自己得出「他害怕」这个结论？能 → 改对了。

**修法二：回忆只留「与当下处境直接相关的那一句」。**

回忆的作用是给当下的动作加重量。所以回忆必须**解释当下的某个具体反应**。

原文：`他想起三天前那件事。那天他也是这样站在门口。`

改成：`他在门口站住。三天前他也站在这儿，那次他没推门。`——回忆压缩成一句，且立刻与当下的动作（推不推门）挂钩。

**修法三：提前抒情直接删。**

事件没发生前的感受，读者无法共鸣（他还不知道会发生什么）。移到事件之后。

### 不该用的修法

- **加强情绪词**（从「很难过」改成「痛彻心扉」）——命名得更重，读者更没感觉
- **加感叹号/破折号**——排版不能制造情绪

## 类型四：过渡冗余

### 识别特征

- 段内是移动、等待、准备、收拾——没有变化发生
- 出现「然后」「随后」「过了一会儿」「就这样」
- 读者读完不知道时间过了多久，也不知道为什么要有这一段

### 两种子型

| 子型 | 特征 | 例 |
|---|---|---|
| 移动冗余 | 从 A 到 B 的过程被写出来，但过程中没发生任何事 | 「他出了门，沿着街往西走，走了小半个时辰，到了米铺。」 |
| 准备冗余 | 出发前的准备被逐项写出 | 「他把刀别好，把干粮装进袋子，又检查了一遍水囊。」 |

### 修法

**修法一：硬切。**

删掉移动过程，直接写到达后的第一句（且必须是动作或声音）。

原文：`他出了门，沿街往西走，走了小半个时辰，到了米铺。米铺关着门。`

改成：`米铺关着门，门板上贴了一张纸。`——读者自己知道他在米铺，移动被完全省略。

**修法二：如果移动过程中有事，只写那件事。**

移动段落唯一的存在理由是「路上发生了什么」。如果发生了，砍掉其余，只留那件事；如果没发生，全删。

原文：`他沿街往西走，路过一个卖饼的摊子，摊主在收摊。他想起自己一天没吃东西，但没停。走了小半个时辰，到了米铺。`

改成：`卖饼的在收摊。他站着看了一会儿，没买。`——只留下「他没买」这件事（这件事说明了他没钱/有急事），移动全删。

**修法三：准备冗余压成一个细节。**

准备过程只有在下述情况才有价值：**某样东西被特意带上或特意留下**。

原文：`他把刀别好，把干粮装进袋子，又检查了一遍水囊。`

改成：`他把刀别好，干粮没带。`——只留「没带干粮」这一个反常决定，它携带信息。

### 不该用的修法

- **把过渡写得好看一点**——过渡的功能是连接，不是内容
- **在过渡里加心理活动**——那会变成类型三（情绪空转）

## 混合型：一段命中两类

平坦段经常是混合的（既有无锚描写又有过渡功能）。处理顺序：

1. **先判主类型**（它想干什么）
2. **主类型修完再复评**
3. 通常修完主类型，次类型会自动消失（因为段落变短了）

不要两类同时修，会导致改出来的东西比原来更乱。

## 四类成因的修法成本对照

| 类型 | 典型成本 | 收益 |
|---|---|---|
| 信息无效 | 低（挪位置）/ 中（改造成人物台词） | 高 |
| 描写无锚 | 低（删多余物件）/ 中（重写成带动作） | 高 |
| 情绪空转 | 中（换成动作需要重写） | 高 |
| 过渡冗余 | 最低（直接删） | 中（删了不损失，但也不增加） |

**优先级**：过渡冗余先处理（最低成本、零风险），然后是信息无效和描写无锚，最后是情绪空转（成本最高）。

## 一类特殊情况：设计出来的平坦

有些平坦段是**故意的**，用来制造对比。

**合法条件**（三项全中才算合法）：

1. 平坦段紧邻一个高峰（前或后 1–2 段内）
2. 平坦段长度 ≤ 高峰段的 1/2
3. 平坦段承担明确功能（喘息/时间流逝/人物独处后的决定）

**三项缺一 → 不是设计，是失控。**

判据：如果删掉这个平坦段，读者会不会觉得「中间缺了什么」？不会 → 它不是设计，删掉。

## 诊断报告格式

```
【平坦段】第 <a>-<b> 段（<n> 字）｜三曲线 <好奇 n / 紧张 n / 情绪 n>
【主类型】<信息无效 / 描写无锚 / 情绪空转 / 过渡冗余>
【子型】<哪一种>
【识别证据】「<引用原文 ≤20 字>」→ <为什么判这一类>
【是否设计】<是/否> — 依据：<三项条件逐项>
【修法】<哪一条修法> — 动作：<挪位置 / 换动作 / 删 / 压成一句>
【预期效果】<删多少字 / 三曲线预估变化>
```

## 一个反直觉的结论

**平坦段最常出现在「作者查过资料」的地方。**

作者为了写某个场景去查了大量细节（官制、器物、地理、工艺流程），写的时候舍不得丢，全塞进去。这些内容对作者是宝贵的研究成果，对读者是零。

判据：这段里的细节，有多少是**读者需要才能理解后续剧情**的？低于 30% → 这整段是作者的研究笔记，不是小说。
