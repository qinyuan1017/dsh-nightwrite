> 适用：要给一章打三条曲线分数、或者怀疑「这章某段是平的」要定量确认时读这份，取采样点、三档刻度锚点与平滑方法。

# 曲线采样与刻度

三条曲线（好奇/紧张/情绪）的本质是**按段落采样**。采样做错，曲线就是自己编的。

## 采样单位：自然段，不是场景

**采样单位 = 自然段**（含对白段）。理由：读者的阅读停顿发生在段与段之间，不在场景与场景之间。

**切段细则**：

| 情况 | 处理 |
|---|---|
| 单段 ≤300 字 | 一段一采样 |
| 单段 300–600 字 | 在段落内部的转折处（出现新动作/新信息/话题切换）切成两段采样 |
| 单段 >600 字 | 必须切，切成 250–300 字左右 |
| 对白段 | 连续对白每 3–4 句算一个采样点（因为读者读对白更快） |
| 场景标题/分隔线 | 不算采样点，只作边界标记 |

**采样点数量参照**：3000 字的章约 25–40 个采样点。低于 20 → 切得太粗，平坦段会被平均掉；高于 50 → 切得太细，噪音淹没形状。

## 三档刻度（完整锚点）

SKILL 只给了「1–10 分」和「高分特征」。要打出可比较的分，必须有锚点，否则每章的分都不可比。

### 好奇度锚点

问的是「我想知道接下来会怎样吗」。

| 分 | 锚点 | 具体判据 |
|---|---|---|
| 1–2 | 无问题 | 这一段结束时，没有任何悬着的问题。读者可以在此停下 |
| 3–4 | 有问题但读者不在意 | 有问题，但指向的对象读者不关心（一个刚出场的配角会怎样） |
| 5–6 | 有明确问题 | 指向读者已关心的对象，且这个问题可被回答（他会不会去 / 她知不知道） |
| 7–8 | 有问题且读者想要答案 | 指向读者已投入的对象 + 问题有代价（答错会失去什么） |
| 9–10 | 问题逼着往下读 | 问题刚被提出（不是重申）+ 答案必须马上知道（时间压力/动作悬停） |

**打分的判别式**：`如果读者在这里合上书，他会不会因为不知道答案而难受？` 会 → ≥7；不会但有一点好奇 → 5–6；无所谓 → ≤4。

### 紧张度锚点

问的是「有没有要输的东西」。

| 分 | 锚点 | 具体判据 |
|---|---|---|
| 1–2 | 无赌注 | 没有任何可能失去的东西 |
| 3–4 | 赌注是抽象的 | 「可能会不好」但没有具体的东西会失去 |
| 5–6 | 有具体赌注但不紧迫 | 明确知道会失去什么，但没有时间压力 |
| 7–8 | 具体赌注 + 紧迫 | 明确会失去什么，且随时可能发生 |
| 9–10 | 赌注已开始损失 | 正在失去（不是可能失去），且不可逆 |

**关键区分**：紧张度高分不靠「危险」，靠「**损失的具体性 + 时间上的逼近**」。两个人在安全屋里平静讨论一个可能致命的计划，紧张度只有 5；一个人在安全屋里，但知道对方三分钟后会推门进来，紧张度 8。

### 情绪值锚点

问的是「我现在有感觉吗」。

| 分 | 锚点 | 具体判据 |
|---|---|---|
| 1–2 | 无感 | 纯粹的信息/动作交代，读完没有任何情绪指向 |
| 3–4 | 有情绪但很弱 | 有一点（轻微不适/轻微愉悦），但说不出指向谁 |
| 5–6 | 有明确情绪 | 能说出「我为他着急 / 我讨厌这个人」，但强度中等 |
| 7–8 | 强情绪 | 愤怒/心疼/爽/恐惧，有明确指向，且有身体反应（想骂、鼻子酸） |
| 9–10 | 情绪峰值 | 想停下来喘一口气 / 想立刻看下一段 |

**判据**：情绪值的分数不是「写得好不好」，是**读者的反应强度**。写得克制但有效的一段可以是 8 分；写得煽情但读者没反应的是 3 分。

## 平坦段的判定与边界

SKILL 定：三条都 ≤4 = 平坦段。

**边界处理**（SKILL 没说清的部分）：

| 情况 | 判定 |
|---|---|
| 好奇 4 / 紧张 4 / 情绪 5 | **不是**平坦段（有一项过 5） |
| 好奇 4 / 紧张 4 / 情绪 4 | 是平坦段 |
| 好奇 3 / 紧张 5 / 情绪 3 | 不是，但这是**低效段**：只有紧张度撑着，容易累 |
| 好奇 6 / 紧张 2 / 情绪 2 | 不是，但这是**单一驱动段**，见下文 |

**新增两个次级判定**（不是平坦段但同样需要处理）：

- **低效段**：只有一项 ≥6，其余 ≤4。这一类段落的共同问题是读者只用一种动力在读，读三四个就会累。
- **虚高段**：三项都 7+ 但读者实际不会有反应。判据：这一段里发生了什么事？如果只能说出「他想了想」「他们说了几句」，三项分都被高估了。**虚高是最常见的打分错误**。

## 平滑：怎么处理单点尖峰

单段的分数会抖。相邻段的正常波动是 ±2，超过 ±3 的跳变要么是真实断裂，要么是打分不一致。

**判断规则**：

```
|score[i] - score[i-1]| ≥ 4 → 复核这两段的打分
```

复核方法：把两段的「发生了什么」并排写出来，重新打一次。如果还是差 4 分以上 → 真实断裂（记入报告）；如果重打后差 ≤2 → 原来打错了。

**不许做数值平滑**（移动平均）。曲线的作用是暴露问题，平滑会掩盖尖峰和断崖——而断崖正是最需要报的东西。

**允许的一种处理**：对白快节奏段的分数天然偏高（因为读者读得快，单位时间刺激高）。可以给对白段统一压 1 分，但必须在报告里注明。

## 三种曲线形状的完整判据

SKILL 第 4 步给了三种：单调下降、一条直线、锯齿过多。这里给第四种（最常见的好形状）和各自的量化判据。

### 形状一：上升型（健康）

**判据**：末段三项分的均值 ≥ 首段均值 + 2，且中途没有 ≥4 的断裂。

**例外**：如果末段是章末钩子，允许最后 1–2 段陡升（这是设计）。

### 形状二：单调下降（问题）

**判据**：最后 5 段的均分比前 5 段低 ≥3 分，且中途没有回升。

**后果**：章末泄劲。读者读到末尾时动力最低，钩子接不住。

**常见成因**：作者把高潮放在中段，后面都是收尾。

### 形状三：一条直线（问题）

**判据**：全章三项分的标准差 ≤1.5。

**后果**：没有起伏。读者不会累，但也不会被抓住。

**注意**：低分直线（全程 4 分）比高分直线（全程 7 分）更糟——低分直线读者会跳，高分直线读者会麻木。

### 形状四：锯齿过多（问题）

**判据**：全章出现 ≥5 次「相邻段分差 ≥4」的跳变，且方向交替。

**后果**：读者麻木。真正的高潮来时没有对比，反而不响。

**修法方向**：保留 2–3 个真正的峰，把其余降下来。

### 形状五：前高后平 + 章末陡升（可接受）

**判据**：前 1/3 均分 ≥7，中段均分 4–5，最后 2 段 ≥8。

**评价**：这是「前置高潮 + 章末钩子」的常见结构。中段平是可以的，但要控制中段长度（≤全章 40%）。

## 峰值该不该是最高点

SKILL 要求「判断它是否该是本章该有的最高点」。判据：

| 章型 | 峰值应该出现在 | 出现在别处说明 |
|---|---|---|
| 动作章 | 后 1/3 | 出现在中段 → 后段泄劲 |
| 反转章 | 后 1/4（反转那一下） | 出现在开头 → 读者已经知道答案，后面没必要读 |
| 关系章 | 中段（情绪最高点）+ 章末（钩子） | 只有中段峰 → 章末没接住 |
| 过渡章 | 不需要峰，但需要两个小高点 | 有单一大峰 → 过渡章写重了，该拆 |
| 揭秘章 | 末段 | 出现在中段 → 秘密提前泄了 |

## 报告填写要点

```
【曲线表】（节选 6 段示意）
  段  | 好奇 | 紧张 | 情绪 | 发生了什么
  1   |  6   |  3   |  3   | 他蹲在井台边缠绳，绳短了一截
  2   |  7   |  4   |  4   | 院主出来，说院里只住他一个
  ...
  14  |  4   |  3   |  3   | 他洗脸，想起三天前的事        ← 平坦
  15  |  4   |  3   |  2   | 环境描写（墙、井、风）        ← 平坦
  16  |  3   |  4   |  3   | 他坐下，重复了一遍已知的伤情    ← 平坦
【平坦段】第 14/15/16 段（4,3,3｜4,3,2｜3,4,3）
【塌陷区】第 14–16 段（连续 3 段）→ 620 字
【曲线形状】前高后平+中段塌陷 → 中段 620 字会跳读
【峰值】第 9 段（好奇 9 紧张 7 情绪 8）— 是本章该有的最高点（悬念揭示）
【断裂点】第 13 → 14 段（从 7 掉到 4）— 原因：揭示之后直接接了一段独处
```

## 一个反直觉的结论

**中段的平坦比开头的平坦更致命。**

开头的平坦（1–3 段）读者还在适应，容忍度高，而且开头往往承担建立空间的功能，低分是合理的。

中段的平坦（30%–70% 位置）读者已经投入，正在等回报——这时候平，读者的失望是**有期待作背景的**，落差最大。

所以打分后，中段平坦段的权重应该是开头平坦段的 2 倍。同样的 500 字平坦，在中段就该报高风险。
