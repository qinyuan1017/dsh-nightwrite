# 语气词的提取

SKILL.md 给了三项语气特征，但**三项都是定性描述**，写进风格卡后写手无法执行。这份给每项的量化口径，以及「语气词」这项最容易被做成形容词清单的坑。

---

## 一、叙述温度：怎么量

「冷/中/热」的判据不是「心理描写多不多」，是**叙述者替读者解释了多少**。

### 量化方法：三率法

抽 100 个叙述句（不含对白），统计三个比率：

| 率 | 定义 | 例 |
|---|---|---|
| **动作率** | 只含动作/状态，不含心理与评判 | 「他把刀放在桌上。」 |
| **心理率** | 含心理活动（显式或自由间接） | 「他不想说话。」 |
| **评判率** | 叙述者对事件/人物作评价 | 「这是个愚蠢的决定。」 |

判档：

| 动作率 | 心理率 | 评判率 | 温度 |
|---|---|---|---|
| ≥70% | ≤25% | ≤5% | 冷 |
| 45–70% | 25–50% | ≤10% | 中偏冷 |
| 30–45% | 40–60% | ≤10% | 中 |
| 20–30% | 55–75% | ≤10% | 中偏热 |
| 任意 | 任意 | >10% | 热（且需检查是不是 AI 味） |

**关键判据：评判率 >10% 就是热，且是病态的热。** 因为评判是叙述者在替读者下结论，属于 `nightwrite-de-ai-style` 的「意义膨胀」信号。正常的「热」靠心理率，不靠评判率。

### 判定实例

```
冷：「他站起来。桌上还有半碗粥，凉了。他看了三秒，把碗扣在桌上，走了。」
  动作 3 句，心理 0 句，评判 0 句 → 冷

中：「他站起来，觉得胃里空得发疼。桌上还有半碗粥，凉了。他看了三秒，还是走了。」
  动作 2 句，心理 1 句（觉得胃里空得发疼）→ 中偏冷

热：「他站起来。他知道自己不能再待下去了，这个家已经没有他的位置。他看了一眼那半碗凉粥，心里涌起一阵酸楚，终于转身走了。」
  动作 2 句，心理 2 句（他知道/心里涌起），评判 1 句（这个家已经没有他的位置）→ 热，且评判率高
```

## 二、信息给法：怎么量

三档：直给 / 藏一半 / 全靠对话挤出。

### 量化方法：信息释放延迟

对本章的**每一个关键信息**，量「它被读者知道的那一刻」与「它第一次被提及的那一刻」的距离。

```
延迟 = 首次揭示段号 − 首次相关段号
```

| 平均延迟 | 给法 |
|---|---|
| 0（同段揭示） | 直给 |
| 1–3 段 | 藏一半 |
| ≥4 段，或靠对白揭示 | 全靠对话挤出 |

### 三种给法的判据与代价

| 给法 | 判据 | 优点 | 代价 |
|---|---|---|---|
| **直给** | 信息在同一段被说清 | 清楚，不困惑 | 无悬念，读者被动 |
| **藏一半** | 给出部分，留一个具体缺口 | 有钩子，读者主动 | 缺口太多会变困惑 |
| **对话挤出** | 信息只在人物说话时透露 | 自然，有性格 | 效率低，且容易变成「采访稿」 |

**判据：对话挤出的比例 = 靠对白揭示的关键信息数 ÷ 关键信息总数。**

| 比例 | 判定 |
|---|---|
| <20% | 直给为主 |
| 20–50% | 混合（最健康） |
| 50–80% | 对话为主，需检查有没有「采访稿」病 |
| >80% | 几乎全靠说，叙述失去功能 |

### 与 `nightwrite-de-ai-style` 的交叉

「全靠对话挤出」如果用得不好，就是「对白说明文」病（`ai-signals-22` 第 18 类）。判据：**对白里有没有人物在解释他已经知道的事**。有 = 病。

## 三、标点习惯：怎么量

这一项最容易被写成「喜欢用破折号」这种无用描述。必须给频率。

### 四项标点指标（每千字）

| 指标 | 算法 | 参照 |
|---|---|---|
| 破折号频率 | 破折号数 ÷ 千字 | 0–2 正常；>4 表示大量插入/打断 |
| 省略号频率 | 省略号数 ÷ 千字 | 0–3 正常；>5 表示犹豫/留白过多 |
| 问号频率（非对白内） | 叙述中的问号 ÷ 千字 | >2 = 自由间接引语多，或作者在自问 |
| 感叹号频率 | 感叹号数 ÷ 千字 | >3 = 情绪外露（AI 味信号） |

### 独特标点用法（这一项才是「风格」）

除了频率，还要记**用法**：

| 用法 | 判据 | 例 |
|---|---|---|
| 短句单独成段做停顿 | 单句成段的比例 | 见下 |
| 破折号做补充而非打断 | 「他走了——带着那把刀。」 | 补充型 |
| 省略号做未完而非犹豫 | 「你要是敢……」 | 未完型 |
| 无标点长串 | 连续 ≥3 个短句用逗号连接 | 急促型 |

**单句成段率**：
```
单句成段率 = 只含 1 句的段数 ÷ 总段数
```

| 率 | 判定 |
|---|---|
| <5% | 不用这个手法 |
| 5–15% | 克制使用（节奏工具） |
| 15–30% | 高频使用（明显风格） |
| >30% | 滥用，读起来像诗 |

## 四、语气词：真正的提取对象

「语气词」不是指「的了吗呢」，而是**这个作者特有的语言指纹**。分四类提取：

### 类 1：口头禅/句式模子

反复出现的句式。判据：**出现 ≥3 次且形态相同**。

- 「说起来，……」开头
- 「……也就是了。」结尾
- 「不是……，是……」对举
- 「偏生……」「倒是……」

**提取方法**：对样本做 4 字串频次统计，取出现 ≥3 次的、不是成语的串。人工筛出有语法功能的。

### 类 2：称代习惯

| 项 | 选项 |
|---|---|
| 第三人称代词 | 他/她/其/对方/此人 |
| 敬称 | 您/你/先生/大人/直呼名 |
| 自称 | 我/咱/在下/晚辈/老子 |
| 群体指代 | 众人/大家/一群人/那些人 |

**判据**：同一个指代对象在全书用同一个词 ≥80% = 稳定习惯；<60% = 混乱，需要统一。

### 类 3：连接词偏好

- 承接：于是/然后/接着/随后/便/就
- 转折：但/却/然而/只是/偏
- 因果：因为/所以/故/因此/于是

**「然后/接着/随后」的频率 >3 次/千字 = 然后体**（`nightwrite-write-chapter` 的 M11 项）。这是必须记进风格卡的负面清单。

### 类 4：虚实词的密度

| 词类 | 判据 | 风格含义 |
|---|---|---|
| 「的」频率 | 每百字 | 高 = 定语长、书面；低 = 口语、动作 |
| 「了」频率 | 每百字 | 高 = 完成态多、事件密集 |
| 「着」频率 | 每百字 | 高 = 持续态多、画面停留 |
| 「被」频率 | 每千字 | 高 = 被动多，人物缺主动性 |

**「被」频率 >8 次/千字**是一个值得记进风格卡的红旗：它意味着主角一直在承受而非行动。

## 五、语气特征的三项怎么写进风格卡

### 温度

```
【温度】中偏冷
  依据：抽 100 句，动作率 52%｜心理率 41%｜评判率 7%
  规则：评判率不得超过 10%；心理描写必须挂在具体动作上，不许独立成段
```

### 信息给法

```
【信息给法】藏一半
  依据：关键信息 18 项，平均延迟 2.1 段；靠对白揭示 6 项（33%）
  规则：每个关键信息必须有一个「第一次被提及」的段，且与揭示段隔 1–3 段
  禁：同一段内既提及又揭示（那是直给）
```

### 标点

```
【标点】省略号克制、破折号用于补充
  依据：破折号 1.2/千字｜省略号 0.8/千字｜感叹号 0.4/千字｜单句成段率 11%
  规则：感叹号 ≤1/千字；单句成段只用于场景转折或收束
  禁：连续 3 段单句成段（那是滥用）
```

## 六、五个不能写进风格卡的形容词

以下词一律不许出现在语气特征里：

| 禁词 | 为什么 | 替成 |
|---|---|---|
| 凝练 | 无法判定 | 平均句长 n 字，短句 n% |
| 大气 | 无法判定 | 场景平均字数 n，单场 ≤n 人 |
| 有张力 | 无法判定 | 每千字推进点 n 个 |
| 克制 | 无法判定 | 评判率 n%，感叹号 n/千字 |
| 细腻 | 无法判定 | 心理率 n%，比喻 n 处/千字 |

**判据：一条规则能不能直接用来判一句话合不合格？** 不能 = 形容词，重写。

## 七、提取工序

1. 抽 3–5 章，切分成句。
2. 随机抽 100 个叙述句，做三率标注（动作/心理/评判）。
3. 列出本章关键信息清单（≥10 项），逐项标「首次提及段」与「揭示段」。
4. 统计四项标点频率 + 单句成段率。
5. 做 4 字串频次统计，人工筛出口头禅。
6. 统计四类称代与四类连接词的分布。
7. 每项都写成「依据（数字）+ 规则（可否判定）」两行。
8. 落盘到 `ledger.upsert` 的 `highlights` 风格卡条目。

**第 7 步是最容易偷懒的**：只写依据不写规则，风格卡就成了分析报告，写手拿不去用。
