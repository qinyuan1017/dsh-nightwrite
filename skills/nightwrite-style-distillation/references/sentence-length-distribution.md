# 句长分布的统计方法

SKILL.md 给了算法（总字数 ÷ 句数、≤8 字句数 ÷ 总句数）。这份补切句口径、字数口径、参照带、以及**为什么不能只看均值**（同样的均值 14 字，可以是「均匀 14 字」也可以是「一半 6 字一半 22 字」，读起来完全不同）。

---

## 一、字数口径（必须先固定）

| 项 | 口径 |
|---|---|
| 计什么 | 汉字、数字、拉丁字母（连续字母算 1 个词） |
| 不计什么 | 标点、空白、换行、Markdown 标记、章节标题 |
| 专名 | 按字数算（「阿禾」= 2 字） |
| 数字 | 「三百斤」= 3 字；「300 斤」= 4 字（3、0、0、斤）；建议统一写成汉字 |
| 引号 | 不算；引号内的内容算 |

**统一口径的原因**：不同口径下平均句长能差 15% 以上，跨章比较会失真。**同一本书的所有统计必须用同一口径。**

---

## 二、切句：何时断

### 主规则

按 `。！？…` 切。连续标点（`？！」`）算一个断点，不重复计。

### 补规则 1：分号不断

`；` 不是断句。中文小说里分号多在长复句内，断了会把一句拆成两句，短句占比虚高。

### 补规则 2：逗号断句测试

一个「逗号 + 分句」要不要单独成句，用**补主语测试**：

> 把逗号换成句号，下一个分句能不能补出主语？能 → 可断；不能 → 不断。

**例**：
> 「他站起来，走到门口，站住了。」
> → 「他站起来。走到门口。」——「走到门口」没有主语但主语可继承（他）。**这是并列谓语，不断。**

> 「他站起来，门外的雨还没停。」
> → 「他站起来。门外的雨还没停。」——后句有自己的主语。**这是两句。**

### 补规则 3：破折号与冒号

- 破折号后如果要补主语 → 断
- 冒号后的内容算同一句（是解释，不是新句）

### 补规则 4：对白

`「……」他说。` 算**一句**（引号内 + 说明语共 1 句），不拆。

但 `「……」` 独立成段、无语说明语时，算 1 句。

### 补规则 5：省略号

`…` 结尾算断句（它承担停顿功能）。`……` 同理算一个断点。

## 三、四项指标与参照带

### 1. 平均句长

```
平均句长 = 总字数 ÷ 句数
```

| 区间 | 判定 | 读者体感 |
|---|---|---|
| <10 字 | 极碎 | 快、喘、适合动作/紧张 |
| 10–14 字 | 偏碎 | 现代网文主流，适合移动端 |
| 14–20 字 | 标准 | 传统出版/文学性稍强 |
| 20–26 字 | 偏长 | 舒缓，适合心理/描写 |
| >26 字 | 过长 | 读者会断气，需要拆 |

**判据：单章平均句长与全书均值的偏差 >30% = 这一章节奏失控**（通常是赶稿或堆描写）。

### 2. 短句占比（句长 ≤8 字）

| 占比 | 判定 |
|---|---|
| <8% | 太疏，读者找不到停顿点 |
| 8–20% | 偏疏（叙述型） |
| 20–35% | 正常 |
| 35–50% | 偏碎（动作/紧张型） |
| >50% | 太碎，像分镜脚本，情绪展不开 |

**注意**：短句占比 >50% 时，读者会觉得「作者在用力」。**这是 AI 味的典型症状之一**（`nightwrite-de-ai-style` 的「均匀节奏」信号）。

### 3. 平均段长

```
平均段长 = 总字数 ÷ 段数
```

| 区间 | 判定 |
|---|---|
| <40 字 | 极碎，移动端友好但显得跳 |
| 40–90 字 | 移动端主流 |
| 90–160 字 | 标准 |
| 160–250 字 | 偏长，PC 阅读友好 |
| >250 字 | 过长，移动端会出现「一屏全是字」 |

**段数的口径**：一个换行分隔的文本块算 1 段。对白独立成段也算 1 段（这会拉低平均段长，是正常的）。

### 4. 对白占比

```
对白占比 = 引号内字数 ÷ 总字数
```

| 区间 | 判定 |
|---|---|
| <10% | 叙述主导（适合心理/环境/史诗） |
| 10–25% | 均衡偏叙述 |
| 25–45% | 均衡（网文主流） |
| 45–60% | 对白主导（适合交锋/日常） |
| >60% | 像剧本，缺乏场景支撑 |

**口径**：只算 `「」`、`""`、`“”` 内的字。说明语（他说/她问）不算对白。

## 四、为什么要看分布，不能只看均值

同样平均 14 字，两种分布：

**均匀型**：
```
14 15 13 14 14 15 13 14
```
→ 读起来**平**，没有节奏变化。这是 AI 最典型的句长分布。

**双峰型**：
```
6 7 22 24 5 6 25 21
```
→ 读起来**有呼吸**：短句推进，长句铺展。

### 分布的两个量化指标

**指标 A：句长标准差**

```
σ = √( Σ(xi − mean)² ÷ n )
```

| σ | 判定 |
|---|---|
| <5 | 太均匀（AI 味信号） |
| 5–9 | 正常 |
| 9–14 | 起伏大（有风格） |
| >14 | 忽长忽短，可能失控 |

**指标 B：长短交替率**

相邻两句一长一短（≥1.8 倍差）的比例：

```
交替率 = 满足 |xi − xi−1| ÷ min(xi, xi−1) ≥ 0.8 的对数 ÷ 总对数
```

| 交替率 | 判定 |
|---|---|
| <15% | 平铺（无节奏） |
| 15–35% | 正常 |
| 35–55% | 节奏感强 |
| >55% | 抖动，读者会觉得晃 |

**这两个指标必须一起报**。只报均值等于没量。

## 五、分场景统计

一本书里不同场景的句长差异很大，**必须分场景量**，否则均值会掩盖问题。

| 场景类型 | 平均句长参照 | 短句占比参照 |
|---|---|---|
| 动作/打斗 | 8–13 字 | 40–60% |
| 对话交锋 | 10–16 字 | 25–40% |
| 心理/回忆 | 16–24 字 | 10–20% |
| 环境/氛围 | 18–26 字 | 8–18% |
| 说明/交代 | 14–20 字 | 15–25% |

**判据：某场景的指标落在参照带外 ≥2 档 = 这个场景的写法与全书不一致**，要么统一，要么明确声明「这是刻意的变化」。

## 七、三个统计污染

### 污染 1：把标题算进字数

标题往往短，会拉低平均句长。**必须剔除。**

### 污染 2：把「作者有话说」算进样本

部分平台文末有作者话，句长和正文完全不同。**必须剔除。**

### 污染 3：混用不同章的字数口径

有的章用「含标点」统计，有的用「不含标点」。**统一成不含标点。**

---

## 八、样本量要求

- **<3000 字不出结论**（波动太大）
- **3000–8000 字**：只报数字，不下「这就是他的风格」的结论
- **≥8000 字**：可下结论
- **≥20000 字**：可分场景下结论

SKILL.md 要求 ≥8000 字。**低于这个数，报告里所有结论必须带「样本不足」标注。**
