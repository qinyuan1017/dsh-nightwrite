# 场景切换的三种写法

> 适用：一章里要换时间、换地点、换在场人物时读这份；判「转场生不生硬」。

场景切换是**唯一允许「骗」读者的地方**，也是新手最容易写成「然后他们就到了」的地方。

三种写法各有明确的适用场合，选错就会生硬。判据是**两个场景之间的时间间隔**和**读者的注意力状态**。

---

## 一、硬切（Hard Cut）

**定义**：不加任何过渡，直接换段进入新场景。用一个空行或场景分隔符（`***`）标记。

**结构**：上一个场景停在一个未闭合的点 → 空行 → 新场景第一句直接给动作。

**适用**：
- 两个场景是**同时或紧接着**发生的（零间隔到几分钟）。
- 上一个场景末尾有强钩子，读者注意力正高。
- 快节奏章。

**正例**：
> 他把刀架在老人颈上。
>
> ※
>
> 院门被人从外面踹开了。

第一场景停在「架上」，第二场景直接给外部打断。零过渡，节奏最猛。

**反例**：
> 他把刀架在老人颈上。就在这时，他们听到院门被人从外面踹开了，原来是追兵到了。

把两个场景塞进一段，还用「就在这时」「原来」两个过渡词把冲击力全磨掉了。

**判法**：硬切后，新场景第一句必须**有动作或声音**。第一句是环境描写（「院子里月光很白」）就会泄气。

**字数要求**：两个场景各自 ≥150 字。短于 150 字的场景不该独立成场，应合并进相邻场景。

---

## 二、锚点过渡（Anchored Transition）

**定义**：用一句**包含时间或空间锚点**的句子衔接两个场景。

**结构**：上一场景结束 → 一句锚点句 → 新场景。

**锚点句的三种形态**：

### 2a. 时间锚
> 他等到三更。
>
> 三更，门开了。

**判法**：时间锚必须给出**具体量**（三更、第二天晌午、七天后），不许写「过了一会儿」「不久之后」。模糊时间锚等于没锚，读者会失去时间感，这是时间线崩坏的起点（见 `changye-continuity-pass` 的时间线维度）。

### 2b. 空间锚
> 他把信塞进怀里，出了巷子。
>
> 巷口那家酒铺已经收摊了，只剩一盏灯。

**判法**：空间锚必须让读者能画出两点之间的关系（巷子里→巷口）。不许写「他来到了另一个地方」。

### 2c. 状态锚
> 他数到第四百二十七下，睡着了。
>
> 醒来的时候，绳子已经松了。

**判法**：状态锚最适合「时间跨度不明但状态变了」的情形。它同时完成时间跳跃和状态交代，效率最高。

**适用**：两个场景间隔几分钟到几天，且**间隔期间没有大事发生**。

**反例**：
> 他把信塞进怀里。过了一会儿，他到了城西。

「过了一会儿」+「到了城西」两个都模糊。这是最典型的生硬转场。

---

## 三、镜头拉远（Pull Back）

**定义**：把视角从人物身上拉到环境/群像/时间之上，用一段全景描写完成转场，然后再落回人物。

**结构**：人物特写 → 拉远（城、夜、人群）→ 落回（另一个人物或同一人物的新时刻）

**适用**：
- 场景切换幅度大（换城、换季节、换阵营）。
- 一章的**开头**（用拉远建立空间，再进人物）。
- 卷末、章末的收束。
- 慢节奏、氛围章。

**正例**：
> 他把碗里的最后一口汤喝完，把碗推回去。
>
> 这座城有三万户人家，今夜有二百一十七户在办丧事。更鼓敲过三下，守城的兵在城楼上换了班，新来的那个打了个哈欠。城西的火烧到天亮才灭，烧掉了半条街。
>
> 天亮的时候，他在城西的灰里找到一只铜镯子。

**判法**：拉远段必须**携带信息**（三万户、二百一十七户、半条街），不能只是「夜色深沉，万籁俱寂」。纯抒情拉远是 AI 信号第 11 类（意义膨胀）的变体。

**长度限制**：拉远段 **≤300 字**。超过就是脱离人物太久，读者会开始跳读。

**频率限制**：单章 ≤1 次。一章用两次拉远，节奏会散。

## 四、三种写法的选择决策树

```
两个场景的时间间隔是多少？
├─ 0（同一时刻/紧接） → 硬切
├─ 几分钟到几小时
│   ├─ 间隙无大事 → 锚点过渡（时间锚）
│   └─ 间隙有大事但不能写 → 硬切 + 后文补述
├─ 一天到几天
│   ├─ 是章内转场 → 锚点过渡（状态锚优先）
│   └─ 是章与章之间 → 不需要转场（章首直接开始）
└─ 跨度大（换城/换季/换阵营） → 镜头拉远，或分章
```

**关键规则**：**跨章不需要转场**。上一章末尾和下一章开头之间的时间，由下一章第一段的时间锚点交代即可，不要在上一章末尾写「三天后……」——那会把钩子毁掉。

## 五、五种必须避免的转场

| 病型 | 例 | 为什么错 |
|---|---|---|
| 然后体 | 「然后他就回家了。」 | 零信息，且「然后」是 AI 味高频词 |
| 蒙太奇清单 | 「他先去了东市，又去了西市，最后去了衙门。」 | 三个场景全压成一句，读者什么都没看见 |
| 万能过渡 | 「时间飞逝，转眼间……」 | 无锚点，时间线从此不可考 |
| 天气过渡 | 「第二天，天气晴朗。」 | 用天气顶替转场，是 AI 信号第 16 类 |
| 自问自答 | 「那么，这三天里他做了什么？他……」 | 说书人腔，破坏视角 |

## 六、转场后的第一句怎么写

这是全套里最实操的一条。**转场后的第一句必须是以下四种之一**：

1. **一个动作**：「他把门推开。」
2. **一句对白**：「"你迟了。"」
3. **一个声音**：「外面有人在砸门。」
4. **一个具体数字或时间**：「第三天，粮价涨到了一斗三百文。」

**不许是**：环境描写、心理活动、抽象判断、人物介绍。

原因：读者刚被切断，需要立刻抓住一个**具体的钩子**。四种开法都给了抓手，四种禁法都要求读者自己重建空间——重建失败就掉读。

---

## 七、场景切换密度

```
转场密度 = 场景数 ÷ 正文字数 × 1000
```

| 密度 | 判读 |
|---|---|
| <0.6 | 场景太少，一章只有一个场景，容易闷 |
| 0.6–1.2 | 正常 |
| 1.2–2.0 | 偏碎，每个场景都浅 |
| >2.0 | 蒙太奇化，读者抓不住 |

单章场景数上限 5（对应 `pre-writing-checklist.md` D2）。
