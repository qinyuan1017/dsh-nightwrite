# 交稿前的自检表

> 适用：正文写完、调 `chapter.save` 之前读这份；对应 SKILL.md 第 5 步与回执六段。

这张表是**交稿闸**。任何一项不过，不许 `chapter.save`。共 24 项，按「硬否决 / 需修正 / 建议」三级标注。

---

## 第一级：硬否决（6 项，一项不过就不许交）

### H1. 细纲三件事是否全部落地

对照 `outline.intent` 的 `summary` 三点，逐点指出落在第几段。

- 三件全有落点 → 过
- 有一件没落地 → **不许交**。要么补写，要么走「破格申请」并说明为什么做不了。

不允许「我打算下章补」——细纲说这一回发生，就必须这一回发生。

### H2. 顺序是否被调整

细纲没定序时允许自定，定了序就不许换。检查方法：抽出三件事的落点段号，看是否单调递增。

### H3. 章末 150 字内是否有 `hook`

`hook` 必须落地在最后 150 字内。检查：

- 最后一句是否属「新信息 / 急追问 / 动作悬停」三类之一
- 是否出现了总结、预告、抒情收尾、「欲知后事如何」

**出现后四者任一 → 不许交。**

### H4. 是否新增了 `ledger` 里没有的东西

逐项查：新角色、新势力、新能力、新专名。

- 有 → 撤掉，或走「破格申请」
- 专名的**别称**也算新增（见 `terms` 的唯一写法要求）

### H5. 是否有明文设定的冲突

本章用到的每条能力、每个专名、每个人物的状态，是否与 `ledger` 明文冲突。

有冲突的，**不许交**。不是「交上去让审校发现」——交稿岗自己要先过这一关。

### H6. 字数是否在 ±15% 内

```
允许区间 = 单回目标字数 × [0.85, 1.15]
```

超上界：说明这章内容偏多，考虑拆章（但拆章要走细纲变更，不许自己拆）。
超下界：说明没写够，回去补推进点。

## 第二级：需修正（11 项，改完再交）

### M1. 连续 1500 字无推进

按 `paragraph-progression.md` 的逐段标注法打标签。任何 1500 字的窗口内标签无变化 → 该段注水，压缩或补推进。

（`pacing` 为快节奏时，阈值收紧到 1000 字。）

### M2. 段落推进标签有「标不上」的段

归不到动作/信息/关系/状态四类的段 → 删或合并。

### M3. 连续 4 段同标签

结构单调。至少打断一处（把某段砍成一句，或把某两段合并）。

### M4. 短句占比不在 8%–45%

低于 8%：节奏太齐。高于 45%：读起来像提纲。

### M5. 平均段长 >250 字或 <40 字

>250：手机一屏看不完。拆段。
<40：整章像诗。合并。

### M6. 对白占比偏离本章章型目标 >15 个百分点

照 `dialogue-narration-ratio.md` 的章型表对。偏离要能说出理由。

### M7. 微动作单章同一项 ≥3 次

照 `changye-de-ai-style/references/micro-action-repetition.md` 统计。超标的替换成人物专属反应或不写反应。

### M8. 段末解释链 ≥3 处

照 `changye-de-ai-style/references/explanation-chain-density.md` 的段末法扫。逐段删。

### M9. 出场但零动作零台词的人物

有 → 给一个动作，或让他不在场。

### M10. 上一回钩子未处理

本章开头的三段内，必须兑现或明确延后上一回的 `hook`。没处理 → 补。

### M11. 场景切换有「然后体/万能过渡」

出现「然后」「过了一会儿」「时间飞逝」「转眼间」作为转场 → 按 `scene-transitions.md` 换成三种正规写法之一。

## 第三级：建议（7 项，记进「存疑点」不必当场改）

### S1. 某段自己也不确定对不对

写进回执的「存疑点」，交审校。**不要在交稿前反复改到没时间**。

### S2. 某个配角的口吻拿不准

写进存疑点，指明是哪一段。

### S3. 某个专名可能和 `terms` 有细微差异

写进存疑点。**不许自己改 `terms`**——那是账本岗的权限。

### S4. 时间跨度算不清

写进存疑点，交 `changye-continuity-pass` 的时间线维度。

### S5. 本章用到某个 `rules` 的边界情形

写进存疑点。**不许自己放宽 rules**。

### S6. 有想加但被细纲挡住的内容

写进「破格申请」，格式：`细纲第 X 点做不了，因为…，建议改成…`。

### S7. 觉得这一章的某处「更带感」

写进存疑点。**不许以「更带感」为由偏离细纲**（SKILL.md 禁止事项）。

## 回执六段的填写要点

### 【回目】

`第 N 回 <标题>｜字数 <n>（目标 <n>，差 <±n>）`

标题必须与 `outline` 的 `title` 一致。不一致要说明（一般是细纲太短，写作时补了字）。

### 【细纲执行】

三点逐条，格式：`① <细纲点> → 已写：<落在第几段，一句话>`

**必须给段号**。「已写」不带段号的等于没写。

### 【章末钩子】

引用最后两句**原句**。不许改写、不许概括。

如果最后两句里没有 `hook`（H3 不过），这里就会暴露——所以这一段其实是自检的一部分。

### 【自补细节】

列清哪些是细纲没有、你补的：配角动作、环境、过场。**这些是允许的**，但必须申报。

不允许申报的类型：新角色、新能力、新专名、新的因果链。那些是 H4 的范围。

### 【存疑点】

S1–S7 的落点。没有就写「无」。

**必须写「无」而不是省略**——省略会让审校以为漏查（与 `changye-continuity-pass` 的 `【致命】` 段同规则）。

### 【破格申请】

没有写「无」。有则给「细纲第 X 点 + 做不了的原因 + 建议改法」。

## 交稿后的动作

`chapter.save` 之后：

1. **停手。不许连着写下一章。**（SKILL.md 禁止事项）
2. 等审校（`changye-continuity-pass`）与读者报告（`changye-reader-report`）。
3. 它们的结论决定这章是否需要 `changye-revision-pass`。
