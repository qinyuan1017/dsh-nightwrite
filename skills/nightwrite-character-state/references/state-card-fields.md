> 适用：要给一个角色建状态卡、或者状态卡字段被写成性格描述（「他现在很痛苦」）时读这份。

# 状态卡五项字段的填法

状态卡记的是**可验证的当前事实**，不是人物评价。判据只有一条：这条记录能不能被下一章的一句正文直接违反？能违反 → 是状态；只是「读起来像」→ 是评价，删掉。

## 一句话判据

| 写法 | 是否合格 | 原因 |
|---|---|---|
| `左臂骨折未愈，不能提重物` | 合格 | 下一章他提重物就是明文违反 |
| `他现在很痛苦` | 不合格 | 「痛苦」无法被违反——他一边痛苦一边笑，读者也不觉得矛盾 |
| `知道沈砚是女子` | 合格 | 他若说「沈兄」，读者立刻发现矛盾 |
| `性格多疑` | 不合格 | 那是人物底色，归 `nightwrite-character-arc` |
| `持有：半枚虎符（缺右半）` | 合格 | 他若拿出完整虎符，立刻穿帮 |
| `对李婶有戒心` | 合格（带程度） | 见下文「关系的量化」 |

**转换公式**：把任何一句评价改写成「一个可观察的限制」——

- 痛苦 → `过去七天每晚惊醒，白天不能集中注意力（写不出字、听漏话）`
- 多疑 → `任何人递东西给他，他不接，先让人自己吃一口`
- 忠诚 → `被问到主子时，他会先看门外有没有人`

## 字段一：已知

**记什么**：他在**当前时点**知道的关键信息，逐条列，每条带来源。

**格式（必须带来源）**：

```
已知：
  · 沈砚是女子（第 12 回，看见她换药）
  · 族叔手上有旧案卷宗（第 20 回，族叔亲口说）
  · 粮价三日后要涨（第 24 回，听米铺伙计说）
```

**计数口径**：

- 只记**会影响判断或对话**的信息，不记「他知道城南有家面馆」
- 每条必须能回答「他怎么知道的」。答不出来 → 这条是作者偷渡进去的，删掉
- 条数按角色重要度控制：主角 15–40 条，主要配角 8–20 条，次要角色 3–8 条

**超过 40 条的处置**：不是删，是**分组**——按「与谁相关」分组（与沈砚相关 / 与旧案相关 / 与户籍相关）。分组后仍然 40 条以上，说明这个角色吸收了太多信息，考虑把一部分转移给另一个在场角色（这在叙事上也更真）。

**三种不能进「已知」的东西**：

1. 读者的推测（作者没写出来，角色不可能知道）
2. 作者以为「显然能推出来」的结论——推理性信息必须有一次**明确的推理场景**才算知道
3. 别的角色知道但没告诉他的事。**这一条最常犯**：写对话时顺手让 A 说出只有 B 知道的事，就是从这里漏的

**「部分知道」的记法**：`知道有人改了官凭（不知是谁）`。半条信息必须标注括号，否则后面写的时候会默认他知道全部。

## 字段二：持有

**记什么**：能被夺走、能被使用、能被看见的具体物件。

**必须记的六类**：

| 类别 | 例子 | 为什么必须记 |
|---|---|---|
| 凭证 | 路引、官凭、婚书、腰牌 | 决定他能不能过关、能不能办成事 |
| 钱 | 具体数额 + 币种 | 决定他能买什么；数额模糊会导致后面「他怎么忽然有钱」 |
| 兵器/工具 | 刀（缺口）、绳、火折 | 决定他能打什么、能做什么 |
| 信物 | 半枚虎符、一枚旧簪 | 通常是伏笔载体，丢了要记账 |
| 药/伤药 | 金疮药两包 | 决定伤能不能好；有药无药差别巨大 |
| 他人的东西 | 替人保管的信 | 最容易漏，也最容易变成矛盾点 |

**格式**：

```
持有：
  · 路引一张（姓名「沈砚」，籍贯被涂改过）
  · 铜钱四十七文
  · 短刀一把，刃口有缺
  · 替李婶保管的信一封（未拆）
```

**三条规则**：

1. **钱必须给数字**。写「一些钱」→ 后面所有涉及买卖的段落都无法判定。给一个数字，并记录每次大额支出。
2. **失去要记减项**。丢掉的东西不减，后面写「他摸出那把缺口的刀」就是矛盾。
3. **消耗品要记余量**。金疮药、火折、干粮，用了就减。数量降到 0 时，下一章不能凭空再用。

## 字段三：关系

**记什么**：对每个**有戏份的人**的当前态度 + 信任度 + 一个可观察的行为表现。

**量化方式**：不要用「好/坏」，用三档 + 一个行为：

| 档 | 含义 | 可观察行为 |
|---|---|---|
| 信 | 会把后背交给他 | 主动告知一个秘密，或把武器交给他保管 |
| 疑 | 会合作但不交底 | 说话留一半，或让别人先试 |
| 敌 | 不会主动接触 | 见面就问「你来做什么」 |

**格式**：

```
关系：
  · 沈砚：疑（第 18 回起）— 会替她挡一次，但不肯说自己的真名
  · 李婶：信 — 把信交给她保管
  · 族叔：敌 — 见面必先看对方手上有没有东西
```

**必须记「变化点」**：每个档位变化都要带章号 + 触发事件。没有变化点 = 无法判定这个关系是什么时候变的，后面重读会以为一直是这样。

**关系的方向性**：A 对 B 和 B 对 A 是两条记录，不许共用一条。单向信任是常态（他信她，她防他），写成双向会抹掉大量戏。

**关系的粒度**：只记**有戏份的人**。全书 20 个角色，每个角色记 15 条关系 = 300 条，多数永远用不上。规则：只记与该角色**同场 ≥2 次**或**有直接利益冲突**的人。

## 字段四：损伤

**记什么**：三类，分开记，因为恢复速度完全不同。

### 身体伤

格式：`部位 + 具体伤情 + 对能力的限制 + 预计恢复`

```
· 左臂：刀伤，深及骨，不能提超过五斤的东西（约需二十日）
· 右肋：断骨两根，不能快跑，不能弓身（约需四十日）
```

**必须有「对能力的限制」**。只写「左臂受伤」→ 下一章他照样使刀，读者会挑出来。写了「不能提超过五斤」→ 他能拿筷子、能递东西，但不能举刀——这才是可执行的状态。

**伤情的时间账**：每次跨章都要按日推进。三章没提伤 = 伤已在恢复，不许忽然严重化（除非有新伤）。

### 心理创伤

格式：`触发条件 + 反应 + 持续时间`

```
· 见血会短暂失神（约十息），事后记不清那十息发生了什么
· 听见瓷器碎裂声会先找门
```

心理创伤必须**给触发条件**。只写「有创伤」→ 写的时候无从下手；给了触发条件，正文里就有具体的戏。

### 能力损耗

格式：`项目 + 当前水平 + 原因`

```
· 右手准头：十步内可中，十步外不稳（第 22 回伤了筋）
· 内力（若世界有）：不足三成，每日可行一次
```

## 字段五：位置

**记什么**：当前位置 + 到达时间 + 按什么方式到达。

```
位置：驿舍后院厢房（第 26 回夜，步行，自城东来，用时两个时辰）
```

**为什么必须带时间和方式**：

- 时间：下一章的时间线要接得上，交代「三天后」时才知道这三天他在哪
- 方式：决定他消耗了多少体力、是否被人看见、路上可能遇到谁

**位置的时间线作用**：把每个角色的位置记录按章号排开，就是一张**并发时间表**。两个角色在同一章的不同位置时，这张表能判定「他能不能在两章之间赶到」。

**位置的三条硬规则**：

1. 位置变化必须与时间线一致（步行日行约 30–40 里，快马日行约 100–150 里，具体按世界设定）
2. 有移动就必须记消耗（体力、盘缠、时间）
3. 移动途中没有记录 = 空白期，不许在空白期里塞入重大事件（那是矛盾来源）

## 更新时的三条纪律（对应 SKILL 第 3 步自查）

### 认知自查

把本章这个角色的**每一句台词**过一遍，每句问：这句话用到的信息，在「已知」里吗？

- 在 → 通过
- 不在，且这个角色是**说者** → 认知越界，必改
- 不在，但这句话是**提问或猜测** → 通过（不知道才问，这是对的）

**最隐蔽的越界**：不是说出秘密，是**说出正确的判断**。比如「你左臂有伤」——如果没人告诉过他，他是怎么看出来的？要么补一个观察细节，要么改成猜错。

### 伤情自查

本章他做的**每一个需要体力的动作**，逐项对照「损伤」：

- 动作需要的体力 ≤ 伤情允许 → 通过
- 超出 → 越界。三种修法：改成别人做 / 加代价（做完就倒下）/ 改伤情（说明已经恢复）

**最常漏的伤情**：不是打斗，是**长途赶路**。肋骨断了还骑马三天，是穿帮。

### 关系自查

本章他对每个人的**反应**，对照关系的当前档位：

- 单次反应超出档位，但有**明确的触发事件**在本章发生 → 通过（关系可以变，但要写变化的那一下）
- 超出但没有触发事件 → 越界，读者会觉得「他怎么忽然对她这么好」

## 变更点记录格式

每一条变更都必须带来源，格式统一：

```
已知 += 沈砚是女子（来自第 12 回：她在药铺后间换药，他从门缝看见）
持有 -= 短刀一把（来自第 19 回：当掉了换药钱）
关系 沈砚：敌 → 疑（来自第 18 回：她替他挡了一刀）
损伤 += 左臂刀伤（来自第 21 回：书办房后巷被砍）
位置 城东驿舍 → 城西米铺（第 26 回，步行，两个时辰）
```

**没有「来自第几回」的条目一律视为无效更新**，不许落盘。理由：三个月后回来改稿，没人知道这个状态从哪来，只能整段重建。

## 状态卡模板（可直接套）

```
角色：<名>  id=<…>  首次出场：第 <n> 回
已知：
  · <信息>（第 <n> 回，<怎么知道>）
持有：
  · <物件>（<状态/数量>）
关系：
  · <人名>：<信/疑/敌>（第 <n> 回起）— <可观察行为>
损伤：
  · <部位>：<伤情> → 不能 <动作>（约需 <n> 日）
位置：<地点>（第 <n> 回，<方式>，自 <出发地> 用时 <时长>）
最后更新：第 <n> 回
```
