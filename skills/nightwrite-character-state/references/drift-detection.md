> 适用：写到中后期发现某个角色「不像他了」「忽然会了不该会的东西」「性格被抹平了」时读这份，判断是漂移还是成长。

# 成长漂移的检测

漂移和成长的区别只有一条：**成长有可见的触发事件和代价，漂移没有**。

漂移是角色在没有任何事件推动的情况下，向着「更好用/更讨喜/更符合作者当下需要」的方向滑动。读者感觉得到，但说不清，最后说出来的是「人设崩了」。

## 五个漂移症状

按可检测性从高到低排。

### 症状一：能力漂移

他忽然会了一件从未学过、也没人教过的事，而且没人问。

**检测方法**：取他本章做的每一件需要技能的事，问「这个技能第一次出现在哪一回？」

- 能找到（首次出场就交代过 / 有学习场景 / 有人教）→ 通过
- 找不到，但本章有一次**明确的临场学会**（偷看、被指点、试错）→ 通过，但要记进状态卡
- 完全找不到 → 能力漂移

**典型形态**：
- 前期说是「不识字」的书办，后期开始读案卷
- 前期「不会水」的人，落水后自己游上来
- 前期「从没杀过人」的人，第一次杀人就干净利落且毫无反应（反应缺失也是漂移）

**修法三选一**：
1. 补一个学习场景（在漂移点之前，最短半章）
2. 改成失败（他不会，试了也不行——这比会了更有戏）
3. 改前文（把「不识字」改成「只认得几个字」）

### 症状二：道德漂移

他做了一件以他的底色不该做的事，且事后没有代价。

**四种方向**（都会发生，不都是坏）：
- 变好：自私的人开始牺牲
- 变坏：善良的人开始下狠手
- 变软：硬汉开始犹豫
- 变冷：热心人开始不管

**判定标准**：事后有没有**至少一处**表现代价（失眠、回避、被别人指出、行为习惯改变）？

- 有 → 是成长或堕落（正向变化）
- 无 → 道德漂移

正例：`他第一次亲手杀人，之后三章里他吃饭都只吃半碗，且不再坐靠门的位置。`

反例：`他杀了人，把刀擦干净，回去睡了。`（如果前 40 章他连鸡都没杀过，这就是漂移）

**最常犯的一类**：主角对敌人越来越狠，但作者从不写他的不适。这在爽文里可以接受，但**必须在前 3 次给代价**，第 4 次之后才可以省略——省略本身是「他已经习惯了」的证明。

### 症状三：口吻漂移

他说话的方式变了，包括句长、用词层级、称呼、禁忌词。

**检测方法**：从早期章节和当前章节各抽 10 句他的话，遮住名字，做三件事：

1. 平均句长差：超过 8 字 → 漂移（早期短促的变成长句缠绕，或反之）
2. 称呼差：对同一个人换了叫法且没有关系变化事件 → 漂移
3. 禁忌词命中：早期立的禁忌词在当前出现了 → 崩人设（这一条是无条件的）

**注意**：口吻漂移常常是**作者的疲劳造成的**。写了两百章之后，所有角色都向作者自己的自然语感收敛。这是最难自查的一类，必须靠抽样对照。

**修法**：不用重写整章，把漂移的句子按声线参数改回来即可。禁忌词命中必须改，一个都不许留。

### 症状四：判断力漂移

他做的决定，与他的认知水平、经历、性格配置不符——通常是**变聪明**了。

**检测方法**：把他本章的判断逐条写出，问「他怎么想到这一步的？」

- 有推理链（他看到了 A、记得 B、因此推出 C）→ 通过
- 没有推理链，但结论正确 → 判断力漂移（这是「作者替角色想」）

**典型形态**：
- 前期需要人提点的角色，后期一眼看穿全局
- 前期冲动的人，后期忽然开始「布局」
- 配角的判断永远与主角一致（配角失去独立性）

**「聪明化」是最普遍的漂移**，因为作者写到后面自己知道全局，会不自觉地把全局认知灌给角色。**判据**：这个角色此刻知道的，是否少于作者知道的？如果他表现得和作者一样全知，就是漂移。

### 症状五：情绪平坦

他对重大事件的反应强度，明显低于前文同类事件。

**检测方法**：建立「事件—反应」对照表。取前文同类事件的反应强度作为基准：

| 前文事件 | 反应强度（用了多少篇幅） |
|---|---|
| 第 8 回：妹妹被抓 | 写了 1200 字（追、喊、失手、被人按住） |
| 第 22 回：妹妹受伤 | 写了 400 字（抱着走、找大夫、守夜） |
| 第 41 回：妹妹受重伤 | 只有 80 字（「他把她背回去，一路上没说话」） |

第三行是不是漂移？**不一定**——如果他此时已经经历了十次类似的事，「不说话」比「大喊」更重。判定要问：**这个沉默是写出来的沉默，还是没写？**

- 写出来的沉默：有具体动作（背回去、不说话、之后三章都避开这个话题）→ 成长
- 没写：一句带过，后面再没提 → 漂移或遗漏

**情绪平坦的最强信号**：主角对**新类型的**事件反应平淡。旧类型事件麻木是合理的，新类型（第一次失去同伴、第一次被至亲背叛）反应平淡一定是漂移。

## 漂移 vs 成长的判定表

| 检查项 | 漂移 | 成长 |
|---|---|---|
| 触发事件 | 无，或只有一句交代 | 有具体场景，且是角色自己的选择 |
| 代价 | 无 | 有（失去什么，且不可逆） |
| 过程 | 一次跳跃 | 至少两个中间态（犹豫→做→后悔/接受） |
| 他人反应 | 没人注意到 | 至少一个旁人指出「你变了」 |
| 后续行为 | 没有变化 | 至少两处后续行为改变 |
| 可追溯 | 追不到起点 | 能指到「第 X 回之后他就这样了」 |

**判定规则**：
- 6 项里 ≥4 项落在「成长」列 → 成长，不干预
- 3 项 → 灰区，需要补代价或补他人反应
- ≤2 项 → 漂移，必须修

## 检测的执行顺序

不要一章一章读。按这个顺序做，成本最低：

1. **建对照表**：从 `ledger.get` 的 `characters` 取状态卡的五个字段（已知/持有/关系/损伤/位置），把当前章的实际表现逐项对照。这一步能抓出能力、关系、伤情类漂移的 70%。
2. **抽样口吻**：早期 10 句 + 当前 10 句，做遮名和句长对比。抓口吻漂移。
3. **列决策链**：本章该角色做的每个判断，写一行「他根据什么」。抓判断力漂移。
4. **列反应强度**：本章重大事件，量一下给了多少篇幅，与前文同类事件比。抓情绪平坦。
5. **查道德代价**：本章他做的越界行为，事后有没有代价。抓道德漂移。

五步做完约需 20–40 分钟，能覆盖全部五类。

## 已发生漂移的处置

不要回改前文（成本过高，且容易引入新矛盾）。按这个优先级：

| 处置 | 成本 | 适用 |
|---|---|---|
| **追认**：把漂移点写成一次转变 | 中 | 漂移幅度小，且能补一个触发事件 |
| **归因**：让别的角色指出他变了，把它变成戏 | 低 | 幅度中等，且不违反底色 |
| **回收**：让漂移成为代价（他变了，然后因此吃亏） | 中 | 幅度大，但方向与主线不冲突 |
| **回退**：改当前章，改回原样 | 低 | 只发生在最近 1–2 章 |
| **改前文** | 极高 | 只在漂移涉及核心设定时使用，且必须记 `ledger.upsert` 说明 |

**追认的具体做法**：找到这个变化最可能发生的那个时间点（通常是一次重大失去之后），在那一章补 200–400 字，写他做的一个选择。不需要重写整章，只需插入一小段。

**归因的具体做法**：在下一次同场时，让另一个角色说一句「你以前不这样」。这一句同时做到：承认变化、给读者交代、把变化变成关系戏。成本极低，效果最好，优先用这个。

## 预防：三条写入状态卡的纪律

1. 每次状态更新都记「来自第几回什么事件」——漂移的根源通常是「不知道他是从哪一步开始变的」
2. 状态卡的「已知」条数上限（主角 40 条）——超限强制分组或转移，防止一个人吸收所有人的信息
3. 每 20 章做一次抽样对照（口吻 10 句 + 决策链 5 条），不要等到写完一卷才查
