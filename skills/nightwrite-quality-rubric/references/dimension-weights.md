# 评分维度的权重

SKILL.md 的六维是**等权**的（各 0–10，门禁线统一）。但等权在实操里有问题：一致性致命时其他五维全废，而节奏 3 分和审美 3 分的后果完全不同。这份给三件事：**硬否决权的分配、加权总分的算法、以及什么情况下可以不用等权**。

---

## 一、六维的三层权重

| 层 | 维度 | 权重性质 |
|---|---|---|
| **否决层** | 一致性、伏笔 | 可以单方面否决整章（不看其他维） |
| **核心层** | 角色、节奏 | 加权 1.5 |
| **表现层** | 钩子、审美 | 加权 1.0 |

### 为什么一致性和伏笔是否决层

- **一致性**：读者读到矛盾会立刻出戏，之后所有内容都不算数。一章有致命冲突，等于这章没写。
- **伏笔**：应收未收是**跨章损伤**——它不只毁这一章，还毁前面所有铺垫。所以它比「这一章不好看」严重。

### 为什么角色和节奏是核心层

这两维决定**读者会不会追**。一致性决定「会不会出戏」，角色和节奏决定「会不会继续」。读者可以容忍一个没审过的世界，但不能容忍一个不像人的人物和一个平的节奏。

### 为什么钩子和审美是表现层

- 钩子：很重要，但它可以靠**结构改动**补救（补一个悬点），成本比改人物低。
- 审美：最容易被高估。文风好但故事不成立的章，读者照样走。

---

## 二、加权总分算法

```
加权总分 = (一致性×2.0 + 伏笔×2.0 + 角色×1.5 + 节奏×1.5 + 钩子×1.0 + 审美×1.0) ÷ 9.0
```

分母 9.0 = 2.0+2.0+1.5+1.5+1.0+1.0。

### 算例

| 维 | 分 |
|---|---|
| 一致性 | 8 |
| 伏笔 | 9 |
| 角色 | 6 |
| 节奏 | 5 |
| 钩子 | 7 |
| 审美 | 8 |

```
= (8×2 + 9×2 + 6×1.5 + 5×1.5 + 7 + 8) ÷ 9
= (16 + 18 + 9 + 7.5 + 7 + 8) ÷ 9
= 65.5 ÷ 9
= 7.28
```

**等权平均是 7.17，加权是 7.28**——因为高权重的两维分高。这个差距不大，但方向对：**同样的失误，出在一致性上比出在审美上更扣分。**

### 反向算例

一致性和伏笔都 5，其余 9：

```
= (10 + 10 + 13.5 + 13.5 + 9 + 9) ÷ 9
= 65 ÷ 9 = 7.22
```

等权平均 7.67。**加权后掉了 0.45 分**——这正是「设定有洞但文笔不错」的章应有的待遇。

## 三、门禁的三道闸

SKILL.md 给了三道：任一维 < 门禁 → 不通过；一致性有致命 → 直接不通过；平均 ≥ 门禁且无单项 < 门禁−2 → 通过。

**加权后补充两道**：

### 闸 4：否决层单项 < 门禁−1 → 不通过

一致性和伏笔即使没有致命，只要比门禁低 2 分以上就否决。理由：这两维的「低」往往是系统性的，不是这一章手滑。

### 闸 5：核心层两维都 < 门禁 → 不通过

角色和节奏**同时**偏低，说明这章的「故事」不成立，不是「写得糙」。

### 完整判定流程

```
1. 一致性有致命？           → 不通过
2. 否决层任一 < 门禁−1？    → 不通过
3. 核心层两维都 < 门禁？    → 不通过
4. 任一维 < 门禁？          → 不通过
5. 加权总分 ≥ 门禁 且 无单项 < 门禁−2？  → 通过
6. 否则                     → 不通过（边界章）
```

**第 6 步的「边界章」是允许的判定**。不许为了凑通过而放宽规则。

## 四、什么时候可以不用等权

三条例外，且都必须声明：

### 例外 1：过渡章

作者声明为过渡章（承接卷末、铺垫新卷），**节奏维权重降到 0.75**，钩子维保持。

理由：过渡章本来就不该有强推进，用同一把尺子会误杀。但**衰减有上限**：不允许下调超过一维。

### 例外 2：首章/试读章

全书第 1 回，**钩子权重升到 2.0**（读者在这一章决定要不要看）。一致性和伏笔权重降到 1.5（首章还没多少设定可比对）。

### 例外 3：卷末章

卷末回，**伏笔权重升到 2.5**（这一卷该收的账必须收），审美降到 0.75（读者在这一章不看句子）。

**声明要求**：用了哪条例外、权重怎么改、改后的加权总分。不声明 = 违规。

## 五、五组不能等权处理的分数对

以下五组分数，等权会算出误导性结果。必须单独指出：

| 情形 | 等权结果 | 实际应判 |
|---|---|---|
| 一致性 2 / 审美 10 | 6.0（像及格） | 不可发——一致性 2 意味着有致命 |
| 节奏 3 / 钩子 10 | 6.5 | 不可发——中段 10 段空转，读者在钩子前就走了 |
| 角色 3 / 审美 9 | 6.0 | 不可发——人物不像人，文笔再好也没用 |
| 伏笔 4 / 钩子 9 | 6.5 | 谨慎——跨章损伤已经开始 |
| 全维 6.5 | 6.5 | 最危险——没有短板但也没有长板，读者不会记住 |

**最后一条要特别注意**：**全维中等是「平」，不是「稳」。** 报告里必须写「六维无短板但也无长板，属风险型合格」。

## 六、单维分之间的不平衡度

```
不平衡度 = 最高维分 − 最低维分
```

| 不平衡度 | 判定 |
|---|---|
| ≤2 | 均衡 |
| 3–4 | 正常波动 |
| 5–6 | 有明显短板，改进优先级应集中在最低维 |
| ≥7 | 畸形：某一维极高掩盖了致命短板 |

**不平衡度 ≥7 时，报告必须在顶部写一句警示**，且改进优先级的第一项必须是**最低维**，不许因为「高维更容易再提分」而改高的那维。

## 七、权重的落盘

`problem.save` 时，每条问题应带权重标签：

```
{ dim: "节奏", score: 5, weight: 1.5, gate: 7, gap: 2.0 }
```

**`gap` = 门禁 − 分数**。这个值是驾驶舱欠账清单排序的依据：**按 `gap × weight` 降序**。

算例：
- 节奏 5（gap 2.0 × 1.5 = 3.0）
- 审美 6（gap 1.0 × 1.0 = 1.0）

→ 先修节奏。

---

## 八、三件不许做的事

1. **不许改权重来让章通过**。改权重必须在打分**之前**声明，不能在算完总分后发现不通过再调。这是 SKILL.md「不许把门禁线往下调」的同一条禁令。
2. **不许只报加权总分不报六维**。加权分是决策用，六维是改进用。
3. **不许用「总分 7.28」这种精度**。报告给一位小数（7.3），精度超过数据可信度是假精确。
