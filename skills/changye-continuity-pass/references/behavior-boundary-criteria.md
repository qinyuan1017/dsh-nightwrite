# 人物行为越界的判据

> 适用：SKILL.md 第 3 步「人物行为」维度时读这份；判「他做了他绝不做的事、说了他绝不说的话」。

这是唯一**需要推理而不是比对**的维度。六类冲突里，其余五类都能靠查账，这一维必须靠判。所以必须有可操作的判据，否则会变成「我感觉不像他」。

---

## 一、三个可判定的证据源

按优先级排列。前一源能判定就不必看后一源。

### 证据源 1：`characters.threshold`（心理阈值）

账面明文写的「绝不做 X」+「破例条件 Y」。

**判法（三步）**：

1. 本章的行为是否属于 `threshold` 里列举的「绝不做」？
2. 是 → 本章有没有出现 `破例条件`？
3. 有破例条件 → 通过（但要检查破例条件本身是否被演出来了，见第三节）
   **没有破例条件 → 致命**

**正例**：
> 账本：「他不会丢下同伴，哪怕会输。破例条件：同伴已经变成敌人。」
> 正文：「他把受伤的阿禾留在庙里，自己走了。」
> 判：属「丢下同伴」。破例条件（同伴变敌人）未出现。**致命。**

**反例**：
> 正文：「阿禾拔出刀，刀尖对着他。他退了两步，转身走了。」
> 判：破例条件出现了。**通过**，但要在报告里记「破例条件已触发，需确认前文是否充分铺垫」。

### 证据源 2：`characters.voice`（语言基因）

账面写的说话方式。

**判法**：本章每一句对白，遮住说明语，能否认出是谁说的（同 `../changye-write-chapter/references/dialogue-narration-ratio.md` 病型 4）。

- 单句认不出 → 不判（单句可能是特殊情境）
- **连续 3 句都认不出** → 警告
- **连续 3 句且与 `voice` 明文相反**（如账面「从不说敬语」但正文用了「您」） → **致命**

### 证据源 3：前文行为（`state` + 已写章节）

账面没写阈值时，用**前文已建立的模式**推。

**判法（五步反推）**：
1. 找出这个人前文做过 ≥2 次的同类选择（都选了同一方向）。
2. 本章的选择是否与那两次相反？
3. 相反 → 继续问：有没有①足够强的外部压力，②前文已有的一次「犹豫」铺垫，③本章内的转折事件。
4. 三者有其一 → 警告（要求补铺垫）
5. 三者全无 → **致命**

**例**：
> 前文：第 4 回、第 8 回，他两次面对「救不救人」都选择了救。
> 本章：他见死不救。
> 检查：外部压力（有——救会暴露自己）／犹豫铺垫（有——第 9 回他多看了那人一眼）／本章转折（无）。
> 判：有其一，**警告**。报告写「需补铺垫：第 9 回的『多看一眼』要写实，不能只是瞥过」。

## 二、四个非越界的免责情形

以下四种不算越界，**不许判致命**：

### 免责 1：身份/关系已改变

账本 `state` 记了状态变化（拜师、成亲、反目），则行为标准随之改变。

**判法**：查 `state` 有没有对应变化。有则按新状态判。**没查 `state` 就判越界是最常见的误判。**

### 免责 2：破例条件被演出来了

见证据源 1。但要求破例条件是**本章内可见的事件**，不能是「他内心其实早就……」这种不落地的说法。

### 免责 3：不可靠叙述者

视角人物在说谎、在自欺、在失智。此时他的「行为」可能是叙述的产物。

**判法**：本章有没有其他的叙述矛盾（同一事件两个说法、明显的时间错乱）？有 → 可以按不可靠叙述处理，判**警告 + 转交**，不判致命。

### 免责 4：成长弧的终点

账本 `arc` 里写明「终点：从 A 变成 B」。如果本章正好是终点那一回，行为与起点相反是**正确的**。

**判法**：查 `arc` 的 `转折` 落在第几回。本章 ≥ 转折回目 → 按终点标准判。

## 三、破例条件的三个合格标准

「破例条件」是这个维度唯一的救生门，所以它本身必须合格，否则所有越界都能被它洗白。

### 标准 1：条件必须是可观察的事件

- 合格：「同伴已经变成敌人」（能看见：他拔刀对着我）
- 不合格：「他心死了」（看不见）

### 标准 2：条件必须在本章之前有铺垫

**至少一次**前文提及。完全没有铺垫的破例条件，判**警告**（不是致命，但要指出「破例来得太突然」）。

### 标准 3：条件触发后必须有代价

破例不能是免费的。人物破了「绝不」之后，必须失去什么（信任、自我认同、退路）。

**判法**：破例之后的 1–3 段内，有没有出现代价的迹象？没有 → 警告。

## 四、五类最常见的假装越界

审查时容易误判成越界的五种情况，逐条给排除法：

| 情况 | 为什么不是越界 | 排除法 |
|---|---|---|
| 极端情境下的应激 | 阈值通常隐含「正常情况下」 | 问：这个情境是不是把人都逼到极限了？是 → 警告不致命 |
| 被人设计 | 行为是别人推导的结果，不是他的选择 | 问：本章有没有人布置了陷阱/骗局？有 → 免责 |
| 醉酒/受伤/中邪 | 判断力受损 | 问：状态栏有没有相应记录？有 → 免责 |
| 说了反话 | 对白不等于动机 | 问：这句话有没有明确的语境（反讽、激将）？有 → 免责 |
| 长线伪装 | 表面行为与真实目的相反 | 问：账本 `hiddenDesire` 能否解释？能 → 免责 |

**关键**：免责不是「放过」，是「降级为警告并在报告里点名」。**免责情形仍要写进报告**，写「疑似越界，因 X 免责，建议确认」。

## 五、越界报告的标准写法

```
【越界】第 <X> 段「<原文 ≤30 字>」
  违反：characters/<名> 的 threshold「<账本原话>」
  破例条件：<本章是否出现>
  铺垫检查：前文提及 <n> 次 / 无
  代价检查：破例后 <有/无> 代价迹象
  等级：<致命 / 警告>
  建议：<一句话怎么改>
```

**不允许的写法**：
- 「第 5 段主角行为不符合人设」（没引账本原话）
- 「感觉他这里崩了」（无法定位）
- 「他应该不会这么做」（没给判据）

## 六、判定的边界

这个维度**只判「有没有越界」，不判「好不好」**。

- 「这个转变太快了」→ 不是越界，是节奏问题，交 `changye-reader-report`。
- 「他这样写不讨喜」→ 不是越界，是审美，不写进报告。
- 「这个选择让剧情不通」→ 先判是不是越界；不是越界就走其他五类。

SKILL.md 禁止事项明确：不许审文风、不许评价好不好看。人物行为维度只回答一个二值问题：**这个行为能不能用账本 + 前文推出来**。
