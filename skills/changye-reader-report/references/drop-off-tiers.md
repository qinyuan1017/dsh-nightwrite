# 弃书风险的三档判据

> 适用：判「弃书风险 低/中/高」时读这份。这是全章最重的一栏——它决定这一章能不能发。

SKILL.md 只给了一句话：「高 = 通读中至少有一次真想划走」。这份把三档拆成可判的条件、给出**位置权重**、给出**跨章累积规则**。

**核心：弃书不是「这章不好」的结果，是「读者找到了一个离开的理由」的结果。** 所以要判的是「有没有那个理由」，不是「这章有多好」。

---

## 一、三档的完整判据

### 高（不可签发）

命中**任一**即判高：

| 条件 | 判据 | 报告必须写 |
|---|---|---|
| H-a | 章首前 300 字内有一次真想划走 | 段号 + 原句 |
| H-b | 有意放弃理解的地方（读者决定「算了不看了」） | 段号 + 放弃什么 |
| H-c | 章末钩子无效，且全章无峰值 | 最后 150 字原句 |
| H-d | 连续 ≥8 段无状态变化 | 起止段号 |
| H-e | 画像卡「雷点」被正面命中 | 雷点编号 + 命中位置 |
| H-f | 主角的行为读起来「不像他」，且没有可理解的解释 | 段号 + 为什么不像 |

**H-f 需要说明**：读者对人物的信任比剧情更容易崩。一个人物做了反常的事，读者不会等解释，会直接关掉。所以这一条单独成立——不需要 `changye-continuity-pass` 的结论，读者视角下「不像他」本身就是弃书理由。

### 中

命中任一：

| 条件 | 判据 |
|---|---|
| M-a | 没有想划走的瞬间，但读完没有继续的动力（「明天看情况」） |
| M-b | 有一处想快速滑过（不是划走），且该处在章首 30% |
| M-c | 有一处想划走，但 400 字内被救回（必须在报告里写「救回段」） |
| M-d | 困惑点 3–4 条 |
| M-e | 全章曲线幅度 ≤1（太平，读者记不住） |
| M-f | 谷长 5–8 段 |

### 低

**全部**满足：

- 无 H 条命中
- 无 M 条命中
- 读完能说出「下一章想看什么」的具体内容
- 困惑点 ≤2 条

**低不许写成「通过」**——SKILL.md 禁止事项明文：没有签发权。

## 二、位置权重

同一个缺陷，位置不同，杀伤力不同。**判档时先按位置加权，再定档。**

| 位置 | 权重 | 说明 |
|---|---|---|
| 段 1–3（章首 300 字内） | ×2.0 | 平台推荐位的「试读区」，绝大多数退出发生在这里 |
| 段 4–8 | ×1.5 | 决定「要不要继续」 |
| 中段 | ×1.0 | 基准 |
| 最后 3 段 | ×1.3 | 决定「要不要点下一章」 |

**用法**：一个中等问题出现在段 1–3 → 按 ×2.0 折算，直接升到「高」。

**例**：
> 中段有一处「想快速滑过」= M-b → 中。
> 同一处若在段 2 → ×2.0 → 判高。

## 三、跨章累积

单章判定之外，还有**跨章判定**。三章连读时：

### 累积规则 1：连续中 = 高

连续三章都是「中」→ 第三批判高。理由：读者不会因为「每章都还行」留下来，会因为「一直没有非看不可的东西」而走。

### 累积规则 2：谷叠加

第 N 章末尾的谷与第 N+1 章开头的谷合并计算。合并后 >8 段 = 高。

### 累积规则 3：递减曲线

三章追读欲均值递减，且第三章 <3.2 = 高。

### 累积规则 4：钩子连废

连续两章章末钩子「无效」= 高。连续两章「勉强」= 中。

## 四、五个「看起来像低其实不是」的情形

| 情形 | 为什么不是低 | 正确档 |
|---|---|---|
| 文笔很好，读起来很舒服 | 舒服 ≠ 想追 | 中（除非有具体期待） |
| 设定很新颖 | 新颖是好奇，不是追读 | 中 |
| 主角很惨，读者心疼 | 心疼是情绪回报，不是追读动力 | 看有没有「想看怎么办」→ 有则低，无则中 |
| 章末有反转 | 反转若无铺垫 = 读者觉得被骗 | 中 |
| 数据上「完读率高」 | 完读 ≠ 追读；读者可能只是没找到更好看的 | 不进判定（本报告不接数据） |

**第 5 条特别重要**：这份手册只判文本体验，不判平台数据。数据由运营那边看。

## 五、三档对应的动作

| 档 | 动作 |
|---|---|
| 高 | 不可发；必须交 `changye-revision-pass`（场景级改动）后重评 |
| 中 | 可发，但要在报告里给出**唯一一个**优先修的位置（不要列 5 条） |
| 低 | 可发；建议记录「这一章为什么留人」，作为后文的模板 |

**「中」只给一个优先修的位置**——这是硬要求。列 5 条等于没给优先级，作者会挑最省力的改，改完还是中。

## 六、弃书点的三种成因

判档之后，还要归因。**成因决定修法，档位只决定要不要修。**

### 成因 1：看不懂（信息缺口）

- 表现：读者在某个段落后放弃理解
- 修法：补信息 / 前移信息 / 拆解术语
- 交叉：`../changye-reader-question/references/confusion-vs-mystery.md`

### 成因 2：不在乎（情感缺口）

- 表现：角色遭遇了什么，读者无感
- 修法：在事件之前建立代价（这个人失去这个会怎样）
- 交叉：`../changye-emotional-payoff/references/payoff-scheduling.md`

### 成因 3：被冒犯（信任缺口）

- 表现：读者觉得作者在糊弄（降智、巧合、说教、价值观冲撞）
- 修法：把「巧合」改成「代价换来的」；删说教；避开画像卡雷点
- 交叉：`../changye-reader-persona/references/persona-card-fields.md`

**判据**：三成因中，**成因 3 最难修**——它损害的是作者信任，修一次不足以挽回，通常需要连续 3 章不出错。

## 七、报告写法

```
【弃书风险】高
  命中：H-a（章首 300 字内想划走）
  位置：第 2 段「<原句 ≤20 字>」
  成因：2（不在乎）— 这个人物此前的处境没有建立，读者不知道他失去这个意味着什么
  跨章：连续两章「中」后升为「高」
  优先修：第 1–3 段需补一个让读者在乎的代价（只给方向）
```

**必须有的四项**：命中的条件编号、段号+原句、成因分类、跨章依据（若无写「单章判定」）。

**不许出现**：
- 「整体风险中等偏高」（没有档位）
- 「有几处可能让人出戏」（没有段号）
- 「建议加强人物塑造」（没有动作）

---

## 八、判定的边界

- **不判好不好看**。判的是「会不会走」。
- **不替作者决定改不改**。只给档位和优先修。
- **不受「这是过渡章」影响**。过渡章同样要留人；若作者声明是过渡章，只在报告里记一句「作者声明的过渡章」，档位照判。
- **不因「后面会好」降档**。读者只在当下做决定。
