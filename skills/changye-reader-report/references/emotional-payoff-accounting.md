# 情绪回报的记账方式

> 适用：判「情绪回报（类型 + 强度）」这一栏时读这份；判「这章是不是空手而归」时读这份。

SKILL.md 给了六种类型和三个强度，没说**怎么确认读者真的拿到**。这份给「承诺-兑现」记账法：读者每一次投入都记一笔应收，兑现才销账，销不掉的账就是读者流失的原因。

**核心：情绪回报不是「作者写了什么情绪」，是「读者被欠了什么、还了多少」。**

---

## 一、记账的三个基本概念

### 投入（debit）

读者为某件事付出的注意力与期待。每一次「读者在乎了」都是一笔投入。

### 承诺（promise）

文本明确或隐含地告诉读者「这个会有下文」。承诺的形成条件（任一）：

- 一个人物提出了问题，没被回答
- 一个威胁被展示，没被处理
- 一个欲望被表达，没被满足/阻断
- 一个不公平被展示，没被纠正

### 兑现（credit）

承诺被结算。结算的三种形态：
- **给到**（他得到了）
- **给不到但有交代**（他失去了，但他知道为什么）
- **被更高价值替换**（他放弃了 A，因为 B 更重要）

**关键：承诺可以兑现为「失去」，但不能兑现为「遗忘」。** 读者能接受悲剧，不能接受作者忘了。

---

## 二、三种回报类型的记账口径

### 爽感 / 解气：压制→反打

```
投入：主角被压制（记 1 笔）
投入：压制被加到极限（记 1 笔，强度 ×1.5）
兑现：反打成功（销 2 笔）
```

**判据：反打必须打在同一个压制点上。** 前文压制他的是「族里说他爹是罪人」，反打必须是「证明他爹不是罪人」，不能是「他打赢了一场比武」。

反打错位 = 只销了 0.5 笔，读者会觉得「爽是爽了，但没解气」。

### 心疼：靠近→失去

```
投入：读者开始在乎这个人（记 1 笔）
投入：这个人展示了脆弱（记 1 笔，强度 ×1.5）
兑现：失去/受伤/离别（销 2 笔）
```

**判据：心疼必须建立在「读者想让他好」的基础上。** 没有建立在乎就写惨，读者只会觉得烦（这叫卖惨）。

### 悬念 / 好奇：提问→部分回答

```
投入：提出一个问题（记 1 笔）
兑现：回答一部分，同时提出下一个问题（销 0.7 笔，新增 1 笔）
```

**判据：悬念类回报天生销不满**，因为它的机制就是「永远有下一个问题」。所以**悬念型章不能连续 3 章都只销 0.7**，第 3 章必须给一个完整回答（销满）。

## 三、强度的量化

强度不能凭感觉。用**读者身体的反应**做锚：

| 强度 | 判据 |
|---|---|
| 强 | 读的时候有生理反应（屏息、鼻酸、想拍桌、笑出声） |
| 中 | 读的时候有明确的情绪，但没有生理反应 |
| 弱 | 需要回想才能确认「这里应该是想让我有感觉」 |

**判定方法**：报告里不许当场判强度。要求读完这章后**先做别的栏（至少两栏）**，回来再判。间隔能过滤掉「刚读完的新鲜感」。

### 强度的三个加成

- 情绪在**章末 150 字内**兑现 → 强度 +1 档
- 情绪兑现前有 **≥400 字的压制** → 强度 +1 档
- 情绪兑现**只由对白完成**（无动作、无场景） → 强度 −1 档

第三条最实用：**光靠说，情绪传不到。** 必须有一个身体动作或一个物件。

## 四、空手而归的判定

SKILL.md 把「空手而归」列为一种类型。它的严格判据：

**本章有 ≥1 笔投入，但兑现 0 笔，且无新增投入。**

三个条件全满足才是空手而归。缺一：

| 缺哪个 | 实际是 |
|---|---|
| 无投入 | 这章没建立任何承诺 → 判「白开水」，比空手而归更严重（读者根本不在乎） |
| 有兑现 | 不是空手而归 |
| 有新增投入 | 是「悬念」，不是空手而归 |

**报告必须写「本来期待什么，没给」**：
> 【情绪回报】空手而归，强度 — 前 3 段建立了「他要为父亲翻案」的期待，但全章只走了流程，一笔没销。

## 五、账期的概念

一笔投入不能无限期挂着。**账期 = 从投入到必须兑现的最大章数。**

| 投入类型 | 账期 | 超期后果 |
|---|---|---|
| 小承诺（这一场要问清的事） | 同章内 | 读者当场觉得拖 |
| 中承诺（这一条线要解决的事） | 3–5 回 | 读者开始怀疑作者忘了 |
| 大承诺（这本书的核心问题） | 全本 | 靠阶段性给甜头维持 |

**判据：本章有没有「超期未销」的账？** 有 → 在报告里点名，但**不进弃书风险**（那是细纲的事，交 `changye-emotional-payoff`）。

## 六、记账表模板

```
| # | 投入（段号） | 类型 | 强度 | 承诺 | 本章兑现（段号） | 状态 |
|---|---|---|---|---|---|---|
| 1 | 3 | 压制 | 中 | 他会不会被赶出宗门 | — | 未销 |
| 2 | 7 | 心疼 | 强 | 阿禾的伤能不能好 | 14（部分） | 部分销 |
| 3 | 11 | 压制 | 强 | 二叔会不会被揭穿 | 21（全） | 已销 |
```

**格式硬要求**：
- 每一行必须有段号。
- 「未销」的行必须在报告里出现。
- 「部分销」的行要写清销了多少（一部分/一半）。

---

## 七、本章净账

```
净账 = 本章兑现笔数（加权） − 本章新增投入笔数（加权）
```

| 净账 | 判定 | 读者状态 |
|---|---|---|
| >0 | 本章还清了旧账 | 满足，但是否追读看有没有新账 |
| =0 | 收支平衡 | 正常 |
| −1 ~ −2 | 略有欠账 | 可接受 |
| <−2 | 欠账过多 | 读者会觉得「一直在憋」 |

**连续三章净账 <−2 = 必须立刻给一次兑付**，否则读者从「期待」变成「不耐烦」。

**特例**：卷末高潮章允许净账大幅为负（因为要开新卷的账）。但卷末高潮章本身的「兑现」强度必须 ≥强。

## 八、五种「假装兑现」

| 假兑现 | 为什么是假的 | 真兑现要什么 |
|---|---|---|
| 主角说「我不在乎了」 | 读者还在乎 | 读者要看到不在乎的证据（行动） |
| 敌人自己摔死了 | 不是主角赢的 | 反打必须由主角造成 |
| 「其实他早就知道」 | 撤销了压力，不是解决 | 压力必须真的存在过并造成伤害 |
| 大段抒情 | 情绪被命名而非被推出 | 动作/物件/场景 |
| 时间跳跃「三年后」 | 跳过了兑现 | 兑现必须被写 |

**第 3 条最隐蔽**（也是 AI 高频写法）：先制造一个困境，章末说「其实主角早就算到了」。读者读到的是「我刚才的紧张是假的」。这会让**后续所有紧张都失效**。

**例外**：如果「早就算到了」本身是一个新信息（读者不知道他知道），且前文埋过暗示，那是合法反转。判据：**前文有没有 ≥1 处可复盘的暗示**。没有 = 假兑现。

## 九、与相关技能的分工

- **这份**：判**本章**的回报到账情况（读者视角）。
- **`changye-emotional-payoff`**：管**跨章排期**（什么时候该给、憋多久算太久）。
- **`changye-plan-novel`**：管**伏笔与转折**（结构层的账）。

三者的口径必须一致：账期、兑现形态、强度锚点。不一致会出现「报告说空手而归，细纲说这章是兑付章」。
