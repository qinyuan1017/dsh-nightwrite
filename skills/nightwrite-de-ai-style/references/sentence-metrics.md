# 句式统计口径

四项指标：平均句长、短句占比、平均段长、对白占比。**全部按字符数（含标点？不含——统一不含标点、不含空白）计算**，这是本书唯一口径，不许中途改。

---

## 一、句子的切分

### 句末标点

在下列字符处断句：`。` `！` `？` `…`（三个点算一个句末）以及 `」` `』` `"` 紧跟在这些标点之后的情形。

**不断句**的位置：
- `，` `；` `：` `、` ——这些是句内停顿，不算句。
- 段末无标点（故意留的顿挫）——**算一句**，按实际字数计。
- 对白里的问句、感叹句——照常断，但归入「对白」统计，同时计入句数。

### 「。」与「……」的争议

「他站住了……」是**一句**，不是两句。连续 6 个点仍算一个句末。
「他站住了……然后呢？」是**两句**。

### 引号内外的处理

对白整句算一句，不管里面有几个逗号：
> 「我不去，你去吧，反正你也不怕死。」

这是**1 句**，字数按引号内全部字符计（不含引号本身）。

对白说明语单独成句：
> 「我不去。」他把杯子放下。

这是**2 句**：对白 1 句（3 字），叙述 1 句（6 字）。

### 示例演算

样本（37 个字符，不含标点）：

```
他把刀横在膝上。风从门缝里进来，吹得灯火歪了一下。
「你不该来。」他说。
```

断句：
1. `他把刀横在膝上` → 8 字
2. `风从门缝里进来` → 7 字
3. `吹得灯火歪了一下` → 8 字
4. `你不该来` → 4 字（对白）
5. `他说` → 2 字

句数 = 5，总字数 = 29（不含标点与空白），平均句长 = 29 ÷ 5 = **5.8 字**。

**注意第 2、3 句**：逗号处的「风从门缝里进来，吹得灯火歪了一下」——按逗号切成两句还是算一句？

规则：**逗号处不断句，除非后接的是完整主谓结构且语义独立**。这一例「吹得灯火歪了一下」主语承前省略，不是独立句，应当合并：

修正：句数是 4，字数 29，平均句长 = **7.25 字**。

这就是口径争议的典型来源。**简化判定法**：逗号后如果补不出主语，就不断句。补得出（「他走了，她留下」）就断。

## 二、四项指标

### 1. 平均句长

```
平均句长 = 总字数（不含标点空白） ÷ 句数
```

保留一位小数。参照带：

| 区间 | 读感 | 适用 |
|---|---|---|
| <10 字 | 极碎，喘不上气 | 打斗、惊恐、短促对峙 |
| 10–15 字 | 紧 | 主流网文默认 |
| 15–22 字 | 中 | 情感、氛围、心理 |
| >22 字 | 松，易散 | 说明、追述、场景铺陈 |

超过 25 字判「拖」，但**单章允许 5% 的长句**——全是短句会假。

### 2. 短句占比

```
短句占比 = 句长 ≤8 字的句数 ÷ 总句数
```

≤8 字是**含 8**。7 字算，9 字不算。

参照带：

| 占比 | 判读 |
|---|---|
| <8% | 太齐，典型 AI 节奏 |
| 8–15% | 偏稳 |
| 15–30% | 健康 |
| 30–45% | 碎，适合动作章 |
| >45% | 过度，读起来像提纲 |

术语句、专名句容易被误判成短句（「金丹期。」3 字）。**规则：单独成句的专名/术语不计入短句分子**，避免虚高。

### 3. 平均段长

```
平均段长 = 总字数 ÷ 段数
```

段的定义：一个换行分隔的文本块。标题、分隔符（如 `***`）、空行不计段。

参照带：

| 区间 | 读感 |
|---|---|
| <40 字 | 极快，像诗 |
| 40–80 字 | 快 |
| 80–150 字 | 标准网文 |
| 150–250 字 | 慢，适合铺垫 |
| >250 字 | 手机屏一屏看不完，掉读 |

**段落离散度**（判「是否均匀」，对应 AI 信号第 6 类）：

```
离散度 = 段落长度标准差 ÷ 平均段长
```

<0.35 判「太匀」；0.35–0.8 正常；>0.8 判「忽长忽短」，检查是不是有段只剩一句。

### 4. 对白占比

```
对白占比 = 引号内字数 ÷ 总字数
```

引号指 `「」` `『』` `""` `""`。旁白引用（引用的书信、告示）**计入对白**——它同样占篇幅。

参照带：

| 占比 | 判读 |
|---|---|
| <10% | 几乎没有对话，全靠叙述扛 |
| 10–25% | 叙述为主，适合单人场景 |
| 25–45% | 均衡，主流区间 |
| 45–65% | 对话驱动，适合交锋、谈判 |
| >65% | 像剧本，画面感会掉 |

## 三、与基准对比的判定

SKILL.md 要求「差异超过 30% 的那一项就是主攻方向」。算差异用**相对差异**，不是百分点：

```
相对差异 = |目标章指标 − 基准指标| ÷ 基准指标
```

例：基准平均句长 14.0，目标章 11.0 → 相对差异 = 3 ÷ 14 = **21%**，不算超标。
基准短句占比 18%，目标章 8% → 相对差异 = 10 ÷ 18 = **56%**，超标，主攻这一项。

**百分比类指标（短句占比、对白占比）的陷阱**：基准 4%，目标 6%，相对差异 50%，但绝对值只差 2 个百分点，不值得动。规则：**百分比指标同时要求绝对差 ≥5 个百分点**才算超标。

---

## 四、统计时的三种污染

1. **把标题算进正文**：回目、章节标题不计入任何指标。
2. **把场景分隔符算成段**：`***`、`---`、空行不计段。
3. **把对话说明语算成对白**：`他说`、`她问` 在引号外，计入叙述。

## 五、少于 3000 字不出结论

单章 3000 字以下时，任何一项指标的标准误差都 >15%，和基准比没有意义。此时只报数，不判超标。跨章比较时，样本必须 ≥3 章合计 ≥8000 字（与 `nightwrite-style-distillation` 第 1 步一致）。
