# 章纲的颗粒度标准

SKILL.md 第 5 步给了三件套（summary / hook）和「3 句以内」的上限，没说**下限**。这份给下限、给颗粒度标尺、给五种「看起来填了其实没填」的虚纲。

**核心判据一句话：细纲写完，另一个没读过原作的人能不能照着写出这一章，且写出来的东西和你想的一样。** 不能 = 颗粒度不够。

---

## 一、颗粒度的四层

同一回可以写成四种粗细。列出是因为**很多虚纲是第一层冒充第三层**。

| 层 | 形态 | 能用来写正文吗 |
|---|---|---|
| L1 事件层 | 「他去见了师父」 | 不能 |
| L2 变化层 | 「他去见师父，得知父亲的案子要重审」 | 勉强，写出来会跑偏 |
| L3 因果层 | 「他去见师父，因为师门收到刑部的公文要提人，师父要把这差事交给他办」 | 能 |
| L4 场景层 | 在 L3 基础上给出「在哪、几个人、谁先开口、卡在哪个问题上」 | 能，且不跑偏 |

**目标：L3 是及格线，关键回（卷首/转折/卷末）要到 L4。**

### L2 与 L3 的分界线

一句话：**L2 只写「知道了什么」，L3 写「因为什么知道了，知道了之后要做什么」。**

- L2：「主角发现二叔在说谎。」
- L3：「主角去二叔家问父亲的下落，二叔说父亲三个月没来过，但桌上的茶还冒着热气——主角发现二叔在说谎，而且知道他在藏人。」

L3 多了三个信息：谁问谁、凭什么发现、发现之后指向什么。

## 二、summary 的下限（三条硬指标）

SKILL.md 要求「3 句以内：起因 → 变化 → 落点」。补充三个硬指标：

1. **必须有一个专名**（人名/地名/物件名）。没有专名的 summary 一定是虚的。
   - 虚：「他去打听消息，遇到阻力。」
   - 实：「他去城西的顺风镖局打听父亲的消息，被镖头赶了出来。」

2. **必须有因果连接词**（所以/因为/于是/却/但）。没有 = 事件并列，不是因果。
   - 虚：「他去了镖局，镖头不认识他，他回家了。」
   - 实：「他去了镖局，镖头却说不认识他——可镖头袖口绣的那道云纹，和他父亲遗物上的一模一样。」

3. **落点必须是「新问题」或「新处境」**，不许是「于是他回去了」。

---

## 三、hook 的颗粒度

SKILL.md：`hook` 一句，必须是读者会追问的东西。

**判法：把 hook 读出来，问「所以呢？」。答得出一个具体的问句 = 合格。**

| 写法 | 「所以呢？」的答案 | 判定 |
|---|---|---|
| 欲知后事如何 | 无 | 废 |
| 他不知道，这一切才刚刚开始 | 无 | 废 |
| 门外站着的人，是他爹 | 「他爹不是死了吗？」 | 合格 |
| 他打开信，只有三个字 | 「哪三个字？」 | 合格 |
| 他赢了 | 「赢了又怎样？」——不具体 | 不合格 |

**hook 的四种类型**见 `references/hook-types.md`。

## 四、五种虚纲（看起来填了，其实没填）

### 虚型 1：动词虚

「解决」「处理」「应对」「面对」「化解」——这些动词没有画面。

- 虚：「主角解决了宗门的危机。」
- 实：「主角把掌门私卖军粮的账册抄了一份，塞进了巡按的轿子里。」

**修法**：把抽象动词换成「用手/用嘴/用钱」做了什么。

### 虚型 2：对象虚

「敌人」「对手」「某个人」「众人」。

- 虚：「他打败了对手。」
- 实：「他在擂台上三招之内挑落了掌门外甥的剑，然后收剑退了三步。」

**修法**：给对象一个专名，或至少给一个身份标签+一个外貌特征。

### 虚型 3：程度虚

「大败」「惨胜」「局势逆转」「实力大增」。

- 虚：「主角大败敌军。」
- 实：「主角烧了敌军的粮车三十辆，自己这边死了十七个人，其中包括他的马夫。」

**修法**：给数字，或给一个具体的损失。

### 虚型 4：时间虚

「经过一段时间」「几个月后」「终于」。

- 虚：「经过几个月的修炼，他终于突破了。」
- 实：「他在后山待了四十九天，出来时能单手举起三百斤的石锁。」

**修法**：给天数。天数本身就是节奏信息。

### 虚型 5：因果虚

「因此」「于是」「所以」后面接的其实是并列事件。

- 虚：「他得罪了掌门，于是被派去守边关。」
- 实：「他得罪了掌门，掌门没动他——而是把他调去守边关，那里三年死了七个守将。」

**修法**：检查「于是」前后是不是**手段-目的**关系。若是「A 之后 B 也发生了」，改成真的因果，或加一句点明因果。

## 五、细纲密度的量化

**每回 summary 的字数**（不含 hook）：

| 字数 | 判定 |
|---|---|
| <25 字 | 不够，L1–L2 层 |
| 25–50 字 | 及格，L3 层 |
| 50–90 字 | 充分，可到 L4 层 |
| >90 字 | 过细，可能把正文写进细纲了（SKILL.md 禁止） |

**判据：一章正文 2500 字，细纲 40–80 字。比例约 1:40。** 低于 1:100 是虚纲，高于 1:25 是越界写正文。

### 五回抽样法

排完一卷后，随机抽 5 回，只读它们的 summary，回答：

1. 这 5 回能不能拼成一个完整的小故事？
2. 每回之间能不能用「因为…所以…」连起来？
3. 有没有两回的 summary 意思几乎一样？

第 3 问命中 = 该卷二分之一是水章。

## 六、关键回要写到 L4（场景层）

**必须到 L4 的回**：卷首回、转折回、卷末回、全书第 1–3 回。

L4 在 summary 之外补四项（写进 `summary` 的括号里，或写进该回的 `beats` 字段）：

```
【场景】<地点> · <在场人数> · <谁先开口>
【卡点】<这一场卡在哪个解决不了的问题上>
【信息】<这一场读者新知道的一件事>
【代价】<这一场谁失去了什么>
```

**例**（转折回）：
> summary：「主角去刑部大堂对质，因为掌门交出了他爹的画押。他在堂上认出画押上的指纹是左手——他爹是右手写字。（场景：刑部大堂 · 五人 · 主审先开口）（卡点：画押是真的，指纹不对）（信息：有人伪造了他爹的画押）（代价：他必须当堂承认自己一直在怀疑父亲）」

**注意**：这是细纲，不是正文。不许写成「他站在堂下，抬头看着匾额上『明镜高悬』四个字」。

## 七、工序：从卷到章

1. 先把该卷的 `turningPoint` 落到具体回号。
2. 从转折回往前倒推：要让它成立，前面必须有哪 3 件事？
3. 从卷首往后推：读者要先知道什么，才能理解第 2 步的那 3 件事？
4. 中间的空档用「升级/试探/代价」三类回填。
5. 每回先写 hook（因为它决定这回到哪儿停），再写 summary。
6. 全部写完后走 SKILL.md 第 6 步的因果链自检。

**第 5 步的顺序很关键**：先写 summary 再想 hook，会导致 hook 变成「下一回的引子」而不是「这一回的悬点」。

## 八、交卷前的四问

- [ ] 随机抽 5 回，能不能串成小故事？
- [ ] 每回 summary 里有没有至少一个专名？
- [ ] 每回 hook 能不能引出具体的问句？
- [ ] 有没有哪一回的 summary 换掉专名后和另一回一模一样？

第 4 问命中 → 该回是模板回，重写。
