# 卷末高潮的设计

SKILL.md 第 4 步只讲「不可逆转折」的三个条件。但**转折不等于高潮**：转折是结构变化，高潮是读者的体感。一份骨架可以有完美转折却没有高潮，读起来就是「哦，原来如此」，没有「啊」。

---

## 一、卷末高潮的四要件

四件缺一，这卷的收尾就软。

### 要件 1：一个当众的场合

转折必须在**有人看**的地方发生。

- 弱：主角在密室里发现真相。
- 强：主角在宗祠大典上，当着全族的面把真相说了出来。

**判据**：在场人数 ≥5，且其中至少 2 人是后文还要出场的角色。**没有目击者的转折，后文必须靠转述，效果减半。**

### 要件 2：一个被推翻的公开说法

前文建立过一个**所有人都信的说法**，卷末把它推翻。

- 公开说法：「他爹是病死的。」
- 卷末：「他爹是被人毒死的，毒是他二叔买的。」

**判据**：这个公开说法必须在卷内**被提到过 ≥2 次**，并且由**不同的人**说过。只提一次的说法，推翻它没有冲击力。

### 要件 3：一个不可撤回的动作

主角在卷末做了一件**无法挽回**的事。

- 可撤回：说了狠话、摔了杯子。
- 不可撤回：杀了人、烧了契书、当众认了罪、签了字。

**判据**：这个动作做完，主角的处境**必须已经被改变**，不需要等下一卷。

### 要件 4：一个明确的新问题

卷末留下的不是悬念，是**「接下来怎么办」**。

- 弱：「他不知道，更危险的敌人还在后面。」（空指代）
- 强：「他杀了他二叔。明天，全族要选出新的族长——而他爹的冤案，只有二叔知道全貌。」

新问题：唯一知道真相的人被他杀了，怎么办。

## 二、卷末回的字数结构

卷末回通常是全卷最长的一回。参考分配（以 4000 字为例）：

| 段 | 字数 | 内容 |
|---|---|---|
| 铺垫 | 600 | 场合准备，人陆续到场 |
| 压力累积 | 1200 | 对手出招，主角挨打/被逼 |
| 反转 | 800 | 主角掏出底牌，公开说法被推翻 |
| 不可撤回的动作 | 600 | 做那件不能撤回的事 |
| 余波 | 800 | 在场者反应 + 主角的新处境 + 新问题 |

**反转不能放在最后一句话**。放在最后 = 读者没时间反应，只剩「哦」。反转后必须留 **≥600 字**的余波。

**这条是刚性的**：反转后字数 <400 的卷末回，判「高潮被砍」，`nightwrite-quality-rubric` 的「情绪兑现」维扣分。

---

## 三、卷末高潮的四种模式

### 模式 1：翻案（信息型）

把前文建立的「事实」掀翻。

- 结构：**错误认知 → 证据出现 → 当众对质 → 认知崩塌 → 代价**
- 适合：悬疑、权谋、宅斗
- 风险：证据来得太容易（「正好有人送来一封信」）。**证据必须由主角付出代价换来**（他为了这封信失去了什么）。

### 模式 2：摊牌（对抗型）

两方把底牌都亮出来。

- 结构：**互相试探 → 一方先亮 → 另一方亮得更大 → 摊牌 → 一方倒下**
- 适合：争斗、宗门、职场
- 要求：**双方都要有底牌**。只有一方有底牌 = 单方面碾压，不是高潮。

### 模式 3：抉择（价值型）

主角必须在两个都不能接受的选项里选一个。

- 结构：**两难建立 → 时间压力 → 反复 → 选 → 代价立刻兑现**
- 适合：情感、伦理、牺牲
- 要求：**两个选项都必须真的能接受一半**。一个是明显更好的选项 = 假两难。

### 模式 4：兑现（情绪型）

前文埋的所有憋屈，一次还清。

- 结构：**压迫到极点 → 主角改变 → 反打 → 全部还清 → 新处境**
- 适合：打脸、复仇、逆袭
- 要求：**还清的对象必须逐一对应**。前文被谁欺负，这回收谁的账。漏一个读者就记着。

---

## 四、卷末高潮与转折的咬合

转折三条件（结构性变化 / 失去 / 不可撤回）与高潮四要件是**两套语言描述同一件事**。对应关系：

| 转折条件 | 对应高潮要件 |
|---|---|
| 处境结构性变化 | 要件 1（当众）+ 要件 2（公开说法被推翻） |
| 失去某物 | 要件 3（不可撤回的动作带来的代价） |
| 后文不能撤回 | 要件 3 |

**所以：一个合格的卷末回，必须同时满足转折三条件和高潮四要件。** 只满足转折的，是「结构正确但不好看」；只满足高潮的，是「好看但不结实」。

## 五、五个常见软收尾

| 症状 | 表现 | 修法 |
|---|---|---|
| **无人见证** | 转折在私密场合发生 | 加目击者，或改成公开场合 |
| **反转太晚** | 最后一句话才反转，无余波 | 反转前移 600 字以上 |
| **代价缺失** | 主角赢了，什么也没失去 | 必须失去一样东西：关系/身份/退路/信念 |
| **单方碾压** | 对手没还手就倒了 | 给对手一张底牌 |
| **旧问题收尾** | 卷末解决的是卷内的小问题，不是卷主张 | 卷末必须回到 `volumes[].summary` 那句话 |

第 5 条最隐蔽。**判法：把卷末回读完，能不能用一句话说清「这卷的主张兑现了」？不能 = 收尾跑偏。**

## 六、卷末之后的第一回

卷末高潮之后的第一回**不许立刻开新线**。

结构：

```
第 N+1 回（卷首回）：
  前 40%：余波（谁死了、谁走了、主角现在在哪、什么变了）
  中 40%：新常态下的第一个小问题
  后 20%：新卷的目标出现
```

**禁止**：卷末回刚杀完人，卷首回直接「三个月后，他在另一个城里」。这叫断层，读者会晕。

**例外**：如果卷末的不可撤回动作**本身就造成了地点转移**（他被流放了），可以硬切，但卷首回第一段必须用一句话交代时间距离。

## 七、卷末高潮的检查清单

- [ ] 场合有 ≥5 人，≥2 人是后文角色
- [ ] 被推翻的公开说法在卷内被 ≥2 个不同的人提过
- [ ] 有一个不可撤回的动作，且动作完成后处境立刻改变
- [ ] 反转后有 ≥600 字余波
- [ ] 卷末的新问题是「接下来怎么办」，不是「他不知道……」句式
- [ ] 能用一句话说清「这卷的主张兑现了」
- [ ] 下一回不硬切
