# 起点欲望转折终点的填法

SKILL.md 给了五段式的判据，但每一段都只有一句话。这份把每段拆成**必须回答的提问 + 合格样例 + 不合格样例 + 三档量级**。

---

## 一、起点：必须能算出「缺什么」

### 三个必答问题

1. **他现在的物质处境是什么？**（住哪、吃什么、欠谁钱）
2. **他现在的自我认知是什么？**（他认为自己是什么人）
3. **这两者之间有没有落差？**（他认为自己是 A，实际处境是 B）

**判据：第 3 问的答案必须是「有落差」，且能一句话说出来。**

### 三档量级

| 档 | 落差强度 | 例 |
|---|---|---|
| **轻** | 认知与处境小错位 | 「他以为自己是县学最好的学生，其实先生们只当他勤勉」 |
| **中** | 认知与处境相反 | 「他以仵作为业，却坚信自己该是读书人」 |
| **重** | 认知建立在错误事实上 | 「他以为父亲是病死的，实际是被族里处理的」 |

**题材决定档位**：爽文/系统流取「中」；悬疑/家族史取「重」；日常/种田取「轻」。

### 不合格的起点

| 写法 | 为什么不行 |
|---|---|
| 「他是个普通少年」 | 无自我认知，无落差 |
| 「他全家被杀了」 | 有处境无认知——这是事件，不是起点 |
| 「他自卑」 | 是形容词，无法推出行为 |

### 合格的起点（完整例）

```
处境：陈留县仵作之子，父亲死后顶了差，月俸三钱，欠药铺二两
认知：他认为自己该是读书人，做仵作只是权宜
落差：他做的每一件仵作活都在证明他不是读书人
缺：一个能承认「我就是仵作」的理由
```

**「缺什么」必须是心理层面的东西**，不是「缺钱」。缺钱是欲望，不是起点。

---

## 二、显性目标：必须能被拒绝、能被阻挠

### 三个测试

1. **能拒绝吗？** 这个目标有没有「他可以不干」的选项？
2. **能阻挠吗？** 有没有具体的人/事能挡住他？
3. **有时间限吗？** 有没有「必须什么时候完成」？

三问全「是」才算合格。

### 合格 vs 不合格

| 目标 | 能拒绝 | 能阻挠 | 有时限 | 判定 |
|---|---|---|---|---|
| 「拿到父亲案的卷宗」 | 是 | 是（衙门的规矩） | 是（三个月后结案） | 合格 |
| 「想变强」 | 否 | 模糊 | 否 | 不合格 |
| 「为父报仇」 | 否（这是使命不是选择） | 是 | 否 | 不合格（缺时限） |
| 「查清父亲死因」 | 是 | 是 | 否 | 半合格（补时限即可） |

**「为父报仇」为什么不合格**：它不能被拒绝——拒绝报仇的角色在读者眼里是不孝，不是选择。**一个不能拒绝的目标不构成压力，只构成义务。**

### 与隐性欲望的关系

**必须冲突。** 见第三节。

---

## 三、隐性欲望：三测试逐条给判法

SKILL.md 给了三测试，但没给「怎么测」。这份给具体操作。

### 测试 1：他能坦然说出来吗？

**操作**：写一句他会说的台词，包含这个欲望。

- 「我查卷宗是为了让父亲的名声干净。」→ 说得出 → 是显性
- 「我查卷宗其实是想证明父亲有罪，这样我就不用恨自己。」→ 说不出口 → 隐性

**判据：如果这句台词他能在公开场合对任何人说，就不是隐性欲望。**

### 测试 2：它和显性目标冲突吗？

**操作**：把两个目标写成两个句子，问「能不能同时满足」。

```
显性：拿到卷宗，为父亲翻案
隐性：证明父亲有罪，这样自己不必内疚
→ 不能同时满足（翻案 vs 定罪）→ 合格
```

**判据：能同时满足 = 无张力 = 不合格。**

### 测试 3：它来自过去的什么？

**操作**：写一个具体的事件（有地点、有时间、有谁做了什么）。

- 不合格：「因为他从小缺爱」——这是解释，不是事件。
- 合格：「九岁那年他替父亲磨刀，父亲说『你要记住，仵作的刀不能见血』——他记住了，但父亲自己死在了刀下。」

**判据：能不能写成一个可以放进正文的回闪场景？** 不能 → 空的。

### 三测试的对表

```
【隐性欲望】想让父亲真的有罪
  测试1 说不出：不能公开说（会被人当成不孝）  ✓
  测试2 与显性冲突：翻案 vs 定罪           ✓
  测试3 有根源：九岁磨刀的那句嘱咐          ✓
```

## 四、转折：三个条件的量化

SKILL.md 给了三条件（自己选择、失去某样东西、不可撤回）。这份给量级。

### 条件 1：由角色自己的选择造成

**判据：把转折的事件重写一遍，把「他选择」换成「他被逼」，剧情还成立吗？**

- 成立 → 不是转折，是遭遇。
- 不成立 → 是转折。

**反例**：「二叔把他赶出族里」——他被逼，不是选择。
**正例**：「二叔给他两个选择：交出兵刃留下，或带着兵刃滚。他选了后者。」——他选了，且两个选项都要付代价。

### 条件 2：失去具体的什么东西

**必须能列出一个清单**，而且清单上的东西在后文不能再出现。

```
失去清单：
  - 族籍（第 12 回起不能再进祠堂）
  - 父亲留下的刀（被二叔收走）
  - 阿禾的信任（她认为他不该走）
```

**判据：失去的东西能不能在后文查证？** 「失去了天真」查不了；「失去了族籍」能查（第 13 回他进不了祠堂）。

### 条件 3：不可撤回

**判据：有没有一条路径能让他回到原样？**

| 路径 | 判定 |
|---|---|
| 后文有「其实那是假的」 | 失败 |
| 后文有「族老改主意了」 | 失败 |
| 后文他能重新入族籍，但必须付出更大的代价 | 通过（不是回退，是二次选择） |

**「付出更大代价才能回去」是通过的**——因为它不撤回，而是抬高了第二次选择的价格。

### 三档转折强度

| 档 | 失去的量 | 不可逆度 |
|---|---|---|
| **轻** | 失去一个机会 | 90% 不可逆（有个极难的回头路） |
| **中** | 失去一个关系 | 几乎不可逆 |
| **重** | 失去身份/名字 | 完全不可逆 |

**一本书里「重」档转折不超过 1 次**（通常是全书的中点或卷末）。

## 五、终点：反差必须可对照

### 判据：把起点和终点写成两个句子，中间加一个「但」

```
起点：为了活着可以低头
终点：为了不低头宁愿死
→ 「为了活着可以低头，但他最后为了不低头宁愿死」
```

**读起来成立 → 有反差。读起来奇怪 → 不是同一个维度上的变化。**

### 不合格的终点

| 写法 | 问题 |
|---|---|
| 「他变强了」 | 强度不是弧光维度 |
| 「他成熟了」 | 无法判定 |
| 「他救了所有人」 | 这是剧情结果，不是人格 |
| 「他成了仵作头」 | 这是地位变化 |

**判据：终点必须能回答「他当初缺的那个东西，他补上了吗？」** 补上了 = 弧光完成；没补 = 弧光未完成（可以是故意的，但要在卡上写明「本角色弧光不完成」）。

### 反差的三个维度

弧光必须在**同一个维度**上首尾对照。选一个：

| 维度 | 起点 → 终点 |
|---|---|
| **价值序** | 活着 > 尊严 → 尊严 > 活着 |
| **归因** | 都是别人的错 → 我也有份 |
| **关系模式** | 靠依附生存 → 靠交换生存 |
| **自我定义** | 我是读书人 → 我是仵作 |

**不许跨维度**：「起点是自卑，终点是当了官」——这是两个维度，不构成对照。

---

## 六、五段互检表

五段填完后，逐对检查：

| 检查对 | 判据 |
|---|---|
| 起点 ↔ 终点 | 同一维度，可对照，反差明确 |
| 起点 ↔ 隐性欲望 | 隐性欲望必须是起点落差的产物 |
| 显性 ↔ 隐性 | 不能同时满足 |
| 隐性 ↔ 转折 | 转折必须让隐性欲望浮出水面（他不得不承认它） |
| 转折 ↔ 终点 | 终点的选择必须是转折造成的 |

### 「隐性 ↔ 转折」这一对最容易漏

**判据：转折发生后，他有没有一次「不得不承认自己有这个欲望」的时刻？** 没有 → 这个转折和弧光无关，只是剧情事件。

## 七、完整填卡示例

```
【角色】沈砚 · id=c_shenyan｜陈留县仵作
【起点】父亲死后顶差，月俸三钱，欠药铺二两｜自认该是读书人，做仵作只是权宜
        落差：每一件仵作活都在证明他不是读书人
        缺：一个能承认「我就是仵作」的理由
【显性目标】三个月内拿到父亲案的卷宗（可被阻挠：衙门规矩不许仵作调卷）
【隐性欲望】想让父亲真的有罪｜根源：九岁替父磨刀，父亲说「仵作的刀不能见血」，父亲却死在刀下
【心理阈值】绝不：验自家人的尸｜破例条件：唯一的线索在尸身上，且没有第二个人能验
【能力上限】能：验伤、辨毒、从尸斑推断死亡时辰｜绝做不到：验骨（受 rules/仵作行规 约束）
【转折】第 12 回 — 二叔给他两个选择：交刀留下，或带刀滚 — 失去族籍、父亲的刀、阿禾的信任 — 为何不可逆：族籍一旦除名，祠堂永不许入
【终点】他不再需要「读书人」这个身份来证明自己｜与起点的反差：为了活着可以低头 → 为了不低头宁愿死（价值序维度）
【禁区】这个设定挡住「靠家世翻身」的写法
```
