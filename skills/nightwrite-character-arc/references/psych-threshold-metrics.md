# 心理阈值的量法

SKILL.md 只给了「坏：他很重感情 / 好：他不会丢下同伴，哪怕会输；唯一破例条件：同伴已经变成敌人」。这份把阈值的**写法、量法、判法**全部量化。

**核心问题：绝大多数阈值写成了「性格形容词」，结果既判不了正文，又会在关键情节挡住作者。**

---

## 一、阈值的三段结构

一条合格的阈值必须有三段：

```
绝不【做某事】，哪怕【代价】；破例条件：【具体触发场景】
```

| 段 | 作用 | 缺失后果 |
|---|---|---|
| **绝不 + 具体行为** | 提供判定依据 | 缺 → 判不了越界 |
| **哪怕 + 代价** | 提供强度（这个阈值有多硬） | 缺 → 读者不知道这有多难 |
| **破例条件** | 提供出口 | 缺 → 关键情节卡死，作者只能硬破 |

### 合格 vs 不合格

| 写法 | 判定 |
|---|---|
| 「他很重感情」 | 不合格：无行为、无代价、无破例 |
| 「他不会丢下同伴」 | 半合格：有行为，无代价，无破例 |
| 「他不会丢下同伴，哪怕会输」 | 半合格：有强度，仍无破例 |
| 「他不会丢下同伴，哪怕会输；破例条件：同伴已经变成敌人」 | **合格** |
| 「他不会丢下同伴，哪怕全队死光；破例条件：无」 | **不合格**：破例条件为「无」= 会在关键情节卡死 |

## 二、阈值的三个量

### 量 1：硬度（H）

```
H = 违反这条阈值，他愿意付出的最大代价 ÷ 这条阈值保护的东西的价值
```

实际操作简化成三档：

| 硬度 | 含义 | 写法 |
|---|---|---|
| **H1 软** | 违反会不舒服，但会违反 | 「他一般不撒谎」 |
| **H2 中** | 违反需要重大理由 | 「他不撒谎，哪怕对自己不利」 |
| **H3 硬** | 违反等于不是他 | 「他不撒谎，哪怕会死」 |

**判据：卡上必须标 H 档。** 不标 → 无法判越界严重程度。

### 量 2：破例成本（C）

破例不是免费出口，必须有成本。

```
C = 破例后他失去什么
```

| C 档 | 破例后 |
|---|---|
| **C1** | 只损失面子/一晚失眠 |
| **C2** | 损失一段关系或一个原则性让步 |
| **C3** | 损失身份/信念（这一次破例改变了他） |

**C3 破例不能超过 1 次。** 一个角色第二次 C3 破例，读者会认为「他其实没这个阈值」。

### 量 3：触发精度（P）

破例条件的**具体程度**。

| P 档 | 写法 | 问题 |
|---|---|---|
| **P1 模糊** | 「情况特殊时」 | 无法判定 |
| **P2 半具体** | 「同伴遇到危险时」 | 可判，但太宽（几乎所有情节都符合） |
| **P3 具体** | 「同伴已经变成敌人，且只有他能杀」 | 可判，且窄 |

**P2 是常见陷阱**：「同伴遇到危险」意味着每一章都可能破例，阈值等于没有。**P2 的破例条件必须加一个「且」——两个条件同时成立。**

## 三、阈值的三种类型

不是所有阈值都是「不做某事」。三类要分别写：

### 类型 1：禁令型（绝不做什么）

「绝不验自家人的尸」

**判定**：正文里有没有他做了这件事？有 → 检查破例条件是否成立。

### 类型 2：义务型（必须做什么）

「必须给每一个死者合眼」

**判定**：正文里有没有他遇到该做但没做的情形？有 → 检查破例条件。

**义务型比禁令型更难判**，因为「没做」是隐性的。判法：**每一章问一次「本章有没有触发这个义务的场景？」** 有且在场景中他没做 → 越界。

### 类型 3：代价型（做某事必须付什么）

「每验一次尸，他会少睡一夜」

**判定**：正文里他做了这件事，有没有演出代价？没演出 → 不是越界，是**账本失效**（这条阈值形同虚设）。

**代价型最容易写废**，因为写手会忘。判据：**做了这件事的章，必须有一处提到代价。**

## 四、越界判定流程

```
1. 正文里有无一个行为，与某条阈值直接冲突？
   （禁令型：他做了「绝不」的事
     义务型：触发场景中他没做「必须」的事
     代价型：他做了带代价的事，但无代价演出）
   ↓ 有
2. 该场景是否满足破例条件？
   （逐条比对破例条件的具体字句，不许「差不多」）
   ↓ 不满足 → 越界
3. 若满足破例条件，检查破例成本是否演出（C 档）？
   ↓ 未演出 → 半越界（阈值被白用）
```

### 步骤 2 的严格性

**「差不多」不算满足。** 破例条件写「同伴已经变成敌人」，正文里同伴只是「不再信任他」——不满足。

**判据：把破例条件当法条读，逐项打勾。** 有一项不打勾就是不满足。

### 三个免责情形（不算越界）

| 情形 | 判据 |
|---|---|
| **身份已变** | 他在这之前经历了身份变化（转折之后），旧阈值不再适用。必须在卡上更新 `state` |
| **不可靠叙述** | 视角人物认为他做了，实际没做（或反之）。必须后文有澄清 |
| **成长弧终点** | 已经到达终点的角色，旧阈值被新的取代。必须卡上有 `arc` 终点 |

**「身份已变」必须更新卡**。只靠正文解释不算——`state` 不更新，后面每一章都会误判。

## 五、五个常见阈值写法及其修法

### 写废 1：「他有底线」

**修法**：把「底线」换成一个具体行为。

> 「他不杀已经放下武器的人。H3。破例：对方放下武器后又伤了人。」

### 写废 2：「他很孝顺」

**修法**：义务型。

> 「他每月初一必须回家一趟，哪怕当天有差事。H2。破例：差事涉及人命。」

### 写废 3：「他怕水」

**修法**：这是弱点不是阈值。阈值是「他不会因为怕水而……」

> 「他不会下水，哪怕能救人也只在岸上想办法。H2。破例：落水的是他妹妹。」

### 写废 4：「他重承诺」

**修法**：禁令 + 破例。

> 「他答应的事一定做到，哪怕对自己不利。H3。破例：承诺是在被胁迫下给的。」

### 写废 5：破例条件写「无」

**修法**：必须给一个。

> 原：「他绝不说谎。破例：无。」
> 改：「他绝不说谎。破例：说谎能保住别人的命，且他自己承担后果。」

## 六、阈值的数量与配置

**一个角色配几条阈值？**

| 角色重要度 | 阈值数 | 配置 |
|---|---|---|
| **主角** | 3–4 条 | 1 条 H3 禁令 + 1 条义务 + 1 条代价型 + 1 条 H2 软阈值（供成长用） |
| **重要配角** | 2 条 | 1 条 H3 + 1 条 H2 |
| **功能性配角** | 1 条 | 1 条 H2（够用来判一次越界） |
| **背景人物** | 0 条 | 不建卡 |

**超过 4 条阈值的主角会写不动**——因为剧情每推进一步都要检查四条禁令。

**只有 H3 没有 H2 的角色会变成石头**——他从不妥协，读者会觉得假。H2 的存在是为了让角色在次要场合可以被推动。

## 七、阈值与剧情的咬合

### 咬合规则 1：转折必须触发一条 H3 阈值

**判据**：转折那一回，角色有没有被迫在「守阈值」和「达成目标」之间选？

- 有 → 咬合
- 没有 → 转折与阈值无关（可以，但弧光弱）

### 咬合规则 2：每 10 回至少用一次阈值

**判据**：搜「阈值相关行为」在已写章的分布。10 回内一次都没有 → 这条阈值是死的。

**死的阈值应该删掉**，不然它只是卡上的一行字。

### 咬合规则 3：破例必须有回响

破例之后，必须有一处（可以是几回之后）提到这次破例的后果。

**判据**：破例回之后 5 回内，有无一句提到「上次那件事」？无 → 破例白破。

## 八、卡上的写法（可复制）

```
【心理阈值】
  T1 [禁令型·H3] 绝不验自家人的尸
      哪怕代价：放弃唯一的线索
      破例条件：线索在尸身上，且没有第二个人能验（两个条件同时成立）
      破例成本：C3（做完他会认为自己不配当仵作）
  T2 [义务型·H2] 必须给每一个死者合眼
      破例条件：有活人等不及（须当场二选一）
      破例成本：C2
  T3 [代价型] 每验一次尸，少睡一夜
      演出要求：做了这件事的章，必须有一句提到失眠
```

**三条必须带的信息**：类型 + 硬度、破例条件（具体到可打勾）、破例成本档位。
