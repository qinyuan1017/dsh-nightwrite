# 读者画像卡

定下**这本书伺候谁**。画像是所有体验判断的基准：同一段文字，对不同的画像可以是加分也可以是致命伤。

## 画像卡九项（缺一项不算卡）

| 项 | 要写出什么 | 反例 |
|---|---|---|
| 目标读者 | 年龄段 + 性别倾向 + 阅读资历 | 「年轻人」 |
| 阅读场景 | 通勤 / 睡前 / 摸鱼 / 蹲坑（决定单章篇幅与分段） | 「碎片时间」 |
| 雷点 | 3 条以上，踩到就走 | 「不喜欢虐」 |
| 爽点 | 3 条以上，触发就留 | 「喜欢爽」 |
| 耐心阈值 | 能忍多少字没进展 | 「耐心一般」 |
| 付费动机 | 为什么愿意掏钱（追连载/看结局/追作者/社交） | 「喜欢就付」 |
| 替代品 | 读者不看你时会看什么（3 个具体书名类型） | 「同类小说」 |
| 情绪需求 | 他从书里想拿走什么（解压/代入/智力快感/情感代偿） | 「想放松」 |
| 弃书触发 | 什么情况下他会直接退出（不是不喜欢，是走人） | 「不好看就走」 |

## 执行步骤

**第 1 步：从 brief 起手，但不照抄**

`outline.get` → `brief` 的 `genre / audience / tone`。这只是粗分类，必须逐项具体化到上表的粒度。「男频玄幻」→「25-35 岁男性，读过 20 本以上同类型，对境界体系熟到能挑错」。

**第 2 步：耐心阈值要给数字**

```
能忍 <n> 字没有推进；
章末钩子无效连续 <n> 章会弃；
单章超过 <n> 字会跳读。
```

数字来自 `pacing` 与阅读场景：通勤 8 分钟 ≈ 3000 字，那单章超过 3000 字就会被跳读。

**第 3 步：雷点/爽点要能判定**

- 坏：「不喜欢啰嗦。」
- 好：「连续两段环境描写就跳读。」

每条都必须能对应到正文里的具体现象。

**第 4 步：写弃书触发的三级**

```
一级（皱眉继续）：<什么情况>
二级（开始跳读）：<什么情况>
三级（直接退出）：<什么情况>
```

**第 5 步：落盘**

写进 `ledger.upsert`（kind=`highlights`，`name='读者画像'`），让读者报告、弃书检查、付费卡点都能引用。

## 输入

- `outline.get` 的 `brief`
- 同类作品的公开信息（若有，可标来源）

## 输出格式

```
【目标读者】<年龄> · <性别倾向> · <资历>（读过 <n> 本同类，熟悉 <…>）
【阅读场景】<场景> → 单章宜 <n> 字，段落宜 <n> 行内
【雷点】1.<可判定> 2.<…> 3.<…>
【爽点】1.<可判定> 2.<…> 3.<…>
【耐心阈值】无推进可忍 <n> 字｜无效钩子可忍 <n> 章｜单章超 <n> 字跳读
【付费动机】<追连载/看结局/追作者/社交> — <为什么是这一类>
【替代品】<类型 A>、<类型 B>、<类型 C> → 本书的差异化是 <…>
【情绪需求】<解压/代入/智力快感/情感代偿> — <从哪看出来>
【弃书触发】一级 <…>｜二级 <…>｜三级 <…>
【落盘】ledger.upsert 成功
```

## 检查清单

- [ ] 九项全部有具体值，没有一项是空标签
- [ ] 耐心阈值给了三个数字
- [ ] 雷点/爽点每条都能对应正文现象
- [ ] 弃书触发了分三级
- [ ] 替代品写了 3 个具体类型，且写了差异化
- [ ] 与 `brief` 的 `genre / audience / tone` 不矛盾
- [ ] 已落盘

## 禁止事项

- 不许评价具体章节的文笔。
- 不许查设定 Bug。
- 不许写「所有读者都会喜欢」——画像必然排除一部分人。
- 不许用「年轻人」「喜欢爽」这类无法判定的标签。
- 不许在画像里写作者的期望（「希望读者觉得深刻」），只能写读者的实际状态。
