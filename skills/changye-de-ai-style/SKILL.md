# 去 AI 味

只动**表达层**：怎么说话。不动**内容层**：发生了什么、谁是谁。

## 执行步骤

**第 1 步：拿词表与风格基准**

- `changye_op` → `aistyle.get`：拿 `words`（内置词表）、`custom`（已加的词）、`disabled`（停用词）。
- 抽 3-5 章 `accepted` 章节作风格基准（没有 `accepted` 就拿最长的几章）。

**第 2 步：算风格卡（四项硬指标）**

```
平均句长 = 总字数 ÷ 句数
短句占比 = 句长 ≤8 字的句数 ÷ 总句数
平均段长 = 总字数 ÷ 段数
对白占比 = 对白字数 ÷ 总字数
```

把它和目标章的数字并排放。差异超过 30% 的那一项，就是这次改稿的主攻方向。

**第 3 步：扫五类结构性痕迹（重点不是词，是模式）**

| 模式 | 长什么样 | 怎么改 |
|---|---|---|
| **对照句滥用** | 「不是X，而是Y」连用两次以上 | 留一处，其余改成直接陈述 |
| **排比堆叠** | 三句同结构并列，且都在抒情 | 砍到一句，把另两句换成动作 |
| **段末总结** | 每段最后一句都在升华/收口 | 删掉总结句，让段落停在动作上 |
| **情绪命名** | 「他感到一阵愤怒/一阵酸楚」 | 删掉命名，只留身体反应或动作 |
| **抽象替具体** | 「气氛凝固」「空气仿佛静止」 | 换成可拍摄的画面：没人敢先动筷子 |

**第 4 步：逐处给对照（原 → 改 → 因）**

每一处必须回答「命中哪条模式」。答不出模式的就是凭喜好，删掉这条改动。

**第 5 步：算改动后指标，回头比**

改完重算风格卡。四项里至少两项向基准靠拢，否则这次改稿无效，回第 3 步。

**第 6 步：词表维护**

新发现的高频 AI 词 → `aistyle.save` 加进 `custom`；作者点名不要的词 → 加进 `disabled`。

## 输入

- 待改正文（`chapter.get`）
- `aistyle.get`：三份词表
- `accepted` 章节 3-5 章：风格基准
- `ledger.get` 的 `characters`：语言基因（改对白必须遵守）

## 输出格式

```
【风格卡】平均句长 <n> 字｜短句(≤8字) <n>%｜平均段长 <n> 字｜对白 <n>%
        目标   <n> 字｜<n>%｜<n> 字｜<n>%
【AI 味密度】<n> 处/千字 → <n> 处/千字
【修改对照】
1. 第 <X> 段
   原：<原句>
   改：<改后句>
   因：<命中：段末总结 / 情绪命名 / …>
2. …
【未动的可疑处】<有疑点但改动会伤事实或人物，留给审校：第 X 段……>
【词表更新】新增 <词>×<n>｜建议停用 <词>
```

## 检查清单

- [ ] 拿到 `aistyle.get` 的三份词表
- [ ] 抽了 3 章以上 `accepted` 作基准
- [ ] 风格卡四项都算出来了，有具体数字
- [ ] 五类模式逐个扫过，不是只查禁用词
- [ ] 每处改动都注明了命中的模式
- [ ] 改后指标重算过，至少两项向基准靠拢
- [ ] 对白改动遵守了 `characters` 的语言基因
- [ ] 没有一处改动改变了事件本身
- [ ] 词表变更已通过 `aistyle.save` 落盘

## 禁止事项

- 不许改剧情走向。一句话里发生的事不许变。
- 不许改人物设定。改的是「他怎么说」，不是「他说什么」。
- 不许顺手修设定冲突。发现了记进「未动的可疑处」，交给审校。
- 不许调 `chapter.save`。只出对照，落盘由写手或修订岗执行。
- 不许一次性重写超过正文 30%。超了说明是结构问题，该走 `changye-revision-pass`。
- 不许把「改成我喜欢的风格」当成去 AI 味。目标是像**这本书的作者**。
- 不许把风格卡当摆设：改了但不看指标，等于没改。
