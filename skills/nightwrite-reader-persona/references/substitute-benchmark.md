> 适用：要填画像卡的「替代品」一项、或者想验证「这本书凭什么让人从别处换过来」时读这份。

# 替代品对标

替代品不是竞品分析，是回答一个问题：**读者此刻正在看别的东西，他为什么会换到这本书？**

答不出这个问题，书的差异化就是空的，改稿时所有取舍都失去依据。

## 三层替代品

### 第一层：同类型头部

读者看过、且记得的那几本。

**写法**：

```
替代品 A：<同类型头部作品，指名或指类型>
读者会拿它比什么：<具体到 2–3 个可比的维度>
本书在比什么：<赢在哪 / 平在哪 / 输在哪>
```

**例**：

```
替代品 A：以漕运为背景的历史权谋（头部两三本）
读者会拿它比：① 漕运细节的真实度 ② 权谋的层数 ③ 主角的起点高低
本书在比什么：细节真实度赢（本书每场冲突都长在漕运流程上）｜权谋层数平（都是三层）｜起点更低（输在代入速度，赢在后期空间）
```

**关键**：必须写「输在哪」。只写赢的差异化是自欺——读者会立刻发现输的那一项，然后觉得被骗。

### 第二层：隔壁类型替代

读者在等更时会转去的类型。

**判据**：这本书的**核心情绪需求**（画像第九项旁边那个），在哪个类型里也能获得？

| 本书的情绪需求 | 隔壁替代类型 |
|---|---|
| 解压/打脸 | 短剧、系统流、无敌流 |
| 代入/被认可 | 都市日常、种田、家族流 |
| 智力快感 | 悬疑、推理、硬科幻 |
| 情感代偿 | 言情、群像、治愈 |

**写法**：

```
替代品 B：<隔壁类型>
读者从这里能拿到同样的 <情绪需求>
本书的差异：<在同一个需求上，本书多了什么 / 少了什么>
```

**例**：

```
替代品 B：短剧式的快节奏打脸
读者从这里能拿到同样的解压
本书的差异：多的是「打脸有代价」（每次赢都掉一层关系），少的是「即时满足」（本书要等 3–5 章）
```

**这一层的用途**：如果本书在「少了什么」这一项上输得太多，说明画像里的「耐心阈值」定得太乐观——读者不会为了「多了的那点深度」等 5 章。

### 第三层：非小说替代（最重要的）

**读者的真正竞争者不是另一本书，是短视频、游戏、剧集。**

这一层必须写，且必须诚实：

```
替代品 C：<具体形态>（短视频 / 手游 / 长剧 / 综艺）
它给的东西：<即时、低成本、不需要连续投入>
本书必须给的补偿：<读者为它付出的连续投入，换到了什么它给不了的>
```

**例**：

```
替代品 C：短视频（15 秒一个爽点，无需记忆前情）
它给的东西：零门槛、零记忆负担、即时反馈
本书必须给的补偿：读者要记住 20 个人名、跟上三条线，换来的是「一个能持续几十小时的、有累积感的世界」——这个累积感是短视频结构上做不到的
```

**这一层写不出来，说明差异化是假的**。因为读者放弃这本书的成本极低（换个 App 而已）。

## 差异化的三种合格形态

### 形态一：别人写不了的细节密度

```
差异化：同类作品里没人写 <具体领域> 的流程细节，本书的每场冲突都长在这个流程上。
```

**判据**：这个领域，普通作者要查多久才能写对？如果答案是「一天」，那不是差异化（谁都能查）。

**合格例子**：漕运的过闸流程、仵作的验尸规程、票号的密押制度——这些需要长期积累，且读者能验证（因为写错了会被懂的人指出）。

### 形态二：结构上的独特设计

```
差异化：同类都是单主角线，本书是双线并行且读者知道两条线会在第 X 卷撞上，撞法未知。
```

**判据**：这个结构能不能用一句话说清，且读者一听就懂？能 → 合格。

**不合格**：「多视角叙事」——这是手法，不是差异化（很多书都用）。

### 形态三：情绪配方的新组合

```
差异化：同类要么纯爽要么纯虐，本书是「虐完必给一个具体的小胜」，且这个小胜永远由主角自己挣。
```

**判据**：这个组合，读者能不能在读完 3 章后说出「这书跟别的不一样」？能 → 合格。

## 差异化的三种假形态（必须排除）

| 假形态 | 为什么假 |
|---|---|
| 「文笔更好」 | 读者无法在 3 段内验证，且不为此换书 |
| 「设定更严谨」 | 严谨是**不出错**，不是**吸引力**。读者不会因为「这本没 bug」而选它 |
| 「人物更立体」 | 同上，这是评论家的词，不是读者的选择理由 |

**共同点**：这三项都是**质量维度**，不是**选择维度**。读者选书靠的是「我想看那个东西」，不是「这本质量更高」。

**判据**：把差异化那句话给一个没读过这本书的人听，他会不会产生「那我去看看」的念头？不会 → 假形态。

## 对标的具体做法

### 第一步：定三个可比维度

不要泛泛比「好坏」，定 2–3 个**可比的、具体的**维度。

| 维度类型 | 例 |
|---|---|
| 密度类 | 每千字的信息条数、爽点间隔 |
| 速度类 | 主角从起点到第一次翻身用了几章 |
| 深度类 | 一条支线的平均跨度（章） |
| 风格类 | 对白占比、句长、比喻密度 |

**选维度的原则**：选读者**能感觉到**的。读者感觉不到「视角一致性」，但能感觉到「爽点间隔」。

### 第二步：给本书和替代品各打一个值

不需要精确，只需量级正确。

```
维度        | 替代品 A | 替代品 B | 本书
爽点间隔    | 2–3 章   | 1 章     | 4–5 章
对白占比    | 40%      | 55%      | 28%
每条支线跨度 | 8–12 章  | 3–5 章   | 15–20 章
```

### 第三步：找「本书的位置」

三种位置，各有对应策略：

| 位置 | 含义 | 策略 |
|---|---|---|
| **极端位** | 在某个维度上远超所有替代品 | 把这个维度做成招牌，前 3 章就展示 |
| **中间位** | 在两项上都居中 | 危险位置：读者没有理由选你。必须在第三项上找极端 |
| **空白位** | 某个维度上没有任何替代品 | 最好的位置，但需要确认这个维度有人要 |

**中间位是最常见的失败位置**。诊断：三项维度里，如果没有任何一项本书是极端的 → 差异化不成立，无论怎么写那句「差异化」都是假的。

### 第四步：确认空白位有人要

空白位可能是没人做，也可能是**没人要**。

**判据**：这个维度上的极端值，能不能对应到画像卡里的某一项雷点/爽点？

- 能 → 有人要
- 不能 → 这个空白位是伪需求（比如「全书没有一句对白」是个空白位，但它不对应任何读者的爽点）

## 对标结果怎么用

对标不是为了「学替代品」，是为了三件事：

### 用途一：定耐心阈值

如果替代品 A 的爽点间隔是 2–3 章，本书是 4–5 章，那么画像卡的「章末钩子可忍章数」必须**比替代品更严**——因为读者会用 A 的节奏来要求本书。

```
本书钩子可忍章数 = 替代品的实际间隔 + 1
```

### 用途二：定前 3 章的展示重点

前 3 章必须展示**本书最极端的那个维度**。如果差异化是「细节密度」，前 3 章就要有密集的流程细节（而不是等到第 10 章）。

**判据**：一个只读过前 3 章的读者，能不能说出「这书跟别的不一样在哪」？

### 用途三：定「不能输太远」的底线

对标表里「输」的那几项，必须设一条底线：

```
底线：<维度> 不低于替代品的 <n>%
```

超过底线的输 → 读者会放弃（因为这在别的书里是基本盘）。

**例**：对白占比 28% vs 替代品 40%，输 30%——如果这个差值让读者觉得「这书读起来费劲」，说明超过了底线，必须调。

## 报告格式

```
【替代品 A】<类型/作品> — 读者比什么：<2–3 维度>｜本书赢 <…>｜平 <…>｜输 <…>
【替代品 B】<隔壁类型> — 同一情绪需求：<…>｜本书多了 <…>｜少了 <…>
【替代品 C】<非小说形态> — 它给 <…>｜本书必须补偿 <…>
【对标表】
  维度 | A | B | 本书 | 位置
  <…>  | <…> | <…> | <…> | <极端/中间/空白>
【差异化】<一句话> → <合格/假形态> — 判据：<能不能让人产生换书念头>
【空白位确认】<维度> 对应画像的 <雷点/爽点>：<有/无>
【底线】<哪项不能输超过 n%>
【前 3 章展示】<哪个维度必须在前 3 章出现>
```

## 一个反直觉的结论

**替代品写得越清楚，越容易发现「这本书没有差异化」。**

这个发现越早越好。因为差异化的缺失不是改稿能解决的——它要求在开书前调整（换设定、换结构、换情绪配方）。写完 100 章才发现没有差异化，只能硬着头皮写完。

所以画像卡的九项里，替代品这一项应该在**开书前**完成，而不是写完第一卷才补。它是唯一一项「补了也没用」的字段。
