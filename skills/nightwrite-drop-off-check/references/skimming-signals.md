> 适用：要判断读者「会不会跳读、从哪里开始跳」时读这份，取八种跳读信号的文本特征与定位方法。

# 跳读信号的文本特征

跳读和弃书不是一回事。弃书是退出，跳读是**还在但不读了**。跳读更难发现，因为读者不会留下任何反馈——他只是在你的长段上滑得快了几秒。

判据只有一个：**读者在这一段里有没有可能错过重要信息而毫无损失？** 有可能 → 这段会被跳。

## 八种信号（按被跳概率从高到低）

### 信号一：连续三段以上的环境/心理描写

**文本特征**：连续 3 段（每段 ≥3 句）没有人物动作、没有对白、没有物件变化。

**为什么被跳**：读者读网文是追事件，描写不产生事件。一段描写的作用是建立空间，建立了就该走。

**阈值**：
- 连续 2 段纯描写 → 可接受
- 连续 3 段 → 跳读概率明显上升
- 连续 4 段以上 → 这一段几乎必被跳

**定位方法**：给每段打标签（动作/对白/描写/信息/关系），找连续 3 个以上「描写」。

**修法**：不是在段落里加动作点缀，而是**把描写拆开塞进动作里**。原著场景描写 + 主角走过去踢了一脚碎石 + 继续描写——这样每两段就有一个动作。

### 信号二：段首出现「这」「那」「他」「她」的指代复盘

**文本特征**：段首句是「这件事让他想起了……」「那天的情形……」「他知道自己必须……」。

**为什么被跳**：这类句子不携带新信息，是作者在帮读者回顾。读者不需要回顾——他刚读过。

**阈值**：单章出现 **≥3 次**即为信号。这类句子每次都消耗读者 0.5 秒且零回报。

**修法**：删掉句子，直接从下一个具体动作开始。如果删掉后读者会失去上下文，说明问题在上一段（上一段没写清），不在这一句。

### 信号三：解释链（发生了什么 + 为什么会这样 + 这意味着什么）

**文本特征**：一个事件后面跟着 2 句以上的解释。

```
他把它塞进袖子里。他不能让人看见——上次就是因为这个被人告了，而这次的官差比上次来的更懂规矩。
```

**为什么被跳**：读者自己会推。「他不能让人看见」是作者在替读者思考，读者会直接跳过这句去读后文。

**阈值**：
- 单章 3 处以上 = 信号
- 密度 >5 处/千字 = 强信号（详见 `nightwrite-de-ai-style/references/explanation-chain-density.md`）

**修法**：删掉解释，只留动作。如果解释里有必要信息，把它改成**后文的一次行为**来证明。

### 信号四：模板化微动作

**文本特征**：`他深吸一口气` `他眼神一凝` `他嘴角勾起一抹弧度` `他心中一凛`

**为什么被跳**：这些动作没有信息。读者读了等于没读，几次之后就形成了「这类句子可以跳过」的习惯——而习惯一旦形成，会连带跳过所有类似句式。

**阈值**：同一个微动作单章出现 ≥3 次 = 信号；全书每万字 >3 次同类 = 模板化。

**定位方法**：建一个微动作清单，全文统计。详见 `nightwrite-de-ai-style/references/micro-action-repetition.md`。

### 信号五：同一信息以不同措辞重述

**文本特征**：同一件事，本章内被说了两次以上，且第二次没有新侧面。

```
「他左臂有伤，不能提重物。」          （第 3 段）
……
「他试着把箱子拎起来，左臂一阵钻痛。」    （第 18 段，但读者早已知道）
```

第二处如果只是**验证**已知信息，没有新限制（比如「疼到握不住刀」才是新信息），就是重述。

**阈值**：单章同一信息重述 **≥2 次** = 信号。

### 信号六：过渡段的「然后体」

**文本特征**：`然后他去了……` `随后他来到……` `接着……` `过了一会儿……`

**为什么被跳**：这类句子是**连接件**，不是内容。读者会直接跳到下一个有内容的句子。

**阈值**：单章 ≥3 处 = 信号。

**修法**：用硬切代替（详见 `nightwrite-write-chapter/references/scene-transitions.md`）。删掉「然后他去了城西」，直接写「城西的米铺关着门」——读者自己知道他在城西。

### 信号七：信息灌段（设定/背景的集中交代）

**文本特征**：一段落里有 2 条以上新信息，且都是「读者不知道但也不急着知道」的。

**为什么被跳**：读者不觉得自己需要这些信息。它们不是在被需要的时候给的，是作者觉得该交代了。

**阈值**：单段 ≥2 条新信息 = 信号；连续 3 段纯给信息 = 强信号。

**定位方法**：按 `nightwrite-chapter-hook/references/information-release-rhythm.md` 的口径数每段新信息条数。

### 信号八：对白里的说明文

**文本特征**：

```
「你也知道，我们家族三百年前因为那场战事迁到这里，祖上定下规矩不入仕，所以我父亲这一代才做了行商……」
```

**为什么被跳**：真实对话里没人这么说话。读者会立刻识别为「作者在借人物讲课」，然后跳过整段对白。

**阈值**：单句说明语 >15 字，或说明语/对白比 >0.8 = 信号。

**判据**：这句话如果换个场合（比如对一个陌生人）说不出口，就是说明文。

## 跳读概率的估算

给一段文字，按八项计分（每项命中 1 分）：

| 得分 | 跳读概率 | 处置 |
|---|---|---|
| 0–1 | 低（<10%） | 不动 |
| 2–3 | 中（10–35%） | 挑最长的那个信号修 |
| 4–5 | 高（35–60%） | 必改，两处以上 |
| ≥6 | 极高（>60%） | 这段等于没写，重写 |

**计分注意**：同一段落命中多项时，按最严重的一项算权重更高——一段同时是「连续描写」和「然后体」和「解释链」，实际跳读概率接近 90%。

## 跳读的三个连带后果

跳读不是独立事件，它会连锁：

### 后果一：章末钩子失效

读者跳过了中段，直接到章末，他的情绪没有被推到该到的位置，所以末段的钩子对他不起作用。**症状**：作者觉得「章末钩子明明很好」，读者反应平平。

**定位**：看 B 窗口中空转的字数。超过 1500 字时，末段钩子的实际效果会打折。

### 后果二：下一章的困惑

跳读避开的信息，读者没有。下一章用到时，读者会觉得「这里没交代」。

**症状**：读者反馈「看不懂」，但你查了确实写了。**这时不要补写，去找那段是不是被跳读了**。

### 后果三：形成跳读习惯

读者一旦在这本书里学会了「这些段落可以跳」，他会扩大范围。第一次跳的是连续描写，第三次会跳过所有描写，第五次会跳过所有非对白段。

**这是最严重的**：到这一步，书的实际阅读量只有字数的 40–60%，所有精心写的场景都白费。

## 定位的执行流程

1. **切段打标签**：全章按自然段切，每段打一个主标签（动作/对白/描写/信息/关系/过渡）。
2. **找连续同标签**：连续 3 段以上同标签 → 查信号一、二、六。
3. **逐段数新信息**：按 `information-release-rhythm.md` 口径 → 查信号七。
4. **扫微动作与解释链**：全文正则式扫描 → 查信号三、四。
5. **查重述**：列出本章信息清单，找重复项 → 查信号五。
6. **查对白说明文**：抽对白段，量说明语占比 → 查信号八。
7. **计分**：按八项给每段打分，输出高风险段清单。

## 报告格式

```
【跳读风险】总得分 <n>/8 → <低/中/高/极高>
【逐项】
  连续描写：第 <a>-<b> 段（<n> 段）→ 命中
  指代复盘：第 <n>/<n>/<n> 段首 → 3 次 → 命中
  解释链：<n> 处（密度 <n>/千字）→ <命中/未命中>
  模板微动作：<n> 处（「深吸一口气」×<n>）→ <命中/未命中>
  信息重述：<哪条> ×<n> 次 → <命中/未命中>
  然后体：<n> 处 → <命中/未命中>
  信息灌段：第 <n> 段（<n> 条信息）→ <命中/未命中>
  对白说明文：第 <n> 段（说明语 <n> 字 / 对白比 <n>）→ <命中/未命中>
【最高风险段】第 <a>-<b> 段（<n> 字）— 命中 <n> 项 — 预估跳读概率 <n>%
【连带影响】章末钩子实际效果 <打折/正常>｜下一章可能困惑：<哪条信息>
【修法方向】<只给方向，不给成稿>
```

## 一个反直觉的结论

**跳读风险最高的不是写得差的地方，是写得好的地方。**

作者写得最用力的段落（精心描写的场景、反复打磨的心理），往往是跳读率最高的——因为作者用力时倾向于**加长**，而长度本身就是跳读的诱因。

所以检查时应优先看**作者最满意的段落**。这个规律在自查时反复成立。
