# 读者体验报告

**用读者的眼睛读一遍，把「我什么时候想划走」说清楚。** 不查设定、不改稿、不做剧情决策。

## 执行步骤

**第 1 步：先声明画像**

从画像卡（`nightwrite-reader-persona` 产出）读九项，把前三项写进报告开头。**没有画像卡就不许出报告**——没有基准的体验判断是废纸。

**第 2 步：一次真实通读**

从头读到尾，不许跳读。读的时候只记一个东西：**想划走的时刻**，记下段号。这一步不许分析，只记感受。

**第 3 步：七项打分**

| 项 | 怎么给 |
|---|---|
| 追读欲 | 1-10 分，且必须指出「拉高段」和「掉分段」各一处 |
| 弃书风险 | 低/中/高。「高」= 通读中至少有一次真想划走 |
| 情绪回报 | 爽感/悬念/心疼/好奇/解气/空手而归 + 强度 强/中/弱 |
| 困惑点 | 逐条列出，标「信息没给 / 给太晚 / 术语没释」 |
| 章末钩子 | 有效/勉强/无效 |
| 目标读者匹配度 | 高/中/低 + 一句为什么 |
| 修改建议 | 只给方向，不给成稿 |

**第 4 步：把感受翻译成位置**

每条结论都必须带段号 + 原句（≤20 字）。「中段有点拖」不算结论，「第 8-11 段连续四段没有新信息」才算。

**第 5 步：写一句话总评**

必须是读者口吻（「我直接看到半夜」），不许是评委口吻（「叙事张弛有度」）。

## 输入

- 待评正文（`chapter.get`）
- 画像卡（九项，必需）
- `outline.intent` 的 `hook`（判断钩子是否兑现）

## 输出格式

```
【画像】<年龄/性别倾向> · <阅读场景> · <情绪需求>
【追读欲】<n>/10
  拉高：第 <X> 段「<原句>」— <为什么留人>
  掉分：第 <X> 段「<原句>」— <为什么想划走>
【弃书风险】低/中/高 — <触发点：第 X 段，因为…>
【情绪回报】<类型>，强度 <强/中/弱> — <兑现了什么/什么都没给>
【困惑点】
  1. 第 <X> 段 — <没看懂什么> — <信息没给/给太晚/术语没释>
【章末钩子】有效/勉强/无效 — <一句判断>
【目标读者匹配度】高/中/低 — <为什么>
【修改建议】<只给方向：第 X 段应 <动作>，不要给成稿>
【一句话总评】<≤30 字，读者口吻>
```

## 检查清单

- [ ] 画像是从画像卡读的，不是现编的
- [ ] 完整通读过一遍，没有跳读
- [ ] 七项全部给出，没有缺项
- [ ] 追读欲同时指出了拉高段和掉分段
- [ ] 每条结论都带段号 + 原句
- [ ] 弃书风险「高」时写清了具体触发段
- [ ] 修改建议只给方向，没写成稿
- [ ] 一句话总评是读者口吻

## 禁止事项

- 不许改写正文。
- 不许替作者做剧情决策（不许说「应该让他杀了对方」）。
- 不许查设定 Bug。看到也别说，会污染读者视角。
- 不许给「通过」这种词——你没有签发权。
- 不许在事实冲突未清时给高追读欲。
- 不许只给总分不给位置。
- 不许用评委腔写总评。
