> 适用：第 3 步「七项打分」时读这份；判「这栏该给几分」时读这份。

# 七栏体验表的评分锚点

SKILL.md 给了七栏的名字和粗口径。这份给**每栏 1/3/5 分的具体锚点**（追读欲按 1–10 分给，锚点按 1/4/7/10 四档），以及锚点之间的灰区怎么判。

**总原则：锚点看「读者做了什么」，不看「文本写得怎么样」。** 读者划走了就是划走了，跟作者想表达多深刻无关。

---

## 一、追读欲（1–10）

**不是问「好不好看」，是问「下一章开出来你会不会点」。**

| 分 | 读者的实际行为 |
|---|---|
| 1–2 | 读到 1/3 就想关掉，靠意志力读完 |
| 3–4 | 能读完，但心里在算「还剩多少」；不会主动找下一章 |
| 5–6 | 读完顺手点了下一章，但不记得这章讲了什么 |
| 7–8 | 读完立刻点下一章，且能复述这一章最关键的一个转折 |
| 9–10 | 读的时候忘了时间；读完想找人讨论 |

**给分流程**：
1. 先给整数分（1–10）。
2. 再找**拉高段**：全文追读欲最高的那一段，必然带一个信息/情绪/动作的具体变化。
3. 再找**掉分段**：全文追读欲最低的那一段。
4. 若「拉高段」在章末 200 字内，+1；若「掉分段」在章首 300 字内，−1。

**硬规则**：拉高段和掉分段都找不到 = 这章是平的，直接给 5，并在报告里写「全章无峰值」。

### 灰区判定

- 「7 还是 8？」→ 看有没有**复述记忆点**。读完能说出「他把婚书撕了」= 8；只能说「他在宴上」= 7。
- 「5 还是 6？」→ 看有没有**主动点下一章的动作**。有 = 6；只是「不反感」= 5。

---

## 二、弃书风险（低/中/高）

三档的判据是**读者的动作**，不是文本的缺陷数。

### 高

通读中**至少一次真想划走**。

必须写清：触发段号 + 触发原因（三类之一）：
- **看不懂**（信息缺口）
- **不在乎**（角色没有值得关心的东西）
- **被冒犯**（价值观/常识冲突）

### 中

没有想划走的瞬间，但**读完没有继续的动力**。

判据：读完这章，问「明天还看吗？」答案是「看情况」= 中。

### 低

读完**主动想看下一章**，且能说出下一章想看什么。

判据：能说出一个具体的期待（「想看他二叔怎么反应」）= 低。说不出 = 中。

### 灰区判定

| 情形 | 档 |
|---|---|
| 有一处想快速滑过（不是划走） | 中 |
| 有一处想划走但被后文救回来了 | 中（要在报告里写「救回段」） |
| 章首 300 字内就想划走 | 高（章首是最贵的位置） |
| 章末钩子无效且有想划走的段 | 高 |

---

## 三、情绪回报（类型 + 强度）

SKILL.md 给了六种类型：爽感/悬念/心疼/好奇/解气/空手而归。

### 类型的判定：问「读完这一章，读者身上多出来的那个东西是什么」

| 类型 | 判据（读完后读者的状态） |
|---|---|
| 爽感 | 有一种「该」的满足，通常来自压制→反打 |
| 悬念 | 有一个具体的「然后呢」卡在脑子里 |
| 心疼 | 对某个角色产生了身体性的不适（胸闷、想哭） |
| 好奇 | 想了解世界/机制/历史，不是想了解人物命运 |
| 解气 | 与爽感相近，但针对的是**前文积累的憋屈**被清算 |
| 空手而归 | 读完没有任何情绪增量 |

**「空手而归」不是六选一里的一项，是「前五项全不成立」的兜底。** 判空手而归时必须写清「本来期待什么，没给」。

### 强度

| 强度 | 判据 |
|---|---|
| 强 | 读完 5 分钟后还记得那个情绪 |
| 中 | 读的时候有，合上就淡了 |
| 弱 | 需要回想才能确认「哦，这里应该是想让我感动」 |

**判法**：不要在读完立刻判强度。报告要求：读完这一章后，**至少隔一个动作**（比如先去看别的章、或先写别的栏）再回来判强度。立刻判会高估。

### 灰区判定

- 「爽感和解气怎么分？」→ 爽感来自**当场**的压制反转；解气来自**前文旧账**被清算。
- 「悬念和好奇怎么分？」→ 悬念指向**人物命运**（他会不会死）；好奇指向**世界规则**（这个门派为什么存在）。

---

## 四、困惑点（逐条列）

每条的格式固定：`段号 + 没看懂什么 + 三分类`。

| 分类 | 判据 | 修法方向 |
|---|---|---|
| 信息没给 | 后文也没解释，读者永远不知道 | 补信息，或在后文给 |
| 给太晚 | 后文解释了，但解释时读者已经放弃理解 | 前移信息 |
| 术语没释 | 名词第一次出现没有上下文锚 | 加一句同位的解释 |

**阈值的量化**：
- 0 条 = 好（但要注意：0 条也可能意味着这章太浅）
- 1–2 条 = 正常
- 3–4 条 = 偏高，读者会开始跳读
- ≥5 条 = 高，直接影响弃书风险

**关键**：困惑点必须区分「作者的故意留白」和「作者的疏忽」。判据：这个困惑在**下一回**会不会被回答？会 = 故意留白，不算困惑点（但要在报告里记「故意留白 X 处」）；不会 = 疏忽。

---

## 五、章末钩子（有效/勉强/无效）

判据看**这一章的最后 150 字**。

### 有效

读完最后一句，脑子里自动冒出一个**具体的问句**，且这个问句是这章建立起来的。

### 勉强

- 冒出的问句很模糊（「后面会怎样」）
- 或问句成立但读者不在乎（因为前文没建立代价）
- 或钩子靠「他不知道……」这种叙述者越界句式撑起来

### 无效

- 最后一句是收束（「于是他睡下了」）
- 或最后一句是总结（「这一天，他成长了很多」）
- 或最后一句是新场景的开头（把钩子提前用掉了）

### 与 `outline.intent.hook` 的比对

SKILL.md 要求读细纲的 hook 判断是否兑现。三种结果：

| 结果 | 判法 |
|---|---|
| 兑现 | 正文最后 150 字实现了细纲 hook |
| 变形兑现 | 内容不同但功能相同（同样能引出问句）→ 算有效 |
| 未兑现 | 细纲承诺的钩子没出现 → 钩子栏最多「勉强」，并在建议里点名 |

## 六、目标读者匹配度（高/中/低）

这一栏问的不是「写得好不好」，是**「这章给的是不是这批人要的」**。

| 档 | 判据 |
|---|---|
| 高 | 这章的三个主要情节点，画像卡的「爽点」里有 ≥2 个被命中 |
| 中 | 命中 1 个，或命中的是「次要爽点」 |
| 低 | 一个都没命中；或命中的是画像卡「雷点」里的东西 |

**必须写「为什么」**：写「命中爽点 B（打脸）+ 爽点 D（身份揭露）」或「全章是画像卡雷点 C（主角被动挨打超过半章）」。

---

## 七、修改建议（只给方向）

**唯一格式**：`第 X 段应 <动作>，因为 <读者反应>`。

允许的动作只有四类：

| 动作 | 含义 |
|---|---|
| 补信息 | 在该段补一句让读者接得上的信息 |
| 前移 | 把这个信息/这个事件挪到更早 |
| 压缩 | 这几段合并，删掉重复 |
| 加变化 | 这一段缺一个状态变化，加一个 |

**禁止**：给成稿、给对白示范、说「应该让他杀了对方」（这是剧情决策）。

---

## 八、七栏之间的联动规则

七栏不是独立的。三条联动：

1. **弃书风险「高」时，追读欲不许 ≥7。** 有想划走的瞬间却给高分，是自相矛盾。
2. **情绪回报「空手而归」时，追读欲不许 ≥6。**
3. **困惑点 ≥5 条时，目标读者匹配度不许给「高」。**

违反任一条 = 报告内部不自洽，必须重判。

---

## 九、评分完成后的一句话总评

读者口吻，≤30 字。判据：**能不能想象这句话出现在评论区**。

- 能：「我直接看到半夜，就为了看他二叔什么时候翻车。」
- 不能：「本章叙事节奏紧凑，情绪层次丰富。」

**自检**：把总评念出来，如果听着像语文老师批作文，重写。
