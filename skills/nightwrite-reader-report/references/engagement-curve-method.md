> 适用：第 2 步通读时要在段号上记「想划走」、或要给整章画一条追读欲曲线时读这份。

# 追读欲曲线的量法

SKILL.md 只要求记「想划走的时刻」。实际报告里更常用的是**逐段曲线**：它能把「中段有点拖」变成「第 8–11 段连续四段的曲线都在 3 分以下」。这份给量法、给标注规范、给曲线形状的诊断表。

---

## 一、量法：五档段级标注

通读时**每一段**给一个 0–5 的整数，不写理由，只写分数。理由留到第 4 步再写。

| 分 | 读者此刻的状态 | 判断线索 |
|---|---|---|
| 5 | 忘了自己在读，只想往下 | 会不自觉地读快 |
| 4 | 想知道下一步 | 有明确的提问 |
| 3 | 正常往下走 | 没有提问，也不烦 |
| 2 | 有点想跳 | 眼睛开始找下一段的开头 |
| 1 | 想划走 | 会看还剩多少 |
| 0 | 已经出戏 | 开始想别的事 |

**「段」的定义**：一个自然段（含对白独立成段的短段）。段号从 1 开始，**标题不计段号**。

### 量法的三条纪律

1. **必须一次通读量完，不许回头改分**。回改会污染——你会用后文的信息给前文加分。
2. **不许写理由**。这一步写下理由，第 4 步就没法诚实判断了。
3. **不许因为「这段文笔好」给高分**。追读欲只看「想不想往下」。

### 段数不足时

一段少于 30 字的短对白区，**相邻 3 段合并为一个测量点**，避免碎段把曲线打散。

---

## 二、曲线的四个统计量

量完之后算四个数：

### 1. 均值

```
均值 = Σ分 ÷ 段数
```

| 均值 | 判定 |
|---|---|
| ≥4.0 | 强 |
| 3.5–4.0 | 良 |
| 3.0–3.5 | 中（多数章在这里） |
| <3.0 | 弱 |

### 2. 峰值位置

最高分所在段的**相对位置** = 段号 ÷ 总段数。

| 位置 | 判定 |
|---|---|
| 0–0.15 | 峰值太早，后文泄气（除非是章首炸弹写法） |
| 0.15–0.35 | 偏早，中后段会掉 |
| 0.35–0.65 | 正常 |
| 0.65–0.90 | 健康（最理想的区间） |
| 0.90–1.0 | 峰值在章末 150 字内，若同时是钩子，优秀；若不是钩子，说明前文太平 |

### 3. 谷值位置与长度

**谷** = 连续 ≥3 段分数 ≤2。

记录：起点段号、终点段号、长度。

| 谷长 | 判定 |
|---|---|
| 无谷 | 优 |
| 3–4 段 | 可接受，但要在建议里点名 |
| 5–8 段 | 有问题，读者会在这里跳读 |
| >8 段 | 严重，弃书风险至少「中」 |

### 4. 波动幅度

```
幅度 = 最高分 − 最低分
```

| 幅度 | 判定 |
|---|---|
| ≤1 | 太平（全章一个温度） |
| 2–3 | 健康 |
| ≥4 | 起伏剧烈，注意会不会是「一段惊艳一段崩」的拼接感 |

**幅度 ≤1 的章**，即使均值 4.0，也要在报告里写「曲线过平，读者记不住这章的峰值」。因为**读者记住的永远是峰和谷，不是平均**。

## 三、四种曲线形状的诊断

把分数连成折线，看形状。

### 形状 A：上升型 `／`

```
2 3 3 4 4 5 5
```

- 判定：**健康**。前提是峰值落在 0.65–0.90 区间。
- 风险：前 15% 分数太低（≤2）会让读者在第一章就退出。
- 修法：前 3 段必须有一段 ≥3。必要时把后文的一个小变化前移。

### 形状 B：山峰型 `∧`

```
2 3 5 4 3 2
```

- 判定：**中后段泄气**。峰值在 0.35–0.5，之后一路掉。
- 风险：读者在高点之后失去动力，容易在章末前退出，钩子救不回来。
- 修法：把峰值后移到 0.7 之后，或在峰值后加一个新变化。

### 形状 C：锯齿型 `∨∧∨∧`

```
5 2 5 2 4 2 5
```

- 判定：**信息密度不均**。高分段是事件，低分段是解释。
- 风险：读者会养成「跳过解释段」的习惯，后面真正的伏笔也被跳掉。
- 修法：把低分段的解释**拆碎塞进高分段**。

### 形状 D：平原型 `—`

```
3 3 3 3 3 3
```

- 判定：**最危险**。没有谷也没有峰，读者不会弃书，但也不会追。
- 风险：均分看起来还行（3.0），实际是「读完了但什么也没发生」。
- 修法：必须找出这一章**唯一的那个变化**，把它放大成一个峰。

## 四、把曲线翻译成报告文字

SKILL.md 第 4 步要求每条结论带段号 + 原句。曲线的写法：

```
【曲线】均值 3.4 · 峰值第 12 段（0.71）· 谷 第 8–11 段（长 4）· 幅度 3
  形状：上升型偏平
  问题：谷在章中偏前，长 4 段，读者会在这里跳读
  定位：第 8 段「<原句 ≤20 字>」— 该段只有环境描写，无状态变化
```

**不许出现的写法**：
- 「整体节奏可以」（无数字）
- 「中段略拖」（无段号）
- 「曲线平缓」（无均值和幅度）

## 五、跨章比较

单章曲线只能说明这一章，**三章连起来看才有意义**。

### 三章连读法

对连续三章分别量曲线，比较均值：

| 模式 | 三章均值 | 判定 |
|---|---|---|
| 递增 | 3.2 → 3.6 → 4.1 | 健康，卷内上升 |
| 递减 | 4.0 → 3.5 → 3.0 | 危险，读者会在这三章内流失 |
| 山峰 | 3.0 → 4.2 → 3.0 | 单章高潮，但两侧空 |
| 平原 | 3.3 → 3.3 → 3.3 | 最危险 |

**判据**：三章均值递减 且 第三章 <3.2 = 报告必须写「连续衰减，建议检查这三章的细纲」。

### 跨章的谷叠加

如果第 N 章末尾有谷，第 N+1 章开头也有谷，**两个谷要合并计算**。读者读的时候不认章界。

合并后长度 >8 段 = 弃书风险至少「中」。

## 六、与 `nightwrite-engagement-curve` 的分工

- **这份**（在 reader-report 里）：给**单章**量曲线，用于出体验报告。
- **`nightwrite-engagement-curve`**：给**多章/整卷**画曲线，用于看节奏分布。

两份的分数口径必须一致（0–5 段级、均值、峰值位置、谷长）。不一致会导致两份报告打架。

**交接规则**：如果本次是三章以上连续评，先按这份逐章量完，再把三章的逐段分数交给 `nightwrite-engagement-curve` 做整卷图。

## 七、量法的常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 用「文笔」当追读欲 | 文笔好的拖沓段被打高分 | 只问「想不想往下」 |
| 回头改分 | 曲线变成后文的反映 | 一次量完，不改 |
| 把标题算作一段 | 段号全部错位 | 标题不计 |
| 只量了前半章 | 谷的位置判错 | 必须通读到尾 |
| 不记 0 分 | 出戏段被隐藏 | 出戏必须记 0 |
| 单章就下「整卷节奏」结论 | 越界 | 三章以上才说整卷 |
