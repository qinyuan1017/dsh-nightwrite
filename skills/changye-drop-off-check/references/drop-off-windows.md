> 适用：要查一章哪个位置会有人退出时读这份，取四个流失窗口的具体判据与风险定级。

# 四个流失窗口

SKILL 正文写的是三个窗口（A 开头 / B 中段 / C 章末）。这份把第四个补上——**D 跨章**，因为相当一部分流失发生在「读完这章、点开下一章的前 50 字」这个位置，它既不属于本章的开头，也不属于本章的末尾。

四个窗口合起来覆盖一次阅读的全部决策点。每个窗口给：读者此刻的状态、判据、风险定级、可接受量。

## 窗口 D 为什么必须有

本章章末钩子做得好（C 窗口低风险），但下一章开头**接不住**，流失照样发生。这时候的流失记在下一章头上，检查本章时会漏掉。

D 窗口的判据只有一条：**下一章开头 300 字内，有没有回应上一章末给的那个东西**。

- 有回应 → 低风险
- 装作没看见但在 2–3 段内回应 → 低风险（这是有效的悬疑手法）
- 完全不回应 → 高风险
- 回应了但不是那个东西（理解错位）→ 低风险（这是最有力的接法，但要求后文纠正）

## 窗口 A：开头 300 字

### 读者状态

试读心态。他不是在读，他在**评估**。手机屏幕上这是第一屏，手指已经准备好返回。

**关键**：这个窗口的读者没有耐心，没有沉没成本，也不打算理解你。他不接受「后面就好了」。

### 三项判据

| 项 | 合格标准 | 判定方式 |
|---|---|---|
| 具体场景 | 至少 2 个可感知实物，其中 1 个带状态 | 找一个没读过的人，让他口述这个空间，说不出来 = 不合格 |
| 正在进行的动作 | 有外部表现、未完成 | 能不能拍成 5 秒镜头；能 = 合格 |
| 一个不对劲 | 多余物 / 反常量 / 错位反应 | 读完前 300 字，读者有没有「等一下」的瞬间 |

### 风险定级

| 缺项数 | 风险 | 说明 |
|---|---|---|
| 0 | 低 | 三样齐 |
| 1 | 中 | 缺的那一项决定后续：缺场景→读者不知道在哪；缺动作→读者不知道在干什么；缺不对劲→读者没有理由往下滑 |
| 2 以上 | 高 | 必改，这是流失率最高的位置 |
| 三项全无且有背景倒灌 | 高（加急） | 倒灌是负分项，不只是缺项 |

**负分项**（出现任一项，风险上调一档）：

- 天气起手（前 100 字里出现天气描写且未作用于人/物）
- 时间地点罗列（「大业七年，江都」式开头）
- 主角自述（「我叫 X，今年 N 岁」）
- 回忆起手（前 100 字进入过去）
- 主题句（「有些债，是要还的」）

### 可接受量

**零**。A 窗口的风险没有任何「可接受」的余地——这一屏的读者是最不值钱的，也是最容易被一句话赶走的。

## 窗口 B：章中段（30%–70%）

### 读者状态

已投入。他读完开头，接受了场景，正在读。这时的风险不是「关掉」，是「开始跳读」。

**中段的流失是隐性的**：读者不会关，他会往下滑得快一点。表现为：这一章读完，但下一章不点了。

### 判据：推进三问

把 30%–70% 区间切段（按自然段切，对白段也算），每段问三问：

1. 这段之后读者知道了什么新的？（信息）
2. 谁做了一个决定？（动作）
3. 局面变了什么？（状态）

三问全否 → 空转段。

**统计算法**：

```
最长连续空转字数 = 从第一个空转段起，到下一个推进段之前的连续字数
```

### 风险定级

| 最长连续空转 | 风险 | 依据 |
|---|---|---|
| < 400 字 | 低 | 读者感觉不到 |
| 400–800 字 | 低到中 | 视空转内容而定：如果是有效氛围（场景铺垫、关系细节）可接受 |
| 800–1500 字 | 中 | 读者开始跳读 |
| > 1500 字 | 高 | 这一段会被整段跳过，且跳过之后的章末钩子会看不懂 |

**注意**：空转的判定不看到底「有没有事发生」，看到底「读者有没有获得新的东西」。一段纯对话，如果只重复已知信息，算空转；一段纯描写，如果建立了后文要用的空间，不算空转（它有信息）。

### 中段的第二类风险：信息重复

判据：同一件事在本章内被**以不同措辞说了 2 次以上**。

| 重复次数 | 风险 |
|---|---|
| 1（说一次） | 无 |
| 2（换个说法再说一次） | 低——如果是不同人物视角，可接受；如果是同一视角重述，浪费 |
| ≥3 | 中——读者会明确感到「这章在凑字」 |

### 可接受量

- 连续空转 ≤800 字
- 单章空转总量 ≤ 全章 20%
- 信息重复 ≤1 处

## 窗口 C：章末 150 字

### 读者状态

决定要不要点下一章。这个决策在读完末段后 **1–2 秒**内做出，且是情绪性的，不是分析性的。

### 判据：末段类型

| 类型 | 风险 | 识别特征 |
|---|---|---|
| 动作悬停 | 低 | 某个动作停在落下前一秒（刀举起未落、门推到一半） |
| 急追问 | 低 | 出现一个必须马上回答的问题 |
| 新信息 | 低 | 刚知道一件来不及消化的事 |
| 情绪欠账 | 低 | 欠了一个明确的情绪（该报的仇没报） |
| 总结本章 | 高 | 出现「这一夜」「从此」「就这样」类收束词 |
| 宣布下章 | 高 | 出现「他不知道，明天……」类预告 |
| 抒情收尾 | 高 | 末段是感受、意象、感慨，没有事实 |
| 欲知后事 | 高 | 直接对读者说话 |

### 四个高风险形态的共同点

它们都在**关门**：把这一章收圆了，让读者感到「这一段结束了」。读者感到结束了，就不会点下一章。

有效的末段是**开门**的：它让读者感到「这里还没完」。

### 末段的三个技术判据

1. **末句是不是名词/动作句，不是感受句？**
   - `他把刀拔出来。`（动作句，开门）
   - `他心里一片冰凉。`（感受句，关门）
2. **末段有没有出现本章已出现过的具体物？** 有 → 是延伸型钩子，最稳；没有 → 是新插入，需要额外成本让读者接住。
3. **末段有没有解释？** 有一句解释 → 钩子力量减半；有两句以上 → 钩子归零。

### 可接受量

零。末段是全章最贵的 150 字，没有「中风险可过」的余地。

## 窗口 D：跨章（下一章开头 50 字）

### 读者状态

刚为上一章付出了情绪，正处在「愿意继续」的峰值。这个峰值只维持 50 字。

### 判据

| 下一章开头 | 风险 | 说明 |
|---|---|---|
| 回应上一章末的东西，且接得紧 | 低 | 读者的情绪被接住 |
| 装作没看见，2–3 段内回应 | 低 | 轻微不安，是好手法 |
| 回应了，但理解错位（人物误解） | 低 | 最有力，但需要后文纠正 |
| 换场景，从头开始 | 高 | 读者的情绪落空 |
| 回应得很晚（半章之后） | 中 | 峰值已过 |
| 完全不回应 | 高 | 读者会认为「上次那个钩子是作者忘了」 |

### 跨章的三条硬规则

1. **不许下一章开头换视角重开**。这是最伤的一类，读者刚跟这个人建立了情绪，你换人了。
2. **不许下一章开头写环境**。读者要的是上一章那个东西的回应。
3. **不许连续两章用同一种接法**。三次「装作没看见」之后，第四次读者就知道你在拖。

## 总风险算法

SKILL 定的是「取三个窗口里最高的那个，不要平均」。这条要严格执行，理由：

- 平均会让一个高风险被三个低风险稀释，而**流失是单点事件**——读者只要在一个窗口被赶走，其他窗口做得再好也没用。
- 所以总风险 = max(A, B, C, D)。

**唯一的例外**：A 窗口的高风险可以「有条件降级」——如果这本书已经连载 50 章以上、读者是核心读者，A 窗口的高风险实际影响有限（老读者会跳过开头）。但**新读者永远走 A 窗口**，所以这个降级只在「存量运营」的语境下成立，不是拿来让这章过关的。

## 报告填写要点

```
【总风险】高（A 高，B 中，C 低，D 中）
【A 开头 300 字】风险 高
  具体场景：无 — 「天阴沉沉的，风从北面吹来」（天气起手，且未作用于人）
  正在进行的动作：有 — 「他蹲在井台边，把断绳的两头往一处缠」
  不对劲：无
  负分项：天气起手
  结论：读者知道他在干什么，但不知道他在哪、也没有理由好奇
【B 中段】风险 中
  推进点：第 4/9/14/22 段（共 4 个）
  最长连续空转：第 15–21 段 · 1080 字
  空转段清单：15（重述户籍问题）16–18（纯环境）19（重复已知伤情）20–21（回忆）
【C 章末】风险 低
  类型：动作悬停
  末段：「他抬手，门外的刀光已经压到门槛上。」
【D 跨章】风险 中
  下一章开头：换到另一角色视角，第 4 段才提上一章的事
【改法方向】A：把第 2 段的动作提到第一句，删天气；B：把 15–21 压成 2 段；C：不动；D：下一章开头改成「门被撞开」的动作切入
```

## 三个窗口与章长的关系

同样 3000 字，窗口的位置不同：

| 章长 | A | B | C |
|---|---|---|---|
| 1500 字（短章） | 前 300 字（20%） | 450–1050 字 | 后 150 字 |
| 3000 字（常规） | 前 300 字（10%） | 900–2100 字 | 后 150 字 |
| 5000 字（长章） | 前 300 字（6%） | 1500–3500 字 | 后 150 字 |

**长章的 B 窗口风险显著更高**：5000 字的章，中段有 2000 字要看住。所以长章的中段必须**内部再分小高潮**——每 1000–1200 字有一个小的推进点。
