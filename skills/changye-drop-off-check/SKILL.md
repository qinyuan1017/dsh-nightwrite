# 弃书点检查

只干一件事：**定位三个流失点，并给风险等级与原因**。不做整体评价、不给改写稿。

## 三个流失窗口

| 窗口 | 位置 | 读者状态 | 流失原因类型 |
|---|---|---|---|
| **A 开头** | 前 300 字 | 随时准备关掉（试读心态） | 无场景 / 无动作 / 无异常 |
| **B 中段** | 全章 30%-70% | 已投入但开始不耐烦 | 无推进 / 无变化 / 信息重复 |
| **C 章末** | 最后 150 字 | 决定要不要点下一章 | 钩子虚 / 已泄劲 / 总结收尾 |

## 执行步骤

**第 1 步：A 窗口三项检查（逐项打勾）**

前 300 字必须同时具备：

1. **一个具体场景**（能看见东西，不是「天很蓝」而是「门口挂着一把生锈的锁」）
2. **一个正在进行的动作**（有人在做事，不是回忆）
3. **一个不对劲**（读者感觉到异样但说不出）

缺 1 项 = 中风险，缺 2 项以上 = 高风险。

**第 2 步：B 窗口扫推进点**

把 30%-70% 区间切段，逐段问：**这段之后，读者知道了什么新的 / 谁做了决定 / 局面变了什么？**

三项都没有的段 = 空转段。统计：

```
最长连续空转 = <n> 段 / <n> 字
```

超过 1500 字 = 高风险；800-1500 字 = 中风险。

**第 3 步：C 窗口判定钩子类型**

末 150 字属于哪一类：

- **新信息**（刚知道来不及消化的事）→ 低风险
- **急追问**（必须马上回答的问题）→ 低风险
- **动作悬停**（危险停在落下前）→ 低风险
- **总结本章 / 宣布下章 / 抒情收尾 / 「欲知后事」** → 高风险

**第 4 步：定总风险**

取三个窗口里最高的那个，不要平均。

**第 5 步：只写原因，不写改法成稿**

原因必须具体到「第 X 段缺了什么」。改法只给方向（「前 300 字应补一个正在进行的动作」），不给成稿段落。

## 输入

- 待查正文（`chapter.get`）
- 画像卡（耐心阈值决定「多少字算空转」）
- `outline.intent` 的 `hook`（判断 C 窗口是否兑现细纲）

## 输出格式

```
【总风险】低/中/高（取三窗口最高）
【A 开头 300 字】风险 <低/中/高>
  具体场景：<有/无 — 引用>
  正在进行的动作：<有/无 — 引用>
  不对劲：<有/无 — 引用>
  结论：<前 300 字读者知道自己在哪、在干什么吗>
【B 中段】风险 <低/中/高>
  推进点：第 <a>/<b>/<c> 段（共 <n> 个）
  最长连续空转：第 <X>-<Y> 段 · <n> 字
  空转段清单：<段号 + 一句为什么没推进>
【C 章末】风险 <低/中/高>
  类型：<新信息/急追问/动作悬停/总结/预告/抒情>
  末段：「<引用>」
【改法方向】A：<方向>｜B：<方向>｜C：<方向>
```

## 检查清单

- [ ] 三个窗口逐个查过，没有合并成一段泛泛而谈
- [ ] A 窗口三项各自有结论和引用
- [ ] B 窗口统计了最长连续空转的字数
- [ ] C 窗口判定了钩子类型（四类有效 + 四类无效）
- [ ] 总风险取的是最大值，不是平均
- [ ] 每条都带段号
- [ ] 只给方向，没给成稿

## 禁止事项

- 不许提供完整改写稿。
- 不许查硬性设定冲突（那是 `changye-continuity-pass`）。
- 不许给「整体还行」这种平均化结论——三个窗口必须分开说。
- 不许把风险等级往下调来让这章显得能发。
- 不许只说「开头不够吸引」而不指出缺的是三件事里的哪一件。
