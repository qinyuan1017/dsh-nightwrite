# 章节写作

这份手册的核心是一条门禁：**没有细纲不许动笔**。它管「怎么写」，不管「写得好不好」。

## 执行步骤

**第 1 步：门禁检查（不过就停）**

三样东西必须同时到位，缺一样立刻退回，不许用「我先写着看」绕过：

| 要件 | 取法 | 缺失时怎么做 |
|---|---|---|
| 本回细纲 | `nightwrite_op` → `outline.intent`（返回 `summary` + `hook`） | 停笔，报「缺细纲」，交回 nightwrite-plan-novel |
| 上一回结尾 | `chapter.get`（上一回，取末 200 字） | 第 1 回除外；缺则报「无前文可接」 |
| 人物与专名 | `ledger.get` 的 `characters`（语言基因、心理阈值）与 `terms` | 缺卡则报「需要建卡」，不许自己编人物口吻 |

**第 2 步：定篇幅与节奏**

`project.get` 的 `targetWords` ÷ 总回数 = 单回目标字数，误差允许 ±15%。

按 `pacing` 排推进点：快节奏每 800-1000 字一个推进，标准每 1200-1500 字一个。写完数一遍——如果连续 1500 字没有任何新信息/新决定/新变化，那段就是在注水。

**第 3 步：按细纲落三件事**

细纲说这一回发生三件事，就写这三件事。

- **不许加戏**：细纲没写的新角色、新势力、新能力，一律不出现。
- **不许省戏**：细纲写的转折不许推后到下一回。
- **不许挪序**：三件事的顺序不许调换，除非细纲本身没定序。

**第 4 步：写章末钩子**

最后 150 字必须把 `hook` 落地。有效的三种写法：

1. **新信息**：读者刚知道一件他还来不及消化的事；
2. **急追问**：一个必须马上回答的问题被提出来；
3. **动作悬停**：一个已经在发生的危险，停在它落下的前一秒。

无效的：总结这一章、宣布下一章要写什么、抒情收尾、「欲知后事如何」。

**第 5 步：交稿**

调 `nightwrite_op` 的 `chapter.save`（`projectId`、`chapter`、`body`），然后停手。**不要连着写下一章**。

## 输入

- `outline.intent`：本回 `summary`（三件事）+ `hook`
- `chapter.get`：上一回正文（衔接语气、未闭合的动作）
- `ledger.get`：`characters`（语言基因 / 心理阈值 / 当前状态）、`terms`（专名唯一写法）、`rules`（能力边界）
- `project.get`：`targetWords`、`qualityGate`

## 输出格式

正文走 `chapter.save`，回执固定六段：

```
【回目】第 N 回 <标题>｜字数 <n>（目标 <n>，差 <±n>）
【细纲执行】
  ① <细纲点 1> → 已写：<落在第几段，一句话>
  ② <细纲点 2> → 已写：<…>
  ③ <细纲点 3> → 已写：<…>
【章末钩子】<引用最后两句原句>
【自补细节】<哪些是我补的：配角动作/环境/过场；没有就写「无」>
【存疑点】<我拿不准、需要审校核的地方；没有就写「无」>
【破格申请】<无 / 细纲第 X 点做不了，因为……，建议改成……>
```

## 检查清单

- [ ] `outline.intent` 有返回，`summary` 不是空的
- [ ] 读到了上一回末 200 字
- [ ] 用到的每个角色都有 `characters` 卡
- [ ] 每个专名都按 `terms` 的唯一写法
- [ ] 字数在目标 ±15% 内
- [ ] 没有连续 1500 字无推进
- [ ] 细纲三件事全部落地，顺序没变
- [ ] 章末最后 150 字把 `hook` 落下来了
- [ ] 章末不是总结、不是预告、不是抒情
- [ ] `chapter.save` 已执行，且没有继续写下一章
- [ ] 回执六段齐全

## 禁止事项

- **不许无细纲开工。** 这是唯一不可协商的一条。
- 不许在正文里写「作者的话」「下章预告」「本章完」。
- 不许新增 `ledger` 里没有的角色、能力、势力。要加先申请。
- 不许调 `review.action`。你交的永远是 `draft`。
- 不许自己改细纲来迁就写出来的内容。
- 不许把「我觉得这样更带感」当作偏离细纲的理由。
- 不许一次交多章。连更是调度权，不是写作权。
