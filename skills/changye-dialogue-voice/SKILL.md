# 对话声线

让读者**闭眼听对白就能认出是谁在说**。只管怎么说，不管说什么、为什么说。

## 执行步骤

**第 1 步：拉四个声线参数**

`changye_op` → `ledger.get` → `characters`，取该角色的：
- **句长倾向**：短促（≤10 字）/ 中等 / 长句缠绕
- **口头禅**：一个高频词或句式
- **称呼习惯**：对不同人怎么叫（这个最能区分身份）
- **禁忌词**：他绝不说的词（说漏了就是崩人设）

四个参数缺一个，这段对白不许写——先补卡。

**第 2 步：定这段对白的「潜台词」**

每段对白必须有一句「他真正想说的」，写在对白之前：

```
表层：<字面说什么>
潜台词：<他真正想要/想掩盖什么>
```

没有潜台词的对话是信息播报，删掉重写。

**第 3 步：写对白的四条硬规则**

1. **不答所问**：真实对话里人常答偏。全是对答如流 = 假。
2. **有打断**：至少一处被打断或抢话。
3. **不完整句**：口语允许缺主语、缺谓语。全是完整句 = 书面语。
4. **动作夹缝**：每 3-4 句对白插一个动作（不是「他说」）。

**第 4 步：遮名测试**

把说话人标签全删掉，只读对白。认不出谁是谁 → 回第 1 步，说明声线参数没落地。

**第 5 步：检查禁忌词**

逐句对照 `characters` 的禁忌词。命中一个就是崩人设，必须改。

## 输入

- `ledger.get` 的 `characters`：句长、口头禅、称呼、禁忌词、当前状态
- 场景上下文（`chapter.get` 或 `outline.intent`）：这段对白发生在什么处境下
- `terms`：专有名词的唯一写法（对白里也要遵守）

## 输出格式

```
【角色声线卡】
  <角色A>：句长 <短促/中等/长>｜口头禅 <…>｜称呼 <对B：…/对C：…>｜禁忌 <…>
  <角色B>：…
【本段潜台词】
  <角色A> 表层：<…>｜潜台词：<…>
【对白（改后）】
  <角色A>：「…」
  <角色B>：「…」
【遮名测试】删掉标签能否认出：<能/不能 + 哪句露馅>
【规则落实】不答所问 <有/无>｜打断 <有/无>｜不完整句 <有/无>｜动作夹缝 <n> 处
【禁忌词检查】命中 <n> 处 → <哪句>
```

## 检查清单

- [ ] 每个出场角色都有完整的四项声线参数
- [ ] 每段对白写了表层/潜台词
- [ ] 四条硬规则逐项落实（不答所问、打断、不完整句、动作夹缝）
- [ ] 遮名测试做过，能认出谁是谁
- [ ] 禁忌词逐句对照过，零命中
- [ ] 专名按 `terms` 写法
- [ ] 对白里的信息量没有超出该角色「当前状态」已知范围

## 禁止事项

- 不许改人物弧光、底色、心理阈值。发现卡不对，报给 `changye-character-arc`。
- 不许决定剧情走向。对白不能推动新的、`outline` 里没有的事件。
- 不许让角色说出他还不知道的信息（对照 `characters.state` 的「已知」）。
- 不许所有角色共用一个句式。全员短句 = 没做声线。
- 不许用对白解释设定（「你知道的，我们家族三百年前……」）。设定靠叙述和五感，不靠人物讲课。
- 不许写「他说道」「她问道」这种标签堆砌，用动作代替。
