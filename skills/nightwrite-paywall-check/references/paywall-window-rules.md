> 适用：要判断免费末章会不会让人掏钱、付费首章开头会不会让人退款、悬念兑现值不值票价时读这份。

# 三个付费卡点的判定细则

卡点的本质是**一次交易的临门一脚**。读者不是不愿付钱，是不愿为「不确定的东西」付钱。三个卡点各自解决一个不确定：

| 卡点 | 读者的不确定 | 你要给的答案 |
|---|---|---|
| 免费末章 | 「下一章值得我付第一笔钱吗」 | 一个已经启动、不许不看的动作 |
| 付费首章开头 | 「我是不是被坑了」 | 立刻接住，不回顾不换人 |
| 关键悬念释放 | 「我等这么久就这」 | 兑现的信息量 ≥ 等待的章数折扣 |

## 卡点一：免费末章

### 三个必须（SKILL 第 2 步的展开）

#### 必须一：一个未落的动作

**判据**：末段结束时，有一个**正在进行的动作**没有完成，且这个动作有后果。

| 合格 | 不合格 |
|---|---|
| 刀已经举起来，还没落下 | 他决定明天去找张三（还没开始） |
| 门被推开一半，外面的人还没进来 | 他想起了很多事 |
| 他把信递出去，对方还没接 | 他终于明白了什么 |

**「未落」的三个条件**：已开始 / 有外部表现 / 结果未定。三个缺一，读者不会急。

**为什么「决定」不算**：决定是内在的，读者可以等。动作是外在的，读者必须知道结果。

**量化**：末段（最后 100–150 字）里，未落动作必须占据**至少一句的句末位置**。放在段中会被后续句子冲淡。

#### 必须二：一个刚抛出、没解释的信息

**判据**：这一条信息是**新的**（读者此前不知道），且**没被解释**（作者没说它意味着什么）。

| 合格 | 不合格 |
|---|---|
| 「碗是两只。院主说他一个人住。」 | 「原来院主一直在骗他，因为他儿子没死。」 |
| 「官凭上的『沈』字，墨色比旁边深。」 | 「他这才知道官凭被人改过。」 |

**区别**：合格的是**现象**，不合格的是**结论**。给现象，读者会自己推，并且想验证；给结论，读者没有可验证的东西。

**「刚抛出」的判据**：这条信息必须是末段（最后 150 字）里出现的。放在章中，读者已经消化了。

#### 必须三：一个明确指向下一章的因果

**判据**：读者能不能说出「因为这件事，所以下一章必然要发生另一件事」？

| 合格 | 不合格 |
|---|---|
| 他答应了三日后给答复 → 下一章必然是答复那场 | 「后来发生了很多事」 |
| 刀已经架在脖子上 → 下一章必然要处理这一刀 | 「他不知道，命运已经改变」 |
| 院主说「今晚别出屋」→ 下一章他必然要出屋或不出去 | 「一切才刚刚开始」 |

**「明确」的判据**：因果链只有一环。读者不需要推理，只需要知道「下一步是什么」。

**三环以上**（因为 A 所以 B 所以 C 所以下一章 D）→ 太远，读者不会感到紧迫。

### 风险定级

| 缺项 | 风险 | 后果 |
|---|---|---|
| 0 | 低 | 卡点成立 |
| 1 | 中 | 卡点弱：读者会犹豫，一部分人会等免费 |
| ≥2 | 高 | 卡点无效：读者会在这里停止 |

**行业参照**（网文付费转化的粗略数量级，用于判断严重程度，不作绝对标准）：免费末章合格时，从免费章到付费章的点开率明显高于不合格时；差额通常在数倍量级。所以这一项是三卡点里最值得投入的。

### 最常见的三个失败

| 失败 | 表现 | 修法 |
|---|---|---|
| **本章总结式收尾** | 末段把这一章的事收圆了（「这一夜，他睡得很沉」） | 删掉收尾，把本章最后一个未落动作切到末尾 |
| **抒情代替动作** | 末段是感受（「他知道，从今往后不一样了」） | 换成具体动作 |
| **预告下一章** | 「他不知道，明天等待他的是……」 | 删掉预告，只留现象 |

## 卡点二：付费首章前 300 字

### 两个雷（SKILL 第 3 步）

#### 雷一：回顾上一章

**判据**：前 300 字里，有没有任何句子在**复述读者刚读过的事**？

三种典型：

```
· 「昨夜的事还留在眼前。」          ← 直接回顾
· 「他想起刚才那把刀。」            ← 用回忆伪装回顾
· 「事情要从三天前说起。」          ← 倒叙开场（等于回顾 + 推迟）
```

**为什么致命**：读者刚付了钱。付钱后第一件事是**验证**这笔钱花得值不值。如果第一屏给的是「你已经知道的东西」，验证结果就是「不值」。

**唯一例外**：回顾只占 1 句，且这一句立刻接上一个**新动作**（不是新感受）。

#### 雷二：换视角讲别人

**判据**：前 300 字的主角，是不是免费末章那个视角人物？

- 是 → 通过
- 不是，但那个人在末章的现场 → 可接受（同一场景的另一个视角）
- 不是，且是完全不同的地点/时间线 → 致命

**为什么致命**：读者的情绪投资在末章那个人身上。换人等于把这份投资清零，读者要从头建立。而付费首章最不能承担这个成本。

### 第三个要求：接住未落动作

**判据**：免费末章那个未落动作，在付费首章前 300 字内有没有**继续**？

三种接法，按质量排：

| 接法 | 例 | 评价 |
|---|---|---|
| **直接继续** | 末章「刀举起未落」→ 首章「刀落下了」 | 最好，读者立刻满足 |
| **延后一秒** | 末章「刀举起未落」→ 首章「他听见自己的心跳」（仍在那一秒里） | 好，制造更强张力，但只能延一次 |
| **装作没看见，2–3 段内回应** | 末章「刀举起未落」→ 首章先写别的，第 3 段回到刀 | 可接受，但要保证 300 字内回来 |
| **完全不接** | 首章从三天后开始 | 致命，等于免费的钩子是假的 |

**「延后一秒」的使用限制**：只能延一次。第二次延读者会认为作者在耍他。

### 风险定级

| 情况 | 风险 |
|---|---|
| 无回顾 + 无换视角 + 接住动作 | 低 |
| 上述三项有一项出问题 | 中 |
| 有回顾或有换视角，且没接住动作 | 高 |
| 三项全错 | 高（加急） |

## 卡点三：悬念释放的性价比

### 三个问题（SKILL 第 4 步的展开）

#### 问题一：等了多久

```
跨度 = payoffAt - plantedAt
```

用 `ledger.get` 的 `foreshadow` 真实章号算，不用估计。

#### 问题二：兑现给了几条新信息

**「新信息」的判据**：读者此前不知道的、且与这个悬念直接相关的。

| 例 | 算几条 |
|---|---|
| 「他父亲其实没死」 | 1 条 |
| 「他父亲没死，而且当年是他自己放的火」 | 2 条 |
| 「他父亲没死，当年是他自己放的火，火是为了烧掉那封信」 | 3 条 |
| 「他父亲没死——他早就猜到了」 | 0 条（读者已猜到的不算） |

#### 问题三：兑现后有没有立刻接新悬念

**判据**：兑现段落结束后，**同一章内**有没有出现一个新的未答问题？

- 有 → 读者会继续
- 没有，兑现章是这一卷的最后一章 → 可接受（卷末允许清空）

- 没有，且是卷中 → 读者会在兑现处合书

### 性价比判定表

把跨度和信息量对上：

| 跨度 | 1 条 | 2 条 | 3 条以上 |
|---|---|---|---|
| ≤5 章 | 值 | 值 | 值（略过载） |
| 6–15 章 | 勉强 | 值 | 值 |
| 16–30 章 | 不值 | 勉强 | 值 |
| >30 章 | 严重不值 | 不值 | 勉强 |

**规律**：跨度和信息量必须大致成正比。约 **每 10 章跨度换 1 条新信息**是及格线。

**再看新悬念**：上述判定命中「不值」但兑现后立刻接了强新悬念 → 升一档（读者被下一个问题带走，不会算账）。命中「值」但兑现后整章无新悬念 → 降一档。

### 三种「不值」的补法

| 情况 | 补法 |
|---|---|
| 跨度太长，信息不够 | 在兑现前 2–3 回补一次中途提及（加压型），缩短感知跨度 |
| 信息够但都是读者猜到的 | 加一条**反预期**的信息（读者猜到 A，给 A + 一个没想到的 B） |
| 兑现后无新悬念 | 在兑现段落的末尾加一个由这次兑现**长出来**的新问题 |

## 分界章不明时的处理

`chapter.list` 没有免费/付费元数据时，按常见区间估计（免费 20–30 章），**必须标注「估计」**。

估计会带来什么影响：如果实际分界比估计晚 10 章，你可能在评价一个非卡点章。所以估计时必须同时给出**两个候选取值**（如「估计在第 24–28 回之间」），并说明这个区间的判定在哪些条件下会翻转。

**禁止**：把估计值当作确定值往下走，然后在报告里写「免费末章风险高」——那是在给一个可能不存在的问题定级。

## 报告填写要点

```
【分界】免费至第 26 回（估计，区间 24–28），付费自第 27 回
【免费末章】风险 中
  未落的动作：有 — 「他抬手，门外的刀光已经压到门槛上」
  未解释的信息：无（末段只有动作，没有新现象）
  指向下一章的因果：有 — 门被撞开 → 下一章必然处理这一刀
  缺项：必须二（缺 1 项 → 中）
  修法方向：在刀光那句之前插一句现象（门外的人穿的是官靴——他没报官）
【付费首章前 300 字】风险 高
  回顾上一章：是 — 第 1 段「昨夜的事还留在眼前」
  换视角：否
  接住未落动作：是（第 4 段才接）
  修法方向：删第 1 段回顾，把第 4 段的动作提到第 1 句
【悬念释放性价比】
  悬念：父亲真实身份｜等了 34 章｜兑现给 2 条新信息｜兑现后接新悬念：无
  判定：不值（34 章 / 2 条 → 严重不值档），且无新悬念 → 不加档
  修法方向：兑现段落末尾加一个由「父亲身份」长出来的新问题
```

## 一个反直觉的结论

**免费末章的价值高于付费首章。**

作者的本能是「付费首章要写得漂亮」，于是把力气全放在首章。但真实的决策发生在**免费末章读完的那 3 秒**——那时候读者还没有付钱，还有得选。付了钱之后，读者的容忍度反而变高（有沉没成本）。

所以投入顺序应该是：免费末章 > 付费首章前 300 字 > 悬念释放。

而免费末章最容易做坏的，恰恰是作者最用力的地方：**把这一章收得很好**。收得好，读者就不必看下一章了。
