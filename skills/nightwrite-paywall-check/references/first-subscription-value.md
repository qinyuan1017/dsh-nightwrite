> 适用：付费首章（上架章）要交稿前读这份，判断这一章能不能兑现免费期攒下的承诺。

# 首订章的价值构成

首订 = 读者第一次为这本书付钱。这一章的任务不是「写得好」，是**证明免费期的承诺是真的**。

免费期（通常 20–30 章）里，作者做了三件事：立了主角要什么、埋了几个悬念、暗示了这本书的爽点类型。首订章必须全部兑现一次**小样**。

## 价值的三个来源

| 来源 | 读者要看到的 | 缺了会怎样 |
|---|---|---|
| **承诺兑现** | 免费期反复暗示的那个东西，至少兑现一小份 | 「原来是这种书」→ 弃 |
| **新信息密度** | 首订章的信息量 ≥ 免费期平均章的 1.5 倍 | 「付费还不如免费」→ 弃 |
| **接入感** | 前一章那个未落动作立刻被接住 | 「我被坑了」→ 弃 + 差评 |

三个来源缺两个以上 → 首订失败，且免费期的读者已经花掉了。

## 来源一：承诺兑现

### 免费期承诺了什么

免费期一定会给读者一个**期待类型**。四种常见类型：

| 类型 | 免费期的暗示方式 | 首订章必须给的小样 |
|---|---|---|
| 逆袭型 | 主角被压制，反复暗示他会成长 | 一次小的胜利（不需要大胜） |
| 复仇型 | 明确写出仇人是谁 | 主角开始动手的第一个动作（不必成功） |
| 情感型 | 两人有明确的关系张力 | 一次只有两人知道的靠近 |
| 求索型 | 一个明确的谜（他是谁/这是什么） | 一条关于谜的新信息（不一定解开） |

**判据**：把免费期最后 5 章的章末钩子排在一起，它们的**共同指向**是什么？那个共同指向就是承诺。

如果 5 个钩子指向 5 个方向 → 免费期没有明确承诺，这是更根本的问题（首订章无论怎么写都救不回来）。

### 怎么兑现「一小份」

「一小份」的判据：**方向对，强度打七折**。

- 逆袭型：读者想看大胜，首订章给一次小胜（赢了但只赢了一个小人物）
- 复仇型：读者想看手刃，首订章给「他终于决定动手」
- 情感型：读者想看表白，首订章给「她记住了他说过的一句话」
- 求索型：读者想看答案，首订章给「谜的一部分被证实」

**不许在首订章给全额**。全额给了，读者会觉得「我想看的已经看完了」，然后走。

### 兑现的位置

首订章的**后 1/3**。

**不能在开头**：开头的位置要留给「接住上一章的未落动作」。承诺兑现放在后 1/3，正好把这一章的结构排成「接住 → 推进 → 兑现小样」三段。

## 来源二：信息密度 ≥ 免费期 1.5 倍

### 为什么是 1.5 倍

免费期的信息密度是「吸引」用的，付费期的信息密度是「回报」用的。读者付了钱，对单位字数的产出预期会上升。

**算法**：

```
免费期平均章信息量 = 免费章新信息条数总和 ÷ 免费章数
首订章信息量 = 首订章新信息条数
比值 = 首订章信息量 ÷ 免费期平均章信息量
```

| 比值 | 判定 |
|---|---|
| ≥2.0 | 优秀（但注意别塞到读者记不住） |
| 1.5–2.0 | 合格 |
| 1.0–1.5 | 偏薄，读者会觉得不值 |
| <1.0 | 不合格 |

**「新信息」口径**：读者此前不知道的、与主线或人物关系直接相关的。不含氛围描写、不含已知信息的重述。

### 提高密度的三种做法

| 做法 | 效果 | 风险 |
|---|---|---|
| 兑现一个已埋悬念 | 高（1 条悬念兑现常带 2–3 条信息） | 低 |
| 引入一个新角色/新势力 | 中 | 中（新角色要花篇幅立，会挤压其他） |
| 揭示一条世界规则 | 中 | 低 |

**首选第一种**。首订章最该做的是「兑现」，不是「扩张」。

## 来源三：接入感

### 硬判据（与 `paywall-window-rules.md` 的卡点二一致）

- 前 300 字必须是免费末章那个视角人物
- 前 300 字不许回顾
- 未落动作必须在 300 字内继续

### 一个常被忽略的点：首订章的**第一句**

第一句的作用不是吸引，是**证明连续性**。

| 第一句 | 评价 |
|---|---|
| 「刀落下去了。」 | 好：直接接住，读者立刻安心 |
| 「他听见自己的心跳。」 | 好：仍在那一秒里（延后一秒，只能用一次） |
| 「三日后，城西的米铺关了门。」 | 差：跳了时间，读者会认为被跳过了一段 |
| 「这件事，要从三年前说起。」 | 最差：倒叙，等于宣告「刚才那个钩子是假的」 |

### 首订章的长度

**不要比免费期平均章短**。短了读者会算「一样的钱，字少了」。

**也不要长 30% 以上**。过长会让读者形成「上架章特别长」的预期，后续正常长度会被认为缩水。

**合理区间**：免费期平均章长 × 0.95 ~ × 1.2。

## 首订章的三段结构

```
【接住】前 15%：继续免费末章的未落动作，给出一个明确结果
【推进】中间 50%：本章主体事件，建立一个新的小目标
【兑现】后 35%：兑现免费期承诺的一小份 + 章末钩子
```

**三段的功能不可互换**：

- 接住段如果缺失 → 读者感到被坑
- 推进段如果缺失 → 这章只是接上一章，没有自己的事
- 兑现段如果缺失 → 读者不知道自己在为什么付钱

## 首订章的五个常见死法

| 死法 | 表现 | 为什么致命 |
|---|---|---|
| **清算式开头** | 首章把免费期所有线索梳理一遍 | 读者已经知道，这是纯浪费 |
| **换主角线** | 首章写另一条线 | 情绪投资清零 |
| **上架感言式** | 开头写作者的话/求订阅 | 打断沉浸，且暴露商业意图 |
| **大场面开局** | 首章直接上大战 | 读者还没建立对新场景的空间感，读不懂 |
| **伏笔大放送** | 首章一次性回收 3 个以上伏笔 | 信息过载 + 后续无牌可打 |

## 免费期该为首订章做的准备

如果免费期还没定稿，这三件事可以直接改善首订：

1. **免费期最后 3 章的章末钩子必须同向**。同一个承诺的三种逼近方式，读者会形成明确期待。
2. **在免费期留一个「只差一步」的悬念**。首订章第一件事就是走完那一步（接住段）。
3. **免费期不要把所有牌都打完**。至少留 2 条未回收伏笔进付费区，首订章兑现其中 1 条。

## 报告格式

```
【承诺类型】<逆袭/复仇/情感/求索> — 依据：免费期末 5 章钩子的共同指向
【承诺兑现】<有/无> — 兑现什么：<…> — 位置：第 <n> 段（应占后 1/3）
【信息密度】免费期均 <n> 条/章｜首订章 <n> 条｜比值 <n> → <优秀/合格/偏薄/不合格>
【接入感】视角人物 <一致/不一致>｜回顾 <有/无>｜未落动作 300 字内继续 <是/否>
【第一句】「<引用>」→ <好/拖延/跳跃/倒叙>
【章长】免费期均 <n> 字｜首订章 <n> 字｜比值 <n> → <合理/偏短/偏长>
【三段结构】接住 <n>%｜推进 <n>%｜兑现 <n>% → <齐/缺哪段>
【死法检查】<命中哪几条>
【改法方向】<只给方向>
```

## 一个反直觉的结论

**首订章最不需要的是「写得更好」。**

作者的本能是「上架了，要拿出最好的文笔」。但首订章的读者此刻在做的是**核对**，不是欣赏。他在核对：我免费期看到的那个东西，是不是真的存在。

文笔再好，核对的答案如果是「那个东西不存在」，读者立刻走。

所以首订章应该写得**更清楚、更直接、信息更密**，而不是更漂亮。把这个当成一次交付验收，不是一次表演。
