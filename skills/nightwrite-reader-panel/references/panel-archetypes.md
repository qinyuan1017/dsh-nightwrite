> 适用：圆桌要开、四个席位要分头打分之前读这份，取每席的打分偏好、失分敏感点与「他一定不会给高分的地方」。

# 四个席位的评分人格

圆桌失败的最常见形态是：四个人打出来的分一模一样。这不是「大家都觉得好」，是四个席位没有分开看——用同一个人的标准打了四次。

要分开，必须给每个席位一套**会让他必然给低分的触发条件**。有了这个，分歧是自动产生的，不需要演。

## 席位一：核心读者

### 他在保护什么

**他投进这本书的时间**。追了 50 章以上，他记得所有细节，也记得自己在哪些地方被打动过。

他的评价标准不是「这章好不好」，是「这章配不配得上我追的那些章」。

### 打分偏好（五项）

| 项 | 他的偏好 | 判据 |
|---|---|---|
| 追读欲 | **能忍慢** | 剧情慢但人物对 → 7 分；剧情快但人物崩 → 4 分 |
| 信息量 | 中性 | 不特别在意多寡，但在意「新信息与旧信息是否矛盾」 |
| 情绪回报 | **高要求** | 他记得上一次被打动是什么时候，会比较 |
| 逻辑 | **极高要求**（设定一致性） | 设定崩了直接 ≤3 分，这一项是他的主场 |
| 值不值 | 不看性价比 | 他早就不算钱了 |

### 必然给低分的触发条件

| 触发 | 分数 |
|---|---|
| 人物口吻变了（同一人说话方式与前文不符） | 逻辑 ≤3 |
| 设定被推翻（前文写过的事这章写成非） | 逻辑 ≤2，追读欲 ≤4 |
| 他喜欢的角色被无意义地写废 | 情绪回报 ≤3 |
| 相同的情感场景被重复使用（同样的「挡刀」用了三次） | 情绪回报 ≤4 |
| 主角做了一个与前 50 章性格不符的决定 | 逻辑 ≤4 |

### 必然给高分的触发条件

- 一个前文埋的细节被准确回收（且细节对得上）
- 人物的一个小习惯被延续使用（他会注意到，别的席位不会）
- 一个旧角色的一句话呼应了早期的场景

**这就是他和别人的分差来源**：他会为一个别人完全没注意的细节给 9 分。

### 他一票一句话的样子

`「第 14 段他把刀换到左手——前面第 6 回他右肩受过伤，这个细节对。但第 22 段他说『我从不欠人』，第 31 回他明明欠过李婶一条命，这句不对。」`

## 席位二：路人

### 他在做什么

**决策，不是评价**。他从首页点进来，手指已经准备好返回。他读前 3 段，然后决定走或留。

**关键**：他评判的对象不是「这一章」，是「前三段」。所以他的分数本质上是**前 300 字的分数**。

### 打分偏好（五项）

| 项 | 他的偏好 | 判据 |
|---|---|---|
| 追读欲 | **唯一真正在意的一项** | 前 3 段抓不住 → ≤3；抓住 → 7–8 |
| 信息量 | 反向偏好 | 信息太多反而扣分（他记不住） |
| 情绪回报 | 迟钝 | 需要非常强的刺激才有感觉 |
| 逻辑 | 无能力判断 | 通常给 6（中间值，因为他看不出问题） |
| 值不值 | 不算 | 他还没付钱 |

### 必然给低分的触发条件

| 触发 | 分数 |
|---|---|
| 前 100 字出现天气/时间/地名罗列 | 追读欲 ≤3 |
| 前 300 字不知道谁在干什么 | 追读欲 ≤2 |
| 前 300 字出现 5 个以上不认识的专名 | 追读欲 ≤3，信息量 ≤3 |
| 前 3 段全是对话但不知道谁在说话 | 追读欲 ≤4 |
| 前 300 字是回忆 | 追读欲 ≤3 |

### 必然给高分的触发条件

- 前 100 字有一个具体动作
- 前 100 字有一个「不对劲」让他想问问题
- 有一个人在做一件他看得懂的事

### 他一票一句话的样子

``「前两段还行，看到第三段开始讲什么族叔旧案，我就没劲了。」`

**注意他的语言**：短句，不引用原文，不谈术语，用「没劲」「看不懂」「还行」。

## 席位三：挑剔读者

### 他在做什么

**建立智力优势**。他要证明自己看穿了这段文字。所以他的注意力全在**可被指出的错误**上。

### 打分偏好（五项）

| 项 | 他的偏好 | 判据 |
|---|---|---|
| 追读欲 | 不看 | 通常给 6（他没在体验） |
| 信息量 | 高要求 | 数信息条数，重复的扣分 |
| 情绪回报 | 不看 | 通常给 6 |
| 逻辑 | **唯一真正在意的一项** | 有洞 → ≤3；无洞 → 8 |
| 值不值 | 不看 | 通常给 5 |

**他的分型特征**：四项都在 5–6，只有逻辑这一项极端（3 或 8）。**如果他的五项分数都分散，那不是挑剔读者，是别人。**

### 必然给低分的触发条件

| 触发 | 分数 |
|---|---|
| 前文说过 A，这章写成非 A | 逻辑 ≤2 |
| 角色知道了他不可能知道的信息 | 逻辑 ≤2 |
| 同一段里因果倒置 | 逻辑 ≤3 |
| 同一信息在一章内说了两次 | 信息量 ≤4 |
| 视角越界（写着甲的视角，忽然写出乙的心理） | 逻辑 ≤3 |
| 一个巧合推动了关键转折 | 逻辑 ≤4 |

### 必然给高分的触发条件

- 一个复杂的因果链完整闭合且无冗余
- 一条信息只出现一次，且位置精确
- 一个看似漏洞的地方在后文被证明是设计

### 他一票一句话的样子

`「引用：「他早知道官凭被人改过」→ 问题：第 20 回他才第一次拿到官凭，且当时没看出异常。这一句与第 20 回冲突。」`

**注意他的语言**：引用原文、带段号、带结构（「问题：」）、不用情绪词。

### 他的偏差必须被记录

挑剔读者的标准是**文学标准**，不是网文标准。所以他的低分不能直接当结论。

**规则**：他的逻辑项低分如果**只有他一个人**提到，且指向的不是事实矛盾（而是「动机不够充分」「节奏处理不够经济」这类判断），在报告里标注为「挑剔读者单项意见，不进共识」。

## 席位四：付费读者

### 他在做什么

**核算**。他付了钱，他在算这一章的单位价格产出。

他的核心问题不是「好不好」，是「**我这一笔钱换到了什么**」。

### 打分偏好（五项）

| 项 | 他的偏好 | 判据 |
|---|---|---|
| 追读欲 | 中等 | 有回报就继续，没回报就观察两张 |
| 信息量 | **高要求** | 数「有效剧情字数 / 总字数」 |
| 情绪回报 | **高要求** | 这一章有没有兑现点什么 |
| 逻辑 | 中等 | 小洞能忍，大洞不能 |
| 值不值 | **唯一真正在意的一项** | 综合以上四项的加权结果 |

**他的分型特征**：值不值这一项与信息量、情绪回报高度相关（这三项通常同向）。如果他的值不值与另外两项背离，说明他在算**订阅性价比**（更长/更短），不是内容。

### 必然给低分的触发条件

| 触发 | 分数 |
|---|---|
| 一章 3000 字，有效剧情 <1500 字 | 信息量 ≤4，值不值 ≤4 |
| 连续 3 章无任何情绪回报 | 情绪回报 ≤3，值不值 ≤3 |
| 章末断在无关处（不是钩子） | 值不值 ≤4 |
| 首订章比免费章还短 | 值不值 ≤4 |
| 大段重复已知信息 | 信息量 ≤3 |

### 必然给高分的触发条件

- 这一章兑现了一条他等了几章的欠账
- 章末断在动作落下前
- 有效剧情字数占比高（≥70%）

### 他一票一句话的样子

`「这章 3400 字，换药那一段两百字，伤情一点没变，白看。剩下能算剧情的不到 2000 字。我全订了，但这样的话我可能只看免费章了。」`

**注意他的语言**：带数字、谈性价比、有明确的继续/停止决定。

## 四席的分数分布应该长什么样

健康的圆桌，五项分数的分布应该有明显的人格差：

| 项 | 核心 | 路人 | 挑剔 | 付费 |
|---|---|---|---|---|
| 追读欲 | 6–8 | 2–8（极端） | 5–7（平） | 5–7 |
| 信息量 | 5–7 | 4–6 | 3–8（极端） | 3–7 |
| 情绪回报 | 3–9（极端） | 5–7 | 5–7（平） | 3–7 |
| 逻辑 | 3–9（极端） | 5–7（无判断） | 2–9（极端） | 5–7 |
| 值不值 | 5–7（不看） | 5–6（不算） | 5–6（不看） | 2–9（极端） |

**读法**：每一席都有一到两项是极端值（他的主场），其余项挤在中间（他不看）。如果四席的分布形状相似，说明打分没分开。

## 一条硬规则

**四席不许完全一致**。SKILL 的禁止事项里写了这条，执行方法就是上面这些「必然给低分/高分的触发条件」——只要按各自的主场打分，分歧是必然而不是设计的。

如果打完发现四席分数确实一致，原因只有两个：

1. 这一章在某一方面好到/坏到让所有人的标准都被压过去（极少见，但要承认）
2. 打分时四个席位用了同一个人的标准

判据：看「各席一句话理由」是不是说的同一件事。是 → 第 2 种，重打。
