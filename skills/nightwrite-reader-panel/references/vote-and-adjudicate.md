# 分歧处理与不投票

圆桌的产物是**分歧点 + 最大共识风险 + 一处建议**，不是结论。这份讲怎么把分歧从「四个分数」变成可用的信息。

## 为什么不能投票

投票有一个隐含前提：四个席位的判断**可以互相替代**。这个前提是错的。

### 三个理由

**理由一：每个席位测的是不同的东西。**

核心读者测的是「与前文的一致性」，路人测的是「前 300 字的吸引力」，挑剔测的是「逻辑闭合」，付费测的是「单位价格产出」。这四件事哪个「多数」有意义？

举例：三个席位说「逻辑没问题」，挑剔说「第 20 段的因果倒置」。投票结果是 3:1，逻辑项通过。但那唯一的 1 是对的——第 20 段确实倒置了。

**理由二：席位的样本不对应真实人群。**

真实读者里路人占 40%、核心 25%、付费 20%、挑剔 15%（见 `comment-archetypes.md`）。票数相等 = 严重高估挑剔读者。

**理由三：投票会掩盖分歧的形状。**

分歧本身是信息：「核心 9 分、路人 3 分」说明这一章对老读者极好、对新读者极差。投票会把这个变成「6 分，通过」。

### 唯一允许的计数

不是投票，是**计名**：数「几个席位点了同一个具体问题」。这是共识的判据（SKILL 第 4 步的 ≥3 席），不是胜负的判据。

区别：计名产出「这是共识风险」，投票产出「这是结论」。前者交给作者决定，后者替作者决定。

## 分歧的排序

SKILL 用「分差 ≥3」筛分歧。筛完之后，分歧可能有 5–8 个，要排序。

### 排序算法

```
分歧优先级 = 分差 × 席位权重 + 主场加权
```

**席位权重**（按该项是谁的主场）：

| 项 | 主场席位 | 该席位的分在计算中权重 |
|---|---|---|
| 追读欲 | 路人 | 路人的分 ×2 |
| 信息量 | 挑剔 + 付费 | 两者各 ×1.5 |
| 情绪回报 | 核心 + 付费 | 两者各 ×1.5 |
| 逻辑 | 挑剔 + 核心（一致性） | 两者各 ×1.5 |
| 值不值 | 付费 | 付费的分 ×2 |

**主场加权的含义**：不是「主场的分更对」，是「主场的分更**敏感**」——他在这个维度上看得更细。所以这一项上的分歧，往往因为他注意到了一个别人没注意的细节。

### 算例

| 分歧项 | 各席分 | 分差 | 主场加权 | 优先级 |
|---|---|---|---|---|
| 逻辑 | 核心 8 / 路人 6 / 挑剔 3 / 付费 6 | 5（8 vs 3） | 挑剔 ×1.5、核心 ×1.5 | 5 × 1.5 = 7.5 |
| 追读欲 | 核心 6 / 路人 3 / 挑剔 6 / 付费 6 | 3（6 vs 3） | 路人 ×2 | 3 × 2 = 6.0 |
| 值不值 | 核心 6 / 路人 5 / 挑剔 5 / 付费 4 | 2（不足 3，不筛） | — | — |

按优先级：逻辑（7.5）> 追读欲（6.0）。

**读法**：逻辑项的分歧优先处理，因为挑剔读者在这一项上的 3 分可能指向一个别人没看到的硬问题。

## 辩论环节的规则

SKILL 第 3 步要求每个分歧项「让分歧项辩论一轮」。规则细化：

### 规则一：反驳必须带段号

合格：`「第 22 段他说『我从不欠人』，第 31 回他欠过李婶一条命。」`
不合格：`「这句话不符合人设。」`

**判据**：把段号删掉之后，这句话还成立吗？还成立 → 它没有具体指向，是感觉。

### 规则二：不许和事佬

**禁止的行为**：把自己的分数改成中间值。

**判据**：辩论之后，有没有席位改分？

- 没改 → 正常，分歧保留（这是大多数情况）
- 改了，且给出了**新的具体证据**（原来没看到的段）→ 合法改分
- 改了，理由只是「对方说得也有道理」→ 和事佬，作废

**改分必须留痕**：`挑剔 逻辑 3 → 5，理由：第 30 段补了一个推理环节，我漏看了。`

### 规则三：一轮，不是多轮

**只辩一轮**。第二轮会开始互相妥协，第三轮会变成协商。

**判据**：辩论记录里出现「那我们都同意……」→ 已经超出一轮了。

### 规则四：允许无结论

辩论结束，分歧还在，这是**正常的产出**。不需要解决它。

报告里保留两个立场，交给作者判断。这是 SKILL 第 6 步「不做结论性判决」的实质。

## 最大共识风险的判定

### 判据链

```
1. 一条问题被 ≥3 席点名 → 候选
2. 该问题的具体位置一致（同一段/同一句）→ 确认
3. 位置不一致但性质一致 → 降级为「潜在共识」
```

**第 2 步为什么重要**：三个席位都说「这章有信息冗余」，但指的是三个不同的段落 → 这不是一个共识问题，是三处小问题。

### 共识风险与低分的区别

| | 共识风险 | 单席低分 |
|---|---|---|
| 性质 | 三席以上同时指出的具体问题 | 一个席位在一个项上的极端低分 |
| 处理 | 优先改，因为它同时影响多个读者群 | 先看是不是主场意见，再定 |
| 例子 | 三席都说「第 14–16 段空转」 | 挑剔说「因果链不够经济」 |

**一条规则**：共识风险优先于任何单席低分。SKILL 写了「它比任何单个低分都重要」，理由就在这里——共识风险同时作用于多类读者，单席低分只作用于一类。

## 「如果只能改一处」的选法

SKILL 第 5 步要求给**一处**建议，并说明能改善哪几席。

### 选法

```
候选 = 所有共识风险 + 优先级最高的分歧项
打分 = 命中席位数 × 2 + 预估可改性
```

**预估可改性**：

| 改动类型 | 系数 |
|---|---|
| 删（压缩/删除） | 3 |
| 挪（位置调整） | 2.5 |
| 换（替换成别的动作/信息） | 2 |
| 补（新增场景/段落） | 1 |
| 改主线 | 0（不进本轮） |

### 算例

| 候选 | 命中席位 | 可改性 | 得分 |
|---|---|---|---|
| 第 14–16 段空转（共识风险，3 席） | 3 | 删 → 3 | 3×2+3 = 9 |
| 逻辑项分歧：第 22 段「我从不欠人」与第 31 回冲突 | 1（挑剔）+ 1（核心也提了） | 换 → 2 | 2×2+2 = 6 |

**选第一个**：删掉空转段，同时改善核心（不再拖）、路人（不再跳读）、付费（有效字数占比提升）三席。

### 一处建议的写法

必须说清三件事：

1. 改哪里（段号）
2. 改的动作类型（删/挪/换/补）
3. 预期改善哪几席，以及为什么

```
【如果只能改一处】
删掉第 14–16 段（620 字，三席点名的空转区）。
预期改善：核心 +2（拖沓感消失）｜路人 +3（前 3 段之后的第二次流失点被消除）｜付费 +2（有效字数占比从 58% 升到 74%）｜挑剔 +0（他不在意这段）
理由：三席同时点名，且改动是纯删除，不引入新的风险。
```

**「为什么是这一处而不是别的」必须写。** 只给建议不解释，等于替作者拍板。

## 报告的反模式

| 反模式 | 为什么不行 |
|---|---|
| 给四个分数然后写「综合 6.5 分」 | 平均数抹掉了分歧的形状 |
| 写「多数认为」 | 投票 |
| 写「应该改成……」 | 成稿，越权 |
| 四个席位的理由用同一种语气 | 没分开看 |
| 分歧项没有反驳记录 | 只打分没辩论 |
| 「建议全章重写」 | 不是「一处」 |
| 把挑剔读者的术语型意见写进共识 | 那不是共识 |

## 一个反直觉的结论

**最值得注意的分歧，是「核心高、路人低」的那一个。**

这个组合说明：这一章对老读者极好（有大量前文呼应），对新读者极差（看不懂在讲什么）。

这是**在慢性自杀**——老读者会自然流失（追完就走），新读者进不来，读者池只会缩小。而作者通常会因为「核心读者给了 9 分」而认为这一章没问题。

所以看到这个组合，优先级应该提到最高，高于任何共识风险。
