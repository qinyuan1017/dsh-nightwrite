# 多读者圆桌

让四类读者**分别打分并互相反驳**，产出**分歧点**与**最大共识风险**。不投票、不拍板。

## 四位参与者（各自独立，不许互相影响）

| 席位 | 立场 | 打分偏好 |
|---|---|---|
| **核心读者** | 认设定、认人物 | 设定崩了给低分，剧情慢能忍 |
| **路人** | 只看前 3 段 | 开局不抓就给低分 |
| **挑剔读者** | 专找逻辑洞 | 逻辑通了才给高分 |
| **付费读者** | 算性价比 | 这章给的信息量 ÷ 花的钱 |

## 执行步骤

**第 1 步：四位独立打分（先不许看别人的）**

每位按同一份评分项打分（追读欲 / 信息量 / 情绪回报 / 逻辑 / 值不值），1-10 分，并各写一句理由。

**第 2 步：公开分歧**

把所有「两位读者分差 ≥3 分」的项列出来。这些是真正需要决策的地方。

**第 3 步：让分歧项辩论一轮**

对每个分歧项，各席位给出**反驳对方的理由**。规则：

- 反驳必须针对具体段号；
- 不许用「感觉」；
- 不许改分数到自己和对方中间（那是和事佬，不是辩论）。

**第 4 步：提取最大共识风险**

一条被认为「有问题」的项被 **3 席以上**同时点名 = 最大共识风险。它比任何单个低分都重要。

**第 5 步：出「如果只能改一处」的建议**

综合分歧与共识，给出**一处**最值得改的地方，并说明它同时能改善哪几席的分数。

**第 6 步：不做结论性判决**

不写「通过」「不通过」「应该这样改」。只给分歧、共识、和一处建议。

## 输入

- 待议正文（`chapter.get`）
- 四类读者的画像（来自 `nightwrite-reader-persona`，或按上表设定）
- 若有多个候选改法：各候选稿全文

## 输出格式

```
【独立打分】
  项          | 核心 | 路人 | 挑剔 | 付费
  追读欲      |  <n> |  <n> |  <n> |  <n>
  信息量      |  …
  情绪回报    |  …
  逻辑        |  …
  值不值      |  …
【各席一句话】核心：<…>｜路人：<…>｜挑剔：<…>｜付费：<…>
【分歧项】（分差 ≥3）
  1. <项> — 核心 <n> vs 路人 <n>
     核心反驳：<针对第 X 段>
     路人反驳：<针对第 X 段>
【最大共识风险】（≥3 席点名）
  · <问题> — 点名席位：<…> — 具体位置：第 <X> 段
【如果只能改一处】
  <改什么> — 预期改善：核心 <+?> 路人 <+?> 挑剔 <+?> 付费 <+?>
【不做判决】本报告不替作者拍板，改不改、改哪处由作者定
```

## 检查清单

- [ ] 四位先独立打分，没有互相影响
- [ ] 五项评分项全部打满
- [ ] 分歧项按「分差 ≥3」筛选
- [ ] 每个分歧项都有一轮互相反驳，且带段号
- [ ] 最大共识风险按「≥3 席」筛选
- [ ] 只给了一处建议，不是一堆
- [ ] 明确写了「不做判决」
- [ ] 没有直接重写任何段落

## 禁止事项

- 不许替作者拍板（不写「应该改成…」的成稿）。
- 不许直接重写正文。
- 不许投票定胜负（多读者不是为了多数决）。
- 不许让四个席位得出完全一致的分数（那说明没分开看）。
- 不许在辩论环节和稀泥（把分数改到中间值）。
- 不许把「最大共识风险」写成主观偏好——必须是 ≥3 席点名的具体问题。
