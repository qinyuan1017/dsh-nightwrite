# 读者疑问清单

一条疑问要么是**钩子**（想看下去），要么是**漏洞**（看不懂）。这份手册只做分类，不做别的。

## 两分法

| 类型 | 读者状态 | 判定 | 处理 |
|---|---|---|---|
| **悬念** | 知道自己不知道，且想知道 | 有明确「谁/什么」指向，且文本暗示过答案存在 | 保留，这是资产 |
| **困惑** | 不知道自己在不知道什么 | 读者连问题都问不出，只觉得糊 | 必须补信息 |
| **硬伤** | 问了但文本根本无法回答 | 前后矛盾或信息缺失 | 转 `changye-continuity-pass` |

## 执行步骤

**第 1 步：逐段记「读者此刻会问什么」**

以第一遍阅读的视角，每段记一到两个问题。记原话（「他为什么要救她？」），不记抽象（「动机不明」）。

**第 2 步：分类三档**

对每条问题问三个问题：

1. 读者问得出具体的人/事/物吗？→ 问不出 = **困惑**
2. 文本里有没有暗示「后面会讲」？→ 有 = **悬念**
3. 文本里有没有能回答的信息，但读者没找到？→ 有 = 信息投放问题（仍算困惑）
4. 前后文互相矛盾？→ **硬伤**（转审校）

**第 3 步：查「藏得对不对」**

悬念要成立必须满足：**读者知道有这么个东西存在**。

- 好：读者知道「他袖子里有东西」，不知道是什么。
- 坏：读者根本不知道袖子里有东西，后文突然掏出来——这不是悬念，是突兀。

**第 4 步：查信息投放位置**

困惑常常不是「没写」，而是「写在读者已经放弃之后」。检查每条该说明的信息是否出现在**读者产生疑问的那一段之后 2 段内**。

**第 5 步：只分类，不改稿**

## 输入

- 待评正文（`chapter.get`）
- `outline.intent`（判断哪些是故意藏的）
- `ledger.get`（判断某个信息是否账本里有但正文没给）

## 输出格式

```
【疑问清单】
  #1 第 <X> 段「<读者原话问题>」→ <悬念/困惑/硬伤>
      依据：<文本哪里暗示/哪里缺失>
  #2 …
【悬念】（保留）
  · <问题> — 指向：<谁/什么> — 暗示位置：第 <X> 段
【困惑】（必须补）
  · <问题> — 缺什么：<信息> — 应补在：第 <X> 段之后 2 段内
【硬伤】（转审校）
  · <问题> — 矛盾处：第 <X> 段 vs 第 <Y> 段
【藏得对不对】
  · <悬念名> — 读者是否知道「有这么个东西」：<知/不知> → <成立/突兀>
【统计】悬念 <n> · 困惑 <n> · 硬伤 <n>
```

## 检查清单

- [ ] 逐段记过疑问，用的是读者原话
- [ ] 每条都分了三档之一，有判定依据
- [ ] 悬念逐条查了「读者是否知道有这么个东西」
- [ ] 困惑逐条给了「应补在哪一段之后」
- [ ] 硬伤已标记转审校
- [ ] 统计数字齐了
- [ ] 没有直接回答剧情问题

## 禁止事项

- 不许直接回答剧情问题（你不是作者，不替作者解释设定）。
- 不许改稿。
- 不许把困惑说成「留白艺术」。读者问不出问题的地方不是艺术，是漏。
- 不许把悬念说成漏洞。有暗示的保留就是资产。
- 不许在没有读完全章的情况下判断某处是困惑。
