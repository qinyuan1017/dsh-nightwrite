# 规则白皮书的写法

SKILL.md 给了「允许 / 禁止 / 代价」三段式，和「一次最多立 5 条」的纪律。这份补三件事：**三段的精度标准、规则的三种类型、以及怎样让规则真的被正文用到**。

---

## 一、三段的精度标准

### 允许：必须有上限

「允许 X」这句话，如果 X 没有上限，它在剧情需要时会被无限拉长。

| 不合格 | 问题 | 合格 |
|---|---|---|
| 可以修习法术 | 无上限 | 可修至三阶；三阶以上需以寿元为引 |
| 可以召唤灵兽 | 无上限 | 可召一兽，兽的品阶不得超过自身一阶 |
| 内力可以外放 | 无上限 | 外放最远三丈；三丈外只剩推力，无杀伤 |

**判据：这条 `allow` 能不能回答「最多多少」？** 不能 → 没写完。

### 禁止：必须与某人的目标冲突

**这是最容易写废的一段。** 一个没有被任何人想违反的禁令，在剧情里永远不会被触发。

**判据**：把 `forbid` 的句子拿去比对 `characters.goal`。有没有至少一个角色的目标需要违反它？

- 有 → 这条禁令会进剧情
- 没有 → 这条禁令是装饰（要么删，要么补一个需要的角色）

**例**：
```
forbid：不可对同族使用借命术
characters 二叔的 goal：三个月内还清赌债
→ 二叔需要寿元，同族是最容易的目标 → 冲突成立，这条禁令会进剧情
```

### 代价：必须是可观察的失去

| 不合格 | 为什么 | 合格 |
|---|---|---|
| 会遭反噬 | 反噬长什么样？无法判定 | 每用一次，失去一段记忆（施术者自选） |
| 折寿十年 | 十年在故事里看不出来 | 每用一次，老了五岁（外貌可观察） |
| 心魔缠身 | 无法判定强度 | 每用一次，连续三夜无法入睡，第三天开始听见那个人的声音 |
| 有报应 | 无法判定 | 用它换来的东西，会在同一年以同样的方式失去 |

**判据：这个代价能不能在正文里被写出来？** 能写出一句具体的描写 = 合格。

## 二、规则的三种类型

不是所有规则都是禁令。三类要分开写，判法完全不同。

### 类型 A：物理规则（世界怎么运作）

**例**：「灵气只能从地脉来，地脉有走向，走向可断。」

**判据**：这类规则决定**地理与建筑**。写完要能回答「这块地为什么能修炼」。

**特征**：不涉及道德，不可违反，违反了就是 bug。

**检验**：能不能用它画一张地图？能 → 写对了。

### 类型 B：制度规则（人可以做什么）

**例**：「仵作不得验自家人的尸；违反者除籍。」

**判据**：这类规则有**执行者**。写完要能回答「谁来判断、谁来罚」。

**特征**：可违反，但代价是被制度惩罚。

**检验**：能不能说出「谁执行这条规则」？说不出 → 这条规则是空的（没人执行 = 不存在）。

### 类型 C：代价规则（做某事必须付什么）

**例**：「借命术：取他人三年寿，施术者失一段记忆。」

**判据**：这类规则的核心是**兑换率**。写完要能回答「一比几」。

**特征**：不禁止，但要付价。

**检验**：能不能算出「为了达到 X，要付多少」？算不出 → 兑换率没定。

### 三类的比例

| 类型 | 建议占比 | 作用 |
|---|---|---|
| A 物理 | 40% | 决定舞台 |
| B 制度 | 40% | 决定冲突 |
| C 代价 | 20% | 决定重量 |

**全是 A → 世界很大但没人有事做。**
**全是 B → 世界像办公室，没有惊奇。**
**全是 C → 读者疲于算账。**

## 三、五条规则的排法

SKILL.md 要求「一次最多立 5 条」。这 5 条怎么选？

### 优先级

1. **第 1 条：主角能力的上限与代价**（没有它，主角打谁都赢或打谁都输）
2. **第 2 条：主角最想违反的那条禁令**（这是主线的发动机）
3. **第 3 条：世界的最强力量是什么、有没有**（决定反派的天花板）
4. **第 4 条：移动/通信的规则**（决定「三天能不能赶到」这类判定的基础）
5. **第 5 条：死亡/救治的规则**（决定「他会不会死」的紧张度）

### 第 4 条最容易漏

**移动与通信规则决定了 90% 的时间线判定。** 如果没立「驿马日行多少里」「传信要几天」，后面每一章的时间冲突都判不了。

```
允许：驿马日行二百里，换马可至三百里
禁止：无（但夜间不得驰驿）
代价：换马需验符，无符者扣马
```

### 第 5 条决定紧张度

**如果世界里有万能解药，主角永远不会真危险。** 必须明确：

```
允许：断骨可接，三日可行走
禁止：断肢不可再生；失血过半不可救
代价：救治需以自身气血为引，救人者三日无力
```

## 四、规则的写法模板

```
【规则】<名>
【类型】A 物理 / B 制度 / C 代价
【允许】<能做什么 + 上限>
【禁止】<不能做什么 + 执行者>
【代价】<失去什么，可观察>
【兑换率】<仅 C 类：一比几>
【冲突角色】<谁的 goal 需要违反它>
【留给写手的禁区】<这条规则禁止写哪类情节>
```

### 「留给写手的禁区」怎么填

这是 SKILL.md 要求输出但最容易敷衍的一项。它必须具体到「不能写哪一场戏」。

| 敷衍 | 合格 |
|---|---|
| 「不能写太强的」 | 「不许写主角单人破阵；破阵必须有人牵制」 |
| 「遵守设定」 | 「不许写他隔空取物；取物必须接触」 |
| 「注意代价」 | 「不许写他连续两次借命而不失忆；每次使用必须有一句写他忘了什么」 |

**判据：这条禁区能不能直接拿去否掉一段草稿？** 能 → 合格。

## 五、规则与正文的咬合验证

立完规则，做三件事验证它真的会被用到：

### 验证 1：算术题

用这条规则算一道题。

```
规则：外放最远三丈
题：主角站在院门，敌人在院墙外五丈，他能打到吗？
答：不能，超出 2 丈
```

**算不出来 → 规则太模糊。**

### 验证 2：找一场戏

给每条规则找一场「会用到它」的戏。找不到 → 这条规则是装饰。

### 验证 3：找一次违反

给每条 `forbid` 找一次「差点被违反」的戏。找不到 → 这条禁令没有张力。

**三条验证全过，规则才算活。**

## 六、六个写废的规则

| 写法 | 病 | 修法 |
|---|---|---|
| 「修炼分九境」 | 这是分类不是规则 | 补 allow/forbid/cost |
| 「违者天诛」 | 代价不可观察 | 改成具体的死法/失去 |
| 「视资质而定」 | 无法判定 | 给一个可测的标准（例如「能引气入体者，十人中一人」） |
| 「上古秘法，无人知晓」 | 等于没写 | 要么写清，要么不写 |
| 「一切以实力为尊」 | 无信息量 | 换成「谁能调兵、谁能收税」 |
| 「代价由剧情决定」 | 破坏自洽 | 定额化 |

## 七、修改规则的纪律

SKILL.md 禁止「改 `rules` 来给角色加能力」。补三条：

### 改规则必须声明

```
【规则变更】借命术
  旧：一次最多三年
  新：一次最多三年，但可用寿元换取加倍
  理由：第 40 回需要一个「不惜代价」的选择
  影响：第 12 / 25 回的两处已写正文需检查（他不该知道加倍之法）
  新立/修正：修正
```

**必须写「影响哪几回」**。不写 = 静默改设定。

### 改规则优先「加限制」而非「加能力」

**判据：这次修改是让世界更窄还是更宽？**

- 更窄（加限制）→ 通常安全，因为它不会破坏已有情节
- 更宽（加能力）→ 危险，因为它会让前面的困难变得可笑

**例**：主角前面花了 10 回解决一个难题，第 40 回你加了一条「其实可以用 X 一次解决」——前 10 回的紧张全废。

### 不许改已发布的规则

已发布的规则是读者的共识。要改只能**补一条新规则来解释旧规则**（「其实那不是全部」），不许直接覆盖。

## 八、规则白皮书的落盘检查

- [ ] 每条都有 allow（带上限）
- [ ] 每条都有 forbid（且能指出一个想违反它的角色）
- [ ] 每条都有 cost（可观察的失去）
- [ ] 每条都标了类型（A/B/C）
- [ ] C 类有兑换率
- [ ] 本次新增 ≤5 条
- [ ] 每条都填了「留给写手的禁区」，且具体到能否掉一段草稿
- [ ] 每条都过了三道验证（算术题 / 找一场戏 / 找一次违反）
- [ ] 与旧账的冲突已写进输出格式的「与旧账冲突」栏
