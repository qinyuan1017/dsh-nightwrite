> 适用：第 4 步建 `terms` 时读这份；发现正文里「一个东西两种写法」时读这份。

# 专名索引的维护

SKILL.md 给了「一物一名」和 `firstAt` 的合法性要求。这份补：**什么该进索引、命名规则、别名怎么处理、以及索引怎样才不会膨胀成垃圾场**。

---

## 一、什么该进索引

### 三条入索引判据

**判据 1：有专名。**

- 有专名 → 候选
- 只是泛称（「一个公差」「几辆马车」） → 不入

**判据 2：会被第二次提到。**

只出现一次的物件，即使有名字也不入（除非它有剧情功能）。判据：**后文会不会再有「它」？**

**判据 3：有可感官验证的形态。**

「三寸长的黑铁牌」入；「一股神秘的力量」不入（那是规则，归 `rules`）。

### 该入的五类

| 类别 | 例 | 关键字段重点 |
|---|---|---|
| **物件** | 玄铁令、父亲的刀 | `definition` 要能画出来 |
| **地名** | 陈留县、望江楼 | 同时进 `locations` |
| **职位/机构** | 仵作、漕帮 | `definition` 写职权 |
| **功法/术语** | 借命术、引气入体 | 同时进 `rules` |
| **称号** | 「陈留一把刀」 | `definition` 写谁给的、为什么 |

### 不该入的三类

| 类型 | 为什么 |
|---|---|
| 泛称 | 无专名，入索引会让索引膨胀 |
| 一次性道具 | 后文不再出现，只是场景零件 |
| 修辞造词 | 「命运的齿轮」这类，不是世界里的东西 |

---

## 二、命名的四条规则

### 规则 1：一名一物，一物一名

**同一个东西只许一种写法。** 这是 SKILL.md 的硬要求。

执行方式：**建条目时,`name` 必须是正文里已经在用的那个写法**，不许「我更喜欢这个写法所以改」。

**判据：正文首次出现时的写法 = `name`。**

### 规则 2：`name` 用全称，不用简称

`name` = 「玄铁令」，不是「令牌」。

**理由**：简称是别名的来源。`name` 用全称，简称在 `definition` 里注明。

### 规则 3：不用「的」结构

| 不合格 | 合格 |
|---|---|
| 父亲的刀 | 沈家刀 |
| 二叔的田 | 西河田 |
| 那个铜片 | 袖中铜片 |

**理由**：「X 的 Y」结构会随持有者变化而变化，不是稳定专名。

**例外**：如果正文里已经用了「父亲的刀」且它是情感核心，那么 `name` = 「父亲的刀」，且 `definition` 里写「沈砚父亲留下的验尸刀，长一尺二」。**专名的价值在于稳定，不在于好看。**

### 规则 4：同类同构

同类专名用同一种构词：

| 类 | 构词 |
|---|---|
| 地名 | 双字 + 县/州/楼/渡 |
| 功法 | 双字 + 术/诀/法 |
| 物件 | 材质 + 形制 |

**判据：把同类专名列在一起，看起来像同一个世界的东西吗？** 不像 → 构词混乱，读者会觉得是拼凑的。

---

## 三、别名的三种处理

### 情形 1：别名是自然的称谓差异（最常见）

同一个人，官称「沈仵作」，熟人叫「沈砚」，敌人叫「那小子」。

**处理**：`name` = 正式名（沈砚）。**别名不建独立条目**，写在 `definition` 里：

```
name: 沈砚
definition: 陈留县仵作（黑铁验尸刀一把）。别名：沈仵作（官称）、砚儿（阿禾用）
```

**为什么别名不建条目**：建了就会变成「两个东西」，`characters` 里会出现重复卡（SKILL.md 明令禁止）。

### 情形 2：别名是「民间叫法 vs 官方名称」

同一个东西，百姓叫「黑牌」，官府文书叫「玄铁令」。

**处理**：`name` = 出现次数多的那个。另一个写进 `definition`。

**判据：出现次数怎么算？** 搜全部已写章，数两种写法的出现次数。多的胜。

**理由**：读者的习惯由多数用法形成。

### 情形 3：别名其实是两个东西

「黑牌」和「玄铁令」形似但不同。

**处理**：建两条。且必须在各自的 `definition` 里写清区别：

```
name: 玄铁令
definition: 黑色铁牌，三寸，正面刻「玄」，背面有齿，共三枚
name: 黑牌
definition: 漕帮的通行牌，黑色木牌，无字，只认人不认牌（形似玄铁令，第 17 回被误认）
```

**判据：两者能不能被一个角色搞混？** 能搞混 → 这是好设计（可以制造误会）；不能搞混 → 可能其中一个该删。

---

## 四、`definition` 的写法

### 必须能通过「画像测试」

**判据：只给 `definition`，一个画师能不能画出来？**

| 不合格 | 合格 |
|---|---|
| 「一把很特别的刀」 | 「长一尺二，单刃，刀柄缠黑布，刃口有三处缺口」 |
| 「一张古怪的符」 | 「黄纸，三寸宽七寸长，朱砂画的不是字，是七个圆圈」 |
| 「一间老屋」 | 「两进，门楣塌了一半，院里有口枯井」 |

### 必须有「反例锚」

**`definition` 里最好有一句「不是什么」**，防止后文写歪：

```
definition: 黑色铁牌，三寸长，正面刻「玄」，背面有齿（不是铜的；不带链子；不能挂在腰上，必须贴身）
```

括号里的三条都是「反例锚」，后文写到它时可以直接比对。

### 职位类要写职权

职位不是外形，是权限。

```
name: 仵作
definition: 县衙属役，掌验尸、填尸格；可入现场但不能下令；不得验自家人；月俸三钱；不入品
```

**「可入现场但不能下令」这一句是关键**——它决定了这个角色能不能调动别人。

## 五、`firstAt` 的规则

### 必须是具体章号

`firstAt: 4`，不是「早期」。

### 必须不超过已写进度

SKILL.md 明文。**判据：`chapter.list` 的最大章号 ≥ `firstAt`。**

### 如果 `firstAt` 指向的那一章没有它怎么办

**这是维护中最常见的问题**：账本记 `firstAt: 4`，但第 4 回里根本没有「玄铁令」。

**处理**：
1. 搜全部已写章，找真正的首次出现。
2. 改 `firstAt` 为真实值。
3. 若真的从未出现 → 这是「预留专名」，在 `definition` 末尾标【未出现】。

**「预留专名」是允许的，但必须标注**。不标的话，后面会以为它已经出现过了。

---

## 六、索引膨胀的控制

### 上限

| 全书字数 | terms 上限 |
|---|---|
| 30 万字 | 60 条 |
| 100 万字 | 150 条 |
| 200 万字 | 250 条 |

**超过上限的处理**：把「出场 1 次且后文不再出现」的条目移到 `definition` 的备注里，或直接删。

**判据：删掉它，后文会不会写错？** 不会 → 删。

### 分级

| 级 | 说明 |
|---|---|
| **核心专名** | 出现在 ≥5 回，或承载核心设定 |
| **一般专名** | 出现在 2–4 回 |
| **边缘专名** | 只出现 1 回 |

**只给核心专名写详细 `definition`**；一般专名一句话；边缘专名只留 name + 一句。

---

## 七、维护工序

每写完一卷，做一次索引维护：

1. **扫新增**：本卷正文里出现的所有专名，哪些还没入索引？
2. **查别名**：同一东西有没有第二种写法？
3. **验形态**：本卷对已索引物件的描写，与 `definition` 一致吗？
4. **校 `firstAt`**：新条目的 `firstAt` 是否真实？
5. **清边缘**：只出现一次且后文不用的，降级或删。
6. **查同构**：本卷新增的专名，构词与既有同类一致吗？

### 第 3 步最重要

**「验形态」是防穿帮的核心。** 例：

```
账本：玄铁令，三寸长
第 38 回：「他摸出那块巴掌大的令牌」
→ 巴掌大 ≠ 三寸 → 冲突
```

**判据：本卷每一处对已索引物件的形态描写，逐句比对 `definition`。** 这个是机械比对，不需要判断。

---

## 八、输出格式的填法

```
【专名】玄铁令｜物件｜黑色铁牌，三寸长，正面刻「玄」，背面有齿
      （不是铜的；必须贴身）｜首现 第 4 回
```

**三样必须有**：类别、可画出的定义（含反例锚）、真实章号。

```
【专名】仵作｜职位｜县衙属役，掌验尸填尸格；可入现场不可下令；不得验自家人；月俸三钱
      ｜首现 第 1 回
```

**职位类要把权限写进定义**，否则后面写「仵作下令抓人」就判不出来。
