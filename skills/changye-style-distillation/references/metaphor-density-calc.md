# 比喻密度的计算

> 适用：第 2 步量「比喻密度」时读这份；判「这本书的意象浓度是多少、要不要在风格卡里限定上限」时读这份。

SKILL.md 给的算法是「明喻+暗喻句数 ÷ 千字」。这个算法有三个坑：**算句还是算处**、**算不算借喻/通感**、**分母是什么**。这份把口径定死，并给出「量完之后怎么变成规则」。

---

## 一、分母口径

```
比喻密度 = 比喻处数 ÷ (总字数 ÷ 1000)
```

- **总字数**：不含标点、空白、标题（与句长统计同口径）
- **必须用千字做单位**，不用百分比——比喻本来就是低频项，用百分比会得到 0.x% 这种看不出差别的数

**为什么是「处」不是「句」**：一句里可以有两个比喻（「他像被抽了骨头，整个人塌成一摊泥」），算 2 处。按句算会低估密集段。

---

## 二、什么算一处比喻

### 计入（四类）

| 类型 | 判据 | 例 |
|---|---|---|
| **明喻** | 有喻词（像/如/似/仿佛/好像/宛如/如同/好比）且本体喻体都出现 | 「他的声音像砂纸刮过木板」 |
| **暗喻** | 无喻词，用「是/成了/变成」连接本体喻体 | 「他是一块被水泡烂的木板」 |
| **借喻** | 本体不出现，只有喻体在语境中可还原 | 「那块砂纸又响了起来」（指他的声音） |
| **通感** | 跨感官的映射 | 「他的声音是青灰色的」 |

### 不计入（六类，容易误计）

| 类型 | 为什么不算 | 例 |
|---|---|---|
| 成语 | 词汇化，读者不激活意象 | 「心如刀割」「面如死灰」 |
| 固定搭配 | 同上 | 「月光如水」「光阴似箭」 |
| 量词/单位 | 语法功能，非修辞 | 「一丝风」「一线希望」「一团乱」 |
| 程度副词化 | 已虚化 | 「快得像飞」「多得数不清」 |
| 轻微拟人 | 常规表达 | 「风停了」「天色暗下来」 |
| 类比/举例 | 逻辑功能 | 「就像上次一样」「如同他所料」 |

**判断口诀**：**遮住喻体，读者还能不能画出画面？** 不能 = 不算。「面如死灰」遮住「死灰」，读者照样懂 = 不算；「他的脸像被人从里面抽走了光」遮住后画不出 = 算。

---

## 三、计数的三个纪律

### 纪律 1：只数「作者造的」

读者一眼能看出是成语/俗语的，一律不算。这条能排除 60% 的误计。

### 纪律 2：同一意象的重复只算首次

「他的手像冰」在第 2 段出现，第 9 段又出现「他的手还是像冰」——第 2 次算 0.5 处（重复使用，不新增意象）。

**为什么**：密度衡量的是「意象供给量」，重复供给不增加读者的认知负担。

### 纪律 3：连续比喻算独立处

一个句子里排比式连用三个比喻（「像刀，像冰，像烧红的铁」），算 3 处。这是高密度信号，必须计入。

## 四、参照带

| 密度（处/千字） | 判定 | 体感 |
|---|---|---|
| 0–1.5 | 极稀 | 冷硬、克制、偏白描 |
| 1.5–3 | 稀 | 主流网文 |
| 3–5 | 中 | 文学性明显 |
| 5–8 | 密 | 抒情/氛围向，读者需要慢读 |
| >8 | 过密 | 意象互相踩踏，读者记不住任何一个 |

**注意**：**过密不是「更文学」，是「更模糊」**。同一段里 4 个比喻并列，读者只会记住最后一个。

### 分场景参照

| 场景 | 参照带 |
|---|---|
| 动作/打斗 | 0.5–2 |
| 对话交锋 | 0–1.5 |
| 心理/回忆 | 3–7 |
| 环境/氛围 | 4–9 |
| 仪式/高潮 | 3–6（可短时冲高） |

**判据：动作场景密度 >4 = 拖慢节奏**，读者会在打斗中被迫停下来解析比喻，紧张感断掉。

---

## 五、质量的四个维度

密度只说明多少，不说明好坏。四个维度判定质量：

### 维度 1：喻体是否在本书的世界里

- 好：「他的背像一张拉满的弓」（古代背景，弓在）
- 差：「他的心跳像节拍器」（古代背景没有节拍器）

**判据：喻体必须是这个世界的人见过的东西。** 这是最硬的一条，也是最容易被 AI 违反的（AI 会调用现代/通用意象）。

### 维度 2：喻体是否与情绪同向

- 好（悲伤场景）：「天光像浸了水的纸，一点点塌下去」
- 差（悲伤场景）：「天光亮得像刚擦过的铜镜」

**判据：喻体的联想方向必须与场景情绪一致**，反向会破坏情绪。

### 维度 3：喻体是否落在人物能感知的范围

- 好（农夫视角）：「那字迹歪得像被犁过的地」
- 差（农夫视角）：「那字迹像某种后现代的解构」

**判据：视角人物不认识的东西不能做喻体**（见 `references/narrative-perspective.md` 的视角越界）。

### 维度 4：是否有「二次展开」

- 好：「他像一块被水泡烂的木板——还是那种沉在河底、连浮都浮不起来的。」
- 差：「他像一块被水泡烂的木板。」

**判据：二次展开让比喻从「贴标签」变成「真的在看」。** 但**每千字最多 1 处二次展开**，多了变啰嗦。

## 六、量完之后怎么变成规则

风格卡里不许写「比喻适中」。必须写成**上限 + 区间 + 场景差异**：

```
【比喻】
  全书 2.8 处/千字（稀）
  心理场景 4–6 处/千字
  动作场景 ≤1.5 处/千字
  单段 ≤2 处（超出则删至 2）
  禁：现代喻体、跨视角喻体
  二次展开：≤1 处/千字
```

**这样写才能用来判稿**：写手写完一章，数一下心理场景的比喻，超过 6 就要删。

### 反面例子（不能这么写）

- 「比喻要恰当」（无法判定）
- 「少用比喻」（没说多少算少）
- 「比喻要有文学性」（循环定义）

## 七、统计表模板

```
【样本】4 章 · 11,240 字
【总密度】32 处 ÷ 11.24 = 2.85 处/千字（稀）
【分类】
  明喻 18｜暗喻 9｜借喻 3｜通感 2
【分场景】
  动作（约 1800 字）：4 处 → 2.2 处/千字（略高，动作宜 ≤1.5）
  心理（约 2100 字）：13 处 → 6.2 处/千字（在带内）
  环境（约 1400 字）：9 处 → 6.4 处/千字（在带内）
  对话（约 3200 字）：3 处 → 0.9 处/千字（正常）
【质量】
  喻体时代错位：0 处
  喻体与情绪反向：1 处（第 7 回：「天光亮得像刚擦过的铜镜」出现在葬礼段）
  二次展开：2 处
【结论】
  总密度健康；动作场景需下调；有 1 处情绪反向需点名
```

## 八、三个常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 把成语当比喻 | 密度虚高 2–3 倍 | 用「遮住喻体能否画出画面」筛 |
| 按句计数 | 密集段被低估 | 按处计数 |
| 只看总密度 | 掩盖场景失衡 | 必须分场景量 |

**最容易犯的是第一个**。一本古风文的成语密度极高，如果全算成比喻，会得出「8 处/千字」的荒谬结论。
