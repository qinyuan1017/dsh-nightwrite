# 叙事视角的判定

> 适用：第 2 步量「视角一致性」时读这份；判「这一章的机位是什么、有没有越界」时读这份。

SKILL.md 只给了「人称（第一/第三）× 聚焦（单一/多视点）」。实际文本里视角有六种，且**越界是这本书风格卡里最必须写清的一条**——因为视角一旦不统一，读者的代入感会碎，而这是最难事后修的。

---

## 一、六个视角类型

| 代号 | 名称 | 判据 | 特征 |
|---|---|---|---|
| **P1** | 第一人称限知 | 「我」+ 只能知道「我」知道的 | 代入最强，信息受限最严 |
| **P2** | 第一人称全知 | 「我」+ 能知道别人心里的事 | 极罕见，通常用于「多年后回忆」框架 |
| **P3L** | 第三人称限知（单视点） | 「他/她」，全章只跟一个人 | 网文主流 |
| **P3M** | 第三人称限知（多视点） | 「他/她」，按场景切换视点人物 | 需**显式分隔**（空行/分隔符/章分） |
| **P3O** | 第三人称客观（摄像机） | 只写看得见听得到的，不写心理 | 冷硬，适合悬疑/动作 |
| **P3G** | 第三人称全知 | 可自由进入任何人的心理，可评论 | 传统说书体 |

### 判定的三步法

1. **看人称代词的主语**：谁是主格？（我 / 他）
2. **看心理描写的归属**：全章的心理描写属于几个人？（1 → 限知；≥2 且无分隔 → 全知）
3. **看叙述者是否评论**：有没有「他不知道，这一去将……」这类叙述者插话？（有 → 全知倾向）

三步的结果查表：

| 人称 | 心理归属 | 叙述者评论 | 判定 |
|---|---|---|---|
| 我 | 1 | 无 | P1 |
| 我 | 1 | 有 | P1 + 越界（见第三节） |
| 他 | 1 | 无 | P3L |
| 他 | ≥2，有分隔 | 无 | P3M |
| 他 | ≥2，无分隔 | 无 | P3G 误用（最常见的问题） |
| 他 | 0 | 无 | P3O |
| 他 | 任意 | 有 | P3G |

## 二、视角越界的六种形态

这是量视角一致性时要逐条查的。

### 越界 1：限知视角里写别人的心理

- 违规：「她把茶推过来。（P3L，视点=他）她心里想，这个人终究还是来了。」
- 判据：视点人物看不到的内心活动被写出来。

**这是最高频的越界**。判法：本章所有「她想/他觉得/他明白」的主语，是不是都是视点人物？有例外就是越界。

### 越界 2：限知视角里写视点人物看不见的事

- 违规：视点人物在屋里，写「院外的雪落了三寸」。

**判据**：这个信息能不能通过视点人物的感官获得？不能 = 越界。

**例外**：如果视点人物**事后知道**，可以用「后来他才知道」的回顾句，但每章 ≤1 次。

### 越界 3：叙述者评论

- 违规：「他推开门。他不知道，这一推，推开的是他一生的劫。」

**判据**：这句话是「谁说的」？如果是叙述者在评价，越界。

**注意**：这是 AI 的高频写法（`changye-de-ai-style` 的「意义膨胀」信号）。风格卡里必须写明「禁叙述者评论」。

### 越界 4：多视点无分隔

- 违规：第 8 段还在写 A 的心理，第 9 段直接写 B 的心理，中间没有空行/分隔符。

**判据**：视点切换必须在**段界且有视觉分隔**（空行、`※`、或另起一章）。

### 越界 5：人称滑移

- 违规：全章第三人称，某段突然出现「我不由得想起」。

**判据**：搜「我」字，除了对白内，正文里出现即越界。

### 越界 6：全知视角里假装限知

- 表现：明明能写所有人的心理，却在某段故意只写一个人的，造成信息释放不均。
- 这**不算违规**，但要在风格卡里标注「P3G，但局部采用限知手法」。

**判据**：全知视角是作者的合法选择，不算越界，但需要声明。

## 三、六种越界的量化

风格卡里视角一项必须写成：

```
【视角】P3L（第三人称限知，视点人物=主角）
  越界：0 处（达标）/ n 处（需修）
  具体：<段号 + 越界类型>
  允许的例外：<回顾句 n 次/章>
```

**阈值**：
- 0 处 = 干净，可作为后续写作的标准
- 1–2 处 = 正常波动（作者偶尔手滑）
- ≥3 处/章 = 视角不统一，需要整章统一

## 四、视角选择与题材的匹配

| 题材 | 主流视角 | 理由 |
|---|---|---|
| 升级流/系统流 | P3L | 读者要跟着主角获得信息 |
| 悬疑/推理 | P3L 或 P3O | 限知制造谜题；客观让读者自己推 |
| 群像/权谋 | P3M | 需要多方的算计 |
| 言情 | P1 或 P3L（双视点 P3M） | 内心戏是核心 |
| 恐怖 | P1 | 代入最强，恐惧最真 |
| 史诗/家族 | P3G | 时间跨度大，需要一个俯瞰的叙述者 |

**判据：题材与视角不匹配 = 风格卡里必须写明「这是刻意的偏离」+ 代价**。例如用 P3G 写升级流，代价是「主角的成长爽感会被稀释」。

## 五、视角的距离（容易漏的一项）

即使同为 P3L，**叙述者与视点人物的距离**也可以差很远。这是风格的关键，但很少被量。

| 距离 | 判据 | 例 |
|---|---|---|
| 极近 | 大量自由间接引语，叙述语与人物内心无缝 | 「他不想进去。进去就得认——认什么？认自己这些年白活了。」 |
| 中 | 有心理描写，但用「他想」引出 | 「他不想进去。他想，进去就得认，认了这些年就白活了。」 |
| 远 | 只有动作与对白，心理靠推测 | 「他在门口站了很久，最后没有进去。」 |
| 极远 | 甚至有客观化的比喻 | 「他在门口站着，像一根钉在门框上的木桩。」 |

**判法**：抽 10 个含心理的句子，数「他想/她觉得/心里」这类显式标记的数量。

| 显式标记占比 | 距离 |
|---|---|
| 0–10% | 极近 |
| 10–40% | 中 |
| 40–70% | 远（标记多说明作者在「报告」心理） |
| >70% | 极远，且是 AI 味信号（`ai-signals-22` 的「通用心理」） |

**关键**：**显式标记越少，距离越近，代入越强。** 但太少会让读者分不清是叙述还是内心（需要靠自由间接引语的语气特征来区分）。

## 六、视角的一致性检查表

```
【人称】我 / 他 —— 全文一致？        □
【视点人数】1 / n —— 切换有分隔？    □
【心理归属】只属于视点人物？          □
【感官边界】写的事都能被感知？        □
【叙述者评论】0 处？                  □
【人称滑移】正文无「我」？            □
【距离】显式心理标记占比 ___%        □
```

七项全过 = 视角可用作标准。

---

## 七、风格卡里的写法

```
【视角】
  P3L，视点人物=主角，全章不切换
  距离：中偏近（显式心理标记 22%）
  禁：写他人内心、写主角看不见的场景、叙述者评论
  例外：允许「后来他才知道」回顾句，≤1 次/章
  已测越界：3 处（第 4/9/15 段，均为写他人内心）
```

**「禁」那一行是关键**——它才是写手能执行的东西。「P3L」只是一个标签。
