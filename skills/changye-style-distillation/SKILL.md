# 风格蒸馏

把「文风」翻译成**数字和可执行规则**。形容词不算产物。

## 执行步骤

**第 1 步：定样本**

从 `chapter.get` 抽 3-5 章，要求：
- 全部是 `accepted`（没有就用最长的几章，并在报告里注明）；
- 总字数 ≥ 8000（太少量不准）；
- 覆盖不同场景（对话多的、动作多的、心理多的各至少一章）。

**第 2 步：量六项硬指标**

| 指标 | 算法 | 用途 |
|---|---|---|
| 平均句长 | 总字数 ÷ 句数（按 `。！？…` 切） | 定节奏基调 |
| 短句占比 | 句长 ≤8 字的句数 ÷ 总句数 | 定「碎」的程度 |
| 平均段长 | 总字数 ÷ 段数 | 定呼吸感 |
| 对白占比 | 引号内字数 ÷ 总字数 | 定「戏在嘴上还是戏在叙述」 |
| 比喻密度 | 明喻+暗喻句数 ÷ 千字 | 定意象浓度 |
| 视角一致性 | 人称（第一/第三）× 聚焦（单一/多视点） | 定叙事机位 |

**第 3 步：抽语气特征（三项）**

- **叙述温度**：冷（只给动作）/ 中（动作+少量心理）/ 热（大量心理与评判）
- **信息给法**：直给 / 藏一半 / 全靠对话挤出来
- **标点习惯**：破折号频率、省略号用法、是否用短句单独成段做停顿

**第 4 步：写成规则（不是描述）**

坏：「语言凝练，节奏明快。」
好：「平均句长 14 字；每段不超过 3 句；动作场景短句占比 ≥60%；比喻每千字 ≤1.5 处。」

**第 5 步：落盘**

写进项目说明或 `ledger.upsert`（kind=`highlights` 存「风格卡」条目），让后续写手和去 AI 味都能引用。

## 输入

- 3-5 章样本正文（`chapter.get`）
- `outline.get` 的 `brief`（`tone` / `audience`，用来判断指标是否合理）
- `ledger.get` 的 `characters`（语言基因，对白基线）

## 输出格式

```
【样本】第 <a> / <b> / <c> 回｜共 <n> 字｜其中 accepted <n> 章
【风格卡·硬指标】
  平均句长 <n> 字｜短句(≤8字) <n>%｜平均段长 <n> 字
  对白 <n>%｜比喻 <n> 处/千字｜视角 <第一/第三人称 · 单一/多视点>
【语气特征】温度 <冷/中/热>｜信息给法 <直给/藏一半/对话挤出>｜标点习惯 <…>
【可执行规则】
  1. <能在改稿时拿来当标准的句子>
  2. …
【与 brief 的张力】<指标和 tone/audience 是否打架；打架时给出取舍建议>
【落盘】<写到哪 / 待写>
```

## 检查清单

- [ ] 样本 ≥3 章、≥8000 字，标明了 `accepted` 比例
- [ ] 六项硬指标全部算出具体数字
- [ ] 三项语气特征都给了判断
- [ ] 「可执行规则」每条都能直接用来判一句话合不合格
- [ ] 没有任何一条规则是形容词（「凝练」「大气」）
- [ ] 检查过指标与 `brief.tone` 是否打架
- [ ] 风格卡已落盘

## 禁止事项

- 不许评价剧情好坏、人物讨不讨喜。
- 不许改设定、不许改正文。
- 不许只给形容词当结论。
- 不许用少于 3 章的样本下结论。
- 不许把「我喜欢的风格」混进风格卡——量的是**这本书**，不是你。
