# 改完怎么复查

SKILL.md 要求回执写「需要重走：审校 <是/否，为什么>｜读者报告 <是/否，为什么>」。但没说**判定标准**，结果就是两种极端：全都说「要重走」（浪费），或全都说「不用」（漏检）。

这份给可判定的重走规则：**改动类型 → 是否重走**的对应表，以及重走时的抽查范围。

---

## 一、重走判定的核心原则

**重走的成本应该与被改动的风险成比例。**

风险来自两件事：
1. **改动碰了什么层**（句子 / 场景 / 结构）
2. **改动碰了什么维**（事实 / 节奏 / 人物 / 文风）

**判据：只要改动碰到「事实层」或「结构层」，审校必须重走。** 只碰句子且不碰事实的，审校可免。

---

## 二、审校（continuity-pass）重走判定表

| 改动类型 | 重走？ | 抽查范围 |
|---|---|---|
| 改错别字、改标点 | 否 | — |
| 改措辞（同义替换，事实未变） | 否 | — |
| 改数字（日期/距离/年龄/银两） | **是** | 该数字涉及的全部已写章 |
| 改人物动作 | **是** | 本章 + 后文 3 回细纲 |
| 改人物知道某事的时间点 | **是（必须全量）** | 全部已写章 |
| 改地点 | **是** | 本章 + 后文 3 回细纲 |
| 改物品状态（在哪/属于谁/坏没坏） | **是** | 本章 + 后文 5 回细纲 |
| 删/加一个场景 | **是（必须全量）** | 全部已写章 |
| 改伏笔的埋设或回收 | **是（必须全量）** | 全部已写章 |
| 改规则/代价 | **是（必须全量）** | 全部已写章 |
| 只改节奏（增删重复动作，事实未变） | 否 | — |
| 只改文风（去 AI 味、调句长） | 否 | — |

### 「必须全量」的三类

**知情、场景增删、伏笔、规则**——这四类改动的连锁范围不可预测，必须全量重走。

**判据**：这类改动会让**后文某处的前提失效**，而失效点可能在 20 回之后。

### 抽查 vs 全量的具体含义

- **抽查范围**：只读列出的那几回，跑 `continuity-pass` 的六类冲突扫描。
- **全量**：跑完整 `continuity-pass`。

---

## 三、读者报告（reader-report）重走判定表

| 改动类型 | 重走？ | 抽查范围 |
|---|---|---|
| 改句子（措辞、句长、去 AI 味） | 否（除非改动 >30% 字数） | — |
| 改章中段（压缩/展开） | **是** | 只重测追读欲曲线 |
| 改章首 500 字 | **是** | 只重测开头留人 |
| 改章末 300 字 | **是** | 只重测钩子 |
| 改情绪回报点 | **是** | 只重测情绪栏 |
| 改视角人物 | **是（全量）** | 全量 |
| 整章重写 | **是（全量）** | 全量 |
| 只改事实（日期、物件） | 否 | — |

**关键区分**：审校看「有没有矛盾」，读者报告看「好不好看」。**事实改动影响前者，位置改动影响后者。**

---

## 四、三个「不用重走」的确认条件

说不重走，必须能过这三问：

1. **改动的文字有没有出现在已写章的其他地方？** 有 → 那些地方要不要一起改？要 → 得重走。
2. **改动的文字有没有被后文细纲引用？** 有 → 细纲要不要改？要 → 得重走。
3. **改动的文字有没有进账本？** 有 → 账本要不要改？要 → 得重走（但账本改动不算重走审校，只算补账）。

**三问全「无」 → 可以不重走，回执里写「已确认无连锁」。**

---

## 五、改完立即做的四件事

在决定重走之前，先做完这四件：

### 1. 读一遍改动区段的前后各 100 字

**目的**：查衔接。改了第 8–13 段，就读第 7 段末 100 字和第 14 段首 100 字。

**判据**：读起来顺不顺？不顺 → 衔接句没改好，回三遍法第三遍。

### 2. 搜改动里的关键词

用改动区段里出现的**专名/数字/动作**去搜全部已写章。

**目的**：找出「这里改了，别处还是旧的」这类不一致。

**判据**：搜出的每一处都要能自洽。有一处不自洽 → 必须一起改，然后重走审校。

### 3. 对一次账本

把改动里涉及的人物/地点/物品/规则逐项查 `ledger.get`。

**判据**：改动后的正文是否仍与账本一致？不一致 → 二选一：回退正文，或改账本（改账本要在回执里声明）。

### 4. 重跑一次保真对表

见 `references/fidelity-check.md` 第五节。五项全过才落盘。

## 六、重走时的抽查范围怎么定

重走不必全量时，用这个公式定抽查范围：

```
向后延伸回数 = 3 + (改动涉及的伏笔跨度 ÷ 10，向上取整)
```

### 算例

改了第 12 回的一个预言，该伏笔 `payoffAt = 45`。

```
跨度 = 45 − 12 = 33
向后延伸 = 3 + ceil(33/10) = 3 + 4 = 7
抽查范围 = 第 12–19 回
```

**理由**：伏笔跨度越长，越可能在中途被别的事件引用。延伸回数按跨度缩放。

### 上限

向后延伸回数不超过 **10**。

超过 10 的，直接全量——因为跨度 70 回以上的伏笔本来就应该全量检查。

## 七、重走结果的三档处理

### 档 1：零新增问题

回执写「审校重走：通过，零新增」。**落盘，结束。**

### 档 2：新增问题但与本次改动无关

例如重走时发现第 9 回有个老的时间冲突。

**处理**：**不修**。记进回执的「发现的其他问题」栏，另案处理。

**理由**：改稿只改被点名的。顺手修别处会破坏「可定位性」（SKILL.md 禁止事项）。

### 档 3：新增问题由本次改动引起

**处理**：必须修。修完再重走一次**同范围**。

**连续两轮同范围重走仍有问题** → 说明改法本身有问题，回退这次改动，重新定改法。

## 八、回执的完整写法

```
【需要重走】
  审校：是
    理由：改了人物知道某事的时间点（第 6 段），属「必须全量」类
    范围：全量（已写 12 回）
    结果：新增 1 条警告（第 4 回「他早知道」与本次改动冲突）→ 已修（改第 4 回一句）
    二次重走：通过，零新增

  读者报告：是
    理由：改了章末 300 字（钩子写法），读者报告的钩子栏失效
    范围：只重测钩子
    结果：钩子 6 → 8

【已确认无连锁的三问】
  其他章出现：无（搜「铜片」只在本章）
  后文细纲引用：无（第 13 回细纲未提此事）
  账本引用：有 → foreshadow「袖中铜片」已更新 status=paid
```

**必须有的四项**：是否重走、理由（引用判定表的哪一行）、范围、结果。

---

## 九、五个常见错误

| 错误 | 后果 |
|---|---|
| 一律说「要重走」 | 成本失控，改一个小错要跑全量 |
| 一律说「不用」 | 连锁问题漏检，后文崩 |
| 只写「是/否」不写范围 | 无法执行 |
| 重走发现问题顺手修了 | 破坏可定位性 |
| 重走两次都不过还继续改 | 改法本身错了，应该回退 |
