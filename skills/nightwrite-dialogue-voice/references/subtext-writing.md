> 适用：一段对白「信息都对、语法也对，但读起来假」时读这份，把说明文式的对白改成有潜台词的对话。

# 潜台词：表层与真正想说的那层

对白的信息量有两个方向：**说了什么**（表层）和**想干什么**（潜台词）。只有表层的对白是信息播报；只有潜台词的对白读不懂。健康区间是两层都在，且**读者能自己往上推一层**。

## 判定：这段对白有没有潜台词

单句判据：**这句话如果照字面理解，人物的行为合理吗？**

- 合理 → 这句话没有问题，但也没有潜台词（可用，但一段里不能全是这种）
- 不合理 → 有潜台词。读者会问「他为什么要这么说」，答案就是他真正想干的事

例：

```
A：「你吃饭了吗？」
B：「吃过了。」
```

两层合一，无潜台词。适合过渡、适合掩饰（B 明明没吃却说吃了，但需要一个后续细节让读者发现——比如碗是空的）。

```
A：「你手上的伤，什么时候弄的？」
B：「不关你的事。」
```

表层：拒绝回答。潜台词：他不想让 A 知道时间，因为那个时间点会暴露他昨晚在哪。**B 的强烈拒绝本身就是信息**。

**量化判据**：一段 10 句以上的对白里，至少 **1/3 的句子**应该是「字面理解不合理」的。低于这个比例 = 说明文；高于 2/3 = 全在打哑谜，读者累。

## 潜台词的四种类型

| 类型 | 表层 | 潜台词 | 落地手法 |
|---|---|---|---|
| **隐藏** | 说一件无关的事 | 真实的东西不能提 | 转移话题、答非所问 |
| **试探** | 问一个已知答案的问题 | 想确认对方会不会撒谎 | 明知故问、重复对方的话 |
| **施压** | 陈述一个事实 | 威胁/提醒你我知道 | 说细节、说时间地点 |
| **回避** | 反问或转移 | 我不能再说了 | 「你问这个做什么」 |

### 隐藏型

需求：A 想问 X，但问 X 会暴露自己不该知道。

```
A：「昨天城西那边，好像出了事？」
B：「你听谁说的。」
A（低头拨火）：「路过，看见围了人。」
```

表层：A 在打听。潜台词：A 昨晚就在城西，他需要知道有没有人看见他。B 的「你听谁说的」是试探型潜台词。

**关键**：隐藏型的落地手法是**给一个可被拆穿的解释**。「路过」这个解释，读者会立刻怀疑。

### 试探型

需求：A 已经有答案，想知道 B 会不会说实话。

```
A：「那封信，你送到了？」
B：「送到了。」
A：「他怎么说？」
B：「他说知道了。」
A：「他说的是『知道了』，还是『知道了，让他等着』？」
```

第三句开始，A 在试探——他其实知道原话，只是想抓住 B 的转述漏洞。

**试探型的判据**：问题必须是**重复的、递进的**。第一次问是正常的，第二次用不同措辞问同一个事，读者就知道在试探。

### 施压型

需求：A 要让 B 明白「我知道你的底」。

```
A：「你这双鞋，是城北刘记的。」
B：「……是。」
A：「刘记只做熟客。你上个月才进城。」
```

表层：说鞋。潜台词：我知道你撒谎。**施压型的力量全在细节的具体度**——说得越具体，压力越大。

**三种施压强度**：

| 强度 | 手法 | 例 |
|---|---|---|
| 轻 | 提一个相关的事 | 「你最近常去城北。」 |
| 中 | 提一个只有当事人懂的细节 | 「你鞋上的泥是城北的红土。」 |
| 重 | 把细节和身份对上 | 「红土只在刘记门口。你认识刘记的人。」 |

### 回避型

需求：A 不能再说了，又不想明说不能说。

```
B：「你那天去哪了？」
A：「你先管好你自己的事。」
B：「我问你话。」
A：「我听见了。」
```

表层：拒绝。潜台词：我不能说，而你也最好别问。「我听见了」是最典型的回避——它回应了「我听见你在问」，但没有回应问题。

## 写对白的四步法

### 第一步：先写「他真正要什么」

在对白之前写一行：

```
表层：A 问 B 那封信送到了没有
潜台词：A 要确认 B 是不是已经看过信的内容
```

没有这一行不许写对白。**原因**：不写这一行，写出来的对白会自动变成信息播报——因为写的时候只想着「要把这个信息给读者」。

### 第二步：把潜台词翻译成行动

潜台词不是情绪，是**动作**。A 要确认 B 看过信，他的动作是：

- 问一个只有看过信才能回答的问题
- 或者提一个信里的细节，看 B 的反应

**这一层是决定对白质量的**。同一个潜台词，用「问」实现和用「设陷阱」实现，写出来完全不同。

反例（用情绪实现潜台词）：`A 盯着 B 的眼睛，眼里闪过一丝疑虑。`——这是叙述，不是对白。

正例（用行动实现）：`A：「他信里说的那件事，你怎么看？」`——如果 B 没看过信，这句话会让他暴露。

### 第三步：让表层与原意错开

三种错开方式，按强度排：

| 方式 | 例 | 读者成本 |
|---|---|---|
| 答非所问 | 问时间，答地点 | 低，最常见 |
| 说过头 | 问一句，答三句，越解释越可疑 | 低，带性格 |
| 说反话 | 明明担心，说「随你」 | 中，需要关系铺垫 |
| 说无关的细节 | 问「你怕吗」，答「灯芯该剪了」 | 高，最有力 |

**错开的幅度**：一句话的表层与原意不能差太远，否则读者跟不上。判据——读者能不能在**同一段内**推出来？能 → 幅度合适；要等到三章后才懂 → 太远，会变成困惑。

### 第四步：加一条泄漏线

潜台词不能全靠读者猜，必须有**一处泄漏**让表层与潜台词连上。

三条泄漏线，选一条：

| 泄漏线 | 做法 | 例 |
|---|---|---|
| 动作泄漏 | 说的时候身体出卖了他 | 说「不关我的事」时把手往袖子里收 |
| 语言泄漏 | 一句话里露出不该有的细节 | 「那天我没去城西」——没人说过去城西 |
| 第三方泄漏 | 另一个人的反应 | 旁边的人忽然不说话了 |

**必须有且只有一条**。三条都有 = 太明显；一条都没有 = 读者不知道有潜台词。

## 对白的四条硬规则（SKILL 第 3 步）的落地

### 规则一：不答所问

**量化**：一段 10 句以上的对话里，答非所问的轮次应占 **15–40%**。

- <15% → 采访稿，全是对答如流
- 40–60% → 有点飘，读者会觉得两人没在交流
- >60% → 各说各的，不是对话

**答非所问的三种合法形态**：

```
问：「你什么时候回来的？」
答：「你脸色不好。」          ← 转移焦点
答：「路上耽搁了。」          ← 只回答一半
答：「你怎么知道我回来了？」    ← 反问（等于承认了）
```

### 规则二：有打断

**量化**：一段对白至少 **1 处**打断，长段（>20 句）2–3 处。

打断的三种写法：

```
「我不是那个意思——」
「那你什么意思。」                ← 用破折号断掉
```

```
「你要是敢去，我就——」
「你就怎样。」                    ← 对方抢话
```

```
「这件事我早就说过，你不能——」     ← 话没说完就停
（他把杯子放下。）
```

**注意**：打断不能只出现在同一方。全是 A 打断 B，读者会觉得 B 没有性格。

### 规则三：不完整句

**量化**：该角色台词里，**缺主语或缺谓语的句子应占 20–50%**。

口语的正常状态就是不全。全是完整句 = 书面语。

```
完整句（假）：「我不知道他去了哪里。」
不完整（真）：「不知道他去哪了。」「去哪了，我不知道。」「不知道。」
```

**三种不完整的合法形态**：

- 省主语：`「不知道。」`（承前省略）
- 省谓语：`「你？」`（问对方是否同去）
- 半句：`「要是那天……」`（说不下去）

**不完整的场合限制**：正式场合（公堂、朝会）的角色可以不省，这本身是身份特征。但省不省要一致——同一个人不能一会儿全句一会儿全省。

### 规则四：动作夹缝

**量化**：每 **3–4 句**对白插一个动作。不是「他说」「她问」，是**具体的身体动作或对环境的作用**。

```
「你今晚就走？」她把碗往桌上一放。
「嗯。」
「不等天亮？」
他没答，把刀往腰间系。            ← 动作代替回答
```

**动作的三种功能**（每次插动作时明确是哪一种）：

| 功能 | 例 | 作用 |
|---|---|---|
| 掩饰 | 说话时低头拨火 | 泄漏潜台词 |
| 阻断 | 把碗一放 | 制造节奏停顿 |
| 代替 | 系刀不答 | 用动作替代台词 |

**禁止的动作**：`他笑了笑` `他叹了口气` `他皱了皱眉`——这三类是无信息动作，属于 AI 味（详见 `nightwrite-de-ai-style/references/micro-action-repetition.md`）。

## 常见失败模式

| 症状 | 病因 | 修法 |
|---|---|---|
| 两人轮流讲设定 | 对白承担了叙述的功能 | 把设定挪到叙述，对白只留冲突 |
| 每句都很短很碎 | 以为「短=口语」 | 短句占比控制在 40–60%，其余放中长句 |
| 全是反问 | 用反问代替潜台词 | 反问占比 ≤25% |
| 潜台词读者看不懂 | 泄漏线缺失 | 加一条动作泄漏 |
| 潜台词太明显 | 三条泄漏线全上了 | 删到一条 |
| 一段对白没有任何动作 | 全在空中说话 | 每 3–4 句加一个功能性动作 |
| 所有对话都在推进剧情 | 没有一场「无用」的对话 | 每 3 章至少一场纯关系戏（不推剧情） |

## 一个检验：删掉全部对白，看还剩什么

把这章的台词全删，只留叙述，读一遍：

- 剧情还完整 → 对白只是装饰，说明对白承担的信息太少（或叙述承担太多）
- 剧情断了 → 对白承担了必要信息，正常
- 剧情断了但补不回来 → 对白承担了不该由它承担的设定（信息灌进对白）

**健康的比例**：删掉对白后，剧情大体会断，但读者能大致猜到发生了什么。这个状态说明对白在**推进**而不是**解释**。
