- `references/hook-types.md` —— 钩子的四种类型：新信息/急追问/动作悬停/威胁预告，各给判法与失效形态

# 小说规划

把「一个题材」变成「一张能直接动笔的章纲表」。这份手册只管骨架，不管句子。

## 执行步骤

**第 1 步：锁定定位（不写结构，先定四件事）**

从 `changye_op` 的 `outline.get` 读出 `brief`。缺的字段用下面四问补齐，问不清就不许往下走：

| 字段 | 要问出什么 | 反例（不算答出来） |
|---|---|---|
| `genre` | 站内分类 + 一个同类对标 | 「玄幻」 |
| `audience` | 年龄段 + 阅读场景（通勤/睡前/摸鱼） | 「年轻读者」 |
| `tone` | 一个情绪关键词 + 一个反义词 | 「轻松」 |
| `hookStyle` | 章末靠什么留人（悬念/爽点/情绪/信息差） | 「好看」 |

再定 `pacing`（每千字几个推进点）、`taboo`（绝不写什么）、`ending`（结局方向）。

**第 2 步：算账（先算字数，再分卷）**

```
总字数 ÷ 章均字数 = 总章数
总章数 ÷ 每卷章数 = 卷数
```

`project.get` 的 `targetWords` 是总字数。章均按 `pacing` 定：快节奏 2000-2500，标准 2500-3000。算完用 `outline.save` 写 `brief.volumes` 和 `brief.chaptersPerVolume`。

**第 3 步：定卷主张（每卷一句话）**

每卷必须能用一句话说清「这卷要解决什么」，且这句话里必须有一个**代价**：

- 坏：「第一卷：主角进入宗门，开始修炼。」
- 好：「第一卷：主角为留在宗门必须赢下三次比试，输了就得回去顶他爹的罪。」

写进 `volumes[].summary`。

**第 4 步：定不可逆转折（每卷一个）**

转折的三个条件，缺一不算：
1. 主角的处境发生**结构性变化**（不再是「打不过这个人」而是「不再有这个人可打」）；
2. 主角**失去**了某个东西（退路、关系、身份、信念）；
3. 后文**不能撤回**（不许用「其实他没死」抹掉）。

写进该卷 `summary` 和对应回的 `summary`。

**第 5 步：逐回填细纲（三件套）**

每回必须写满三项，写不满就是没完成：

```
chapter: 章号（连续，不许跳）
title:   回目（不超过 12 字，含动词或冲突）
summary: 这一回发生什么（3 句以内：起因 → 变化 → 落点）
hook:    章末钩子（一句，必须是读者会追问的东西）
```

**第 6 步：因果链自检（这一步不做完不许交）**

把所有相邻两回拉成一条链，逐对回答：

> 因为上一回结尾「____」，所以这一回开头「____」。

答不上或答成「然后他就」= 细纲虚了，回第 5 步重写那一对。

**第 7 步：落盘**

调 `changye_op` 的 `outline.save`，一次传完整 `volumes`。只把表格贴在对话里等于没做。

## 输入

- `outline.get`：现有 `brief` 与 `volumes`（重排时必读）
- `project.get`：`targetWords`、`qualityGate`、`worldState`
- `ledger.get`：已有伏笔（新细纲不许和已种伏笔冲突）
- `chapter.list`：实际已写进度（重排时已 `accepted` 的章回目与钩子视为硬约束）

## 输出格式

```
【定位】<题材> · <读者> · <基调> · 钩子风格 · <节奏> · 结局方向
【账】总 <n> 字 ÷ 章均 <n> = <n> 章 ÷ 每卷 <n> 章 = <n> 卷
【卷主张】
  第 1 卷：<一句话，含代价>
  第 2 卷：…
【转折点】第 N 卷 · 第 M 回 — <不可逆变化> — 失去 <什么>
【细纲】
  第 1 回 | <回目> | 起因…→变化…→落点… | 钩子：<…>
  第 2 回 | …
【因果自检】
  第 1 回 → 第 2 回：因为<…>，所以<…>
  第 2 回 → 第 3 回：…
【落盘】outline.save 成功 · 共 <n> 回 · <n> 字
```

## 检查清单

- [ ] 四问全部有具体答案，没有「玄幻」「轻松」这类空标签
- [ ] 字数账算过，卷数×每卷章数 = 总章数
- [ ] 每卷主张都含一个代价
- [ ] 每卷至少一个三条件齐全的转折
- [ ] 每回 `summary` 都在 3 句内，且都有落点
- [ ] 每回 `hook` 都是一句可追问的话，不是「欲知后事」
- [ ] 因果链逐对答得出，没有「然后他就」
- [ ] 新细纲与 `ledger.get` 已有伏笔无冲突
- [ ] 已 `accepted` 的回目和钩子没被改动
- [ ] `outline.save` 已执行

## 禁止事项

- 不许在细纲里写正文片段、对白示范、修辞句。看到自己写出「他冷笑一声」就删掉。
- 不许一次只交一卷就宣布完成。要么交完整骨架，要么明确说「本轮只到第 N 卷，剩余待定」。
- 不许留「以后再说」的伏笔、留白章、待定回目。
- 不许改已 `accepted` 章节的任何事实。要改必须声明影响哪几回并等确认。
- 不许用「主角成长了」「局势变化」这种无法拍摄的 `summary`。
